2017年7月，内华达州的沙漠里，一栋还没盖完的厂房办了场开业典礼。马斯克站在台上说的第一件事，是台下这块地方只完工了14%，七分之一。

紧接着他补了一句：等它全部建完，这一座工厂的电池产量，会顶得上全世界其他所有锂电池工厂加起来的总和。

台下一片掌声。这话听起来像发布会标配的吹牛。可把当时的账算一遍，会发现他没在夸张，因为按传统路径，那些产能压根不存在，也没人打算建。

## 想造五十万辆车，先得把全世界的电池厂都算进去

特斯拉的使命写在每份材料第一行：加速世界向可持续能源转变。马斯克讲这句的时候强调了两点，这件事早发生还是晚发生，有区别；这件事能不能上规模，也有区别。

规模是关键词。他给的理由很朴素：世界很大。想让全球碳排放曲线真的拐头，电动车和储能电池的产量必须大到能改变总量，小打小闹的产量连统计误差都算不上。

然后是那道算术题。特斯拉内部的推演是，要做到年产50万辆车，需要把地球上所有生产锂电池的工厂全部加起来，包括给手机、笔记本、汽车供货的，产能凑在一起才够。

马斯克的判断方式很工程师：如果这么多产能真的在建设，卫星照片上应该看得见。他没看见。于是结论变成了，要么我们自己想办法把这东西造出来，要么市面上根本不会有足够多的电动车。

“我们就硬着头皮上了。”（马斯克）

他还提到技术迭代这条线。这座工厂用的是第三代技术，从 Roadster 到 Model S 再到 Model 3，电池和动力系统的设计已经走过三轮大改。降本靠两件事：技术一代代往前推，以及把规模做到极致。工厂之所以这么大，原因就在这里，没有别的选项。

## 工厂不是复印机，是一件要被重新发明的产品

这一段是他整场演讲里最想让人记住的。

他说，大部分人看工厂的眼光是错的。在很多人的脑子里，工厂约等于复印机，把现成的设备一台台买回来，按产品目录拼起来，通上电，然后开始复制。他把这种做法叫“目录工程”（catalog engineering）：这台机器找这家公司买，那台机器找那家公司买，拼完收工。

他认为这种思路放到产品设计上会显得荒唐。假如造一辆车的方式是从本田借个保险杠，从别处借个方向盘，再找第三家借个电机，拼出来的东西大概像毕加索的画。

没人会这样造车。那也不该这样造工厂。

所以他的结论是：**工厂本身就是一个产品，是一台“造机器的机器”，它值得投入比产品本身更多的创新和工程能力。**

他还顺手吐槽了制造业的公众形象。造东西被当成无聊的活，做产品设计才酷。他要做的一件事是把制造业重新变得有吸引力，原话是“它需要爱，我们打算给它”。

## 判断一座工厂好不好，用物理学

马斯克说他喜欢拿物理当分析框架。

> 物理是真的，其余一切都可以争论，连物理本身也值得怀疑。（马斯克）

套到工厂上，他把效率拆成两个能算的指标。

- **密度**：厂房体积里，真正有用的东西占多少百分比。剩下的是过道、缓冲区、堆放区、等待区。
- **出口速度**：产品离开工厂的速度。

这两个指标一路往下拆，就变成每道工序、每条产线的设计标准。听上去抽象，其实很具体：一台设备离下一台设备多远，物料在两道工序之间要等多久，这些东西决定了工厂的吞吐能力。

基于这个框架，他给出的估计是，这座工厂的生产能力还有至少5倍、乐观些10倍甚至更多的提升空间。这个数字说的是同一片厂房、同一批设备，重新优化布局之后的潜力，并不靠再盖一倍面积。

支撑这个判断的是一件事：整座工厂在 CAD 里建了模。每一根管道，每一段电缆桥架，每一节风管，每一台设备，全在模型里，按最小浪费空间的原则摆放，很多楼层的设备几乎彼此贴着。

他把这种布局比作高密度多层集成电路，像一颗先进 CPU。更远一点，他认为未来的制造业会越来越像那些超高速贴片机，为速度和密度极致优化。

他还举了个反例说明进步从哪来。手机和笔记本变强，靠的从来不是把电脑做成桌子那么大，靠的是时钟频率和集成密度。同一套逻辑，放到制造上一样成立。

这段话背后有个不太被说破的前提：工厂的成本结构里，很大一块是“等待”和“搬运”。设备之间距离越远，物料在路上花的时间越长，在制品库存越高，占用的现金越多。密度提上去，这些隐形成本一起掉下来。他说的5到10倍，指的正是这部分被浪费掉的产能。

## 一个分子少跑几趟地球，成本就下来了

电池成本里有一部分不来自技术，来自物流。

马斯克给了一个衡量制造效率的土办法：看一个分子从被开采出来，到变成成品，一共走了多远的路。

如果锂在某个大洲挖出来，运到另一个大洲加工，再运回半个地球做下一道工序，中间绕地球好几圈才装进车里，那这个产品注定便宜不了。没人能靠环球旅行压成本。

Gigafactory 的做法是把整条链塞进一栋楼：从最上游的原材料处理，到电芯，到模组，到成品电池包，全在一个屋顶下面。他在现场开玩笑说流程分三步，“原材料进去，一堆事情发生，车出来”，秘密全在中间那步。

他提到下一代工厂会更彻底。当时整车厂在加州弗里蒙特，电池厂在内华达，两地分开。到了 Gigafactory 2 以及以后，整车制造和电池制造会合并进同一个园区。理想状态是一边进原材料车厢，另一边直接出整车。

## 六百万平方英尺，一百架波音747

他给了几个换算，帮人建立体感。

这座工厂的占地面积约600万平方英尺。只按占地面积算，它会是世界上最大的建筑；按体积算，仅次于华盛顿州那座波音工厂，排第二。

747 够大了吧。这片厂房的占地面积能停下大约100架。他停了一下，又补了个更没正经的换算：也能装下500亿只仓鼠。

产能量级更夸张。他先给的目标是这座工厂最终产出大约150吉瓦时（GWh），后面又提到两年内做到年产250吉瓦时。两个数字口径上有出入，量级是一致的，都指向一个远超当时行业总和的规模。

对比数字是：2014年全球锂电池总产量，各种用途全算上，大约30吉瓦时。2015年的具体数字他没记住，但差别不大。

他的说法是，到2020年前后，全世界其他所有工厂的产能加在一起，这一座工厂能顶得上。而在2014年，整个地球的产量只有它的零头。

再往后，等工厂完全建成，他估计年产能对应大约150万辆车，同时还能给储能市场供应大量电池包。全部建成的时间点他放在2020年前后。他还说，届时大家站的位置正好是工厂的正中间，所以到那时候应该再办一次派对。

进度比他最初的计划快。Model 3 的预订结果超出预期，50万辆的年产目标提前了整整两年。代价是厂房规模要跟着扩张：外面那栋建筑到第二年面积差不多翻倍。

这里还有个容易被忽略的背景。他们决定动工的时候，Model 3 那场发布会还没开，那些刷屏的预订数字也还不存在。很多人当时怀疑，纯电车的需求能不能撑起这么一座工厂。马斯克在台上把这件事归给了台下的人：**这座工厂能被建出来，是因为有人先相信了它。**

## 现在一千人，将来一万人

有人问到就业。他回答，当时工地上大约有1000人在工作。产能扩到150吉瓦时之后，效率会提升，但用人规模大概会到1万人这个量级。

他还纠正了一个常见误解：Powerwall（家用储能墙）和 Powerpack（商用储能柜）当时已经在出货，产地就是身后那栋楼。这座工厂不是纯粹的建设工地，一部分产线已经在跑。

## 电池报废那天，材料一样都没少

现场有人提到回收，马斯克借这个话题讲了一段他显然很想讲的东西。

Gigafactory 里会自建回收产线，所有电池包都会回收。这么做有个很实际的优势：**回收设备可以针对一款已知的电池包做定制设计。**你不必去处理市面上千奇百怪的电池结构，你知道模组长什么样，就能把拆解机器优化到很精确的程度。

他接着说了那个大多数人不会去想的事实。一块锂电池造出来，用上15到20年，到最后一天，当初装进去的所有材料仍然在里面。没有散失到环境里，也没有被烧掉。所有金属，所有有价值的材料，全都还在。

而今天造一块新电池，材料是整条成本里最贵的部分。

两件事放在一起，结论就出来了：如果能把这批材料原封不动送回工厂，成本只剩运费，新电芯的材料预算就能大幅下降。这就是回收的未来。

工厂本身的用电也做了闭环。全面投产后，Gigafactory 会完全靠可持续能源运行：地热用于温控，风电从外地引入，屋顶铺光伏。三者相加，够整座工厂用。

## 每个大洲都得有一座

提问环节有人问海外布局。马斯克的回答很直接：至少每个大洲都要有一座 Gigafactory。理由还是物流，把车运到半个地球之外，运费和能耗都太高。

他给出的顺序是，先看北美这边什么时候接近饱和，然后去欧洲建电池厂，亚洲这边会去中国，可能还有其他地区。核心逻辑是把生产放在需求附近，把供应链缩短。

产能分配上，前期大约三分之一给储能，30%到35%这个区间，其余给车。长期看两者会大致持平。

他补了一句更大的账：从全球能源转型的宏观角度看，需要的车载电池容量和需要的固定储能容量，量级差不多。这个判断后来基本被验证了，光伏白天发电、晚上没电，储能和电动车消耗的是同一批电芯。

## 大师计划的四件事

演讲里他把特斯拉的总体规划又过了一遍，一共四条。

- 造好看的太阳能板，配上电池储能。
- 覆盖所有主要车型细分市场，用最快速度把世界从石油上挪开。
- 做到比普通人类驾驶员好10倍的自动驾驶。全球每年有120万人死于交通事故，这里的生命是实打实的数字。
- 任何时间都能把车加入共享车队。

第四条他讲得比较细。车大部分时间都停在停车场里闲着。如果能随时接入共享车队，车辆的使用效率会成倍提高，也能抵消一部分拥车成本。

操作方式是打开手机上的 Tesla App，一键把车加进车队。你还能设定规则：只开放给五星用户，或者只给家人，或者谁都可以。想收回的时候再点一下，车自己回来。

他强调决定权完全在车主手里，做不做由你，车是你的。台下有人喊了句玩笑，他接了一句：它还会帮你找宝可梦。

## 锂不够用？宇宙里第三多的元素

锂资源是每场电池发布会都会被问的问题。马斯克的回答从宇宙尺度开始。

锂是宇宙中第三多的元素，前两名是氢和氦。氢在地球上全被水或者碳氢化合物锁住了，自然界找不到游离态的氢；氦是惰性气体，不跟任何东西结合，基本上飘走就没了。锂是金属，飘不走。

所以储量不是问题。几乎任何含盐的溶液里都有锂，海洋里就有巨量。任何一处干涸的古代盐湖湖床，锂含量都很可观。全球锂储量远远超过电动化所需。

他还纠正了一个容易被名字误导的地方：**锂只占一块电池大约2%的成分。**它叫锂离子电池，是活性物质，但重量占比很小。

结论是，把全世界所有汽车换成电动车，锂都不会成为瓶颈。这件事做完之后，还可以开始回收。锂不像石油，烧完就没了。车造出来之后，那批锂可以反复使用、反复再生，永远用不完。

他顺带把“锂峰值”（peak lithium）这个说法批了一句：那是胡扯。

## 专注的代价：叉车电池和 Roadster 都得等

有人问叉车电池。他回答短期不做。理由跟看不看得上这个市场无关，是要保住专注。当时的全部精力都得压在 Model 3 上。

再往后的产品优先级，他给的是紧凑型 SUV。另外团队有个挺有意思的概念：基于 Model X 平台做一款小型巴士。他说如果真按小巴的思路改，Model X 能装下的人数会让人意外。

至于 Roadster，他说自己非常想做下一代，但必须先做出大众买得起的车。“专注最重要，能做的事情太多，一旦不专注，风险是什么都做不成。”

这句话放在整场演讲里不算金句，但它解释了 Gigafactory 为什么长成这个样子。它砍掉了几乎所有非必要环节，把资源集中到电池这一件事上。

## Model 3 的状态：设计刚定稿

他透露 Model 3 的设计在演讲前几周刚刚完成。通常后面还会随着测试做小幅调整，但主体已经定了。

他特别提到，Model 3 上大量部件和系统是第三代设计。第一代在 Roadster，第二代在 Model S 和 Model X，一路迭代下来，很多东西走了很远。里面还有一些创新他当时不能讲。

更让他高兴的是团队观念的变化。特斯拉内部开始真正接受一个想法：设计工厂比设计产品本身更重要。这件事对“大批量造出价格合理、质量过硬的车”极其关键。

他的原话是，他对这件事感觉非常乐观。

## 真正的阻力是宣传

最后有人问普通人能做什么。马斯克的回答跳出了技术圈。

他说，把消息传出去就行。他知道在场的人都相信全球变暖是真的，但外面有很多人不信，这一点让他觉得不可思议。

他把原因指向化石燃料行业，说那边有一场不间断的宣传战，而且他们的钱比特斯拉多上千倍。“他们在自卫，这你可以预料，但宣传是一刻不停的。”

所以他给这场能源转型定了个性质：**这场变革只能从民众中来。**

他也提醒在场的人，接下来美国大选期间，各种离谱的说法会更多。

## 把这场演讲重新排一遍

它的核心不在参数，在一种看待制造的方法论。工厂是产品，密度和出口速度是可以量化的指标，垂直整合压缩的是分子跑动的距离，回收能成立的前提是材料从没离开过你手里。

2017年站在这栋只完工14%的厂房里，他把这些逻辑串成了一条线，然后给了一个时间表：2020年前后全部建成，年产对应150万辆车，产能顶得上全球其他所有工厂之和。

几年过去，这些数字有的兑现了，有的推迟了，有的被更大的扩产计划覆盖掉了。但那一套把工厂当机器来设计的思路，后来被整个制造业抄走了。

- 评估一个制造项目，先算两个数：厂房体积里有用部分占多少，产品从进料到出货要花多少时间。这两个数比任何设备清单都更能说明问题。
- 拆成本的时候画一张物料流动地图，标出每种关键材料从开采到装车走了多少公里。凡是绕地球的项目，都存在被垂直整合吃掉的空间。
- 产品设计阶段就留出回收接口。材料成本占比越高，这一步越值钱，因为十年后那批材料会是你最便宜的原料。
- 别用目录工程的方式拼系统。买现成模块凑出来的东西，性能和成本都会停在别人的水平线上，还多出一堆接口损耗。
- 把专注当资源来管理。列一张“我们决定不做”的清单，长度应该和待办清单差不多。马斯克用叉车电池和 Roadster 换来了 Model 3 的产能。
- 遇到行业性的舆论噪音，别急着辩论。把产品做出来、把成本降下去，那才是最有效的反驳。
