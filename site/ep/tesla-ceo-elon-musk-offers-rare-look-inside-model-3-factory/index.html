Tesla CEO 马斯克罕见带看 Model 3 工厂

Tesla CEO Elon Musk offers rare look inside Model 3 factory

CBS Mornings·2018 年（约）·7 分钟·精读约 3685 字 · 阅读 8 分钟
中文精读由 AI 基于原始视频与文稿改写，非官方翻译，可能存在偏差或错误；表述以原视频为准。说明

2018 年 4 月的加州弗里蒙特，特斯拉工厂的一块白板上写着一个数字：2071。这是过去七天 Model 3 的产量。马斯克（Elon Musk）站在白板旁边，CBS 记者问他，对这个数字满意吗。他说，暂时满意。

一年多以前，他对着全世界说，2017 年底要做到周产 5000 辆。后来目标降到 2500。现在是 2071。记者把这段历史摊开问他，马斯克没有绕：没错，我需要想清楚怎么做得更好，然后才能做得更好。

这是网络电视台的摄像机第一次被允许进入 Model 3 的生产线。也是马斯克少有的、愿意把“生产地狱”这四个字摊开给人看的时刻。开场镜头还没推进车间，记者先念了一串过去一个月的事故清单：主动召回 12.3 万辆老款 Model S；一起涉及半自动驾驶系统的致命车祸；华尔街下调公司信用评级。念完问他，你还好吗。马斯克说：我肯定压力很大，如果我看起来压力很大，那是因为我真的压力很大。

装配线上的“婚姻”

整条生产线被切成三段。前段做车身，中段把电池组和电机装进去，后段收尾。马斯克管中段叫“marriage”，结婚。

记者问：婚前、结婚、婚后，哪个最难？

马斯克：现在是结婚最难。

这个比喻在汽车行业用了几十年。但从他嘴里说出来，配合当时的处境，听起来像在说别的事。电池、电机、车身，三样东西要在同一个节拍上汇合，任何一环慢半拍，整条线就堵在那里。他后来解释，问题恰恰出在“结婚”这一步：新的电池架构、新的电机、新的车身结构，全都在同一个工位上第一次碰面，谁也没跟谁磨合过。

机器人拖慢了生产

这条线被外界称为地球上机器人密度最高的汽车装配线之一。摄像机的镜头扫过去，机械臂排成一片，看不到几个人。

记者问了一个当时很多人都在问的问题：Model 3 是不是机器人用得太多了，也许该多放几个人进来？

马斯克的回答很干脆：有些环节，机器人确实拖慢了生产。

他举了个具体例子。原本设计了一套极其复杂的传送带网络，车身在上面绕来绕去，像迷宫。这套系统在图纸上看着漂亮，实际跑起来完全不工作。最后的处理方式是，把整套东西拆掉，扔了。

我们对自己认定的核心技术太自满了。我们把太多新技术一次性塞进了 Model 3，这些本该分阶段上。（马斯克）

这句话值得停下来想一会儿。外界对特斯拉的刻板印象是“激进”“颠覆”“不怕试错”。马斯克自己给出的失败原因，恰恰是另一种东西：对已有的东西太自信，同时对新东西太贪心。

“太自满”和“太贪心”听起来矛盾，放在一条生产线上却完全说得通。已经跑顺的环节，团队默认它没问题，不再盯着看；新上的环节，一次上太多，任何一个出问题都找不到根因。两头一夹，整条线就卡住了。

4 月初，马斯克亲自接管了 Model 3 生产线。他的说法是，把精度要求拉到极端的水平。

那张睡不下的沙发

记者跟着他走进工厂角落的一间小房间。里面有一张沙发，窄得离谱。

马斯克：我经常睡这儿。

记者：你就躺这儿？

马斯克：对，沙发。

记者：上次你说你直接睡地板，因为沙发太窄了。

马斯克：是啊，这沙发一点都不舒服，很糟糕，不是张好沙发。

这段对话在整个采访里最不像采访。两个人站在一间堆着杂物的屋子里，讨论一张沙发的舒适度。记者后来在演播室里说，她起初以为这是作秀，等马斯克不在场的时候，她去问了工厂的员工。员工说，他真的睡这儿。

她追问员工，他为什么要这样，他又不是在拧螺丝、开机器。员工的回答是：因为他能实时解决问题。他看一眼那块板，就知道问题出在哪儿，走过去改，改完自己回来验证。

这个细节比任何一句“我很拼”都有说服力。睡在工厂的价值不在“睡”，在“实时”。生产线上一个异常从发生到被定位，中间隔着多少层汇报、多少次复现、多少个“我这边看是好的”。把决策者放在物理位置上离问题最近的地方，这段延迟就被压掉了。

记者在演播室里补了一句评价：他把自己犯错误和修错误的过程，实时展示给我们看。平时我们看不到钟表内部的齿轮怎么转，这次看到了。

后视镜和前挡风玻璃

2071 这个数字，马斯克认为是可以持续的。他预计第二季度 Model 3 的产量会有三到四倍的增长。

记者提醒他，批评者听过太多类似的预测，特斯拉至今一次都没兑现过。

马斯克的回应是这次采访里最像他本人风格的一段：

很多人低估特斯拉，是因为他们总看特斯拉过去做了什么，然后拿这个当作我们未来能力的参照。他们看的是后视镜，不是前挡风玻璃。（马斯克）

这句话可以当口号听，也可以当方法听。当口号听，它是典型的马斯克式自信。当方法听，它其实在说一件事：用历史数据外推一家正在改变生产函数的公司，误差会很大。2018 年的特斯拉不是在一条已知曲线上往前挪，它是在换一条曲线。外推法在这种时候会系统性低估，也会系统性高估，方向取决于换曲线的人有没有做成。

这里有个容易忽略的对称性。同一套逻辑，既解释了为什么分析师看衰他，也解释了为什么他敢在愚人节开那个玩笑。两者背后是同一个判断：我对实际情况的掌握，比外面的人清楚。

一个关于破产的愚人节玩笑

2018 年 4 月 1 日，特斯拉正被铺天盖地的“要破产了”的报道围着。马斯克在社交媒体上发了一条：

我们悲痛地宣布，特斯拉已经彻底、完全地破产了。破产到你不能相信的程度。（马斯克）

记者在采访里直接把这事摆出来：大家很紧张，你知道大家在担心，为什么还要开这种玩笑？

马斯克：因为有媒体报道说特斯拉要破产，所以我就开了个愚人节玩笑，说我们真破产了。

记者：埃隆，这不好笑，人们很紧张。

马斯克：愚人节啊，大家放松点。这挺明显的吧。如果我觉得破产有一丝一毫的真实可能，我不会拿它开玩笑。

这段对话没什么可辩的。它暴露的是一种很多人学不来的判断方式：他用自己的信息优势，去校准什么能开玩笑、什么不能。问题在于，玩笑的接收方没有这份信息优势。对站在外面的人来说，“破产”不是段子，是每天醒来都在担心的那件事。

但同一段对话里，他也给出了当时最明确的一次状态描述：

我对特斯拉现在的状况挺乐观的。我现在清楚地知道走出地狱的路在哪。直到不久前，我还不知道。（马斯克）

“知道路在哪”和“走到那儿”是两件事。他当时能给的，只有前者。

交付时间又往后推了

采访里有一个数字，比 2071 更让预订用户关心。马斯克说，去年 7 月发布时下订单的人，大概还要三到六个月才能拿到车。

这意味着比当初承诺的时间晚了六到九个月。

这个数字放在整篇采访里不起眼，但它是“生产地狱”最真实的成本。工厂里的每一个卡点，最后都会折算成某个普通家庭多等的半年。马斯克在采访里没有回避这个换算，他只是没有展开。

这件事跟造车之外的人有什么关系

记者在演播室里的收尾判断，比采访本身更值得记下来。她说，马斯克在自动化上踩的坑，对所有企业都是关键的一课：你会过度自动化。

这一课的完整版是这样的。2018 年之前，主流叙事是“机器换人”，谁的产线机器人多，谁就更先进。特斯拉把这条路走到了极致，然后撞墙。撞墙之后，马斯克做的事不是加更多机器人，是拆掉一整套传送带，把人和简单的工位重新放回去。

“过度自动化”这个词，在 2018 年还是个新鲜说法。几年之后它变成了制造业的常识，再后来变成了所有做流程的人的常识。写代码的、做客服的、跑财务的，都在某个时刻发现，自己搭的那套自动化流程，维护成本比它省下的人力还高。

马斯克给出的诊断是“一次性上太多新技术”。这句话几乎可以原样搬到任何一个正在做系统替换的团队里。新技术本身没错，错的是把所有新东西压在同一次上线里，让故障无法归因。他自己承认，这些应该分阶段上。

采访最后，记者问他，还有什么想说的。他没给金句。整段采访里他也没有给出什么金句。他穿着同一件深色外套，站在轰鸣的车间里，说话语速不快，句子短，遇到不好回答的问题就沉默两秒，然后给一个不带修饰的答案。

演播室里的主持人最后评价他：非常冷静，非常自信，说话就事论事，表达方式很直接。另一位补了一句：他思考的方式是跳出框框的。

这些评价都对，但都轻了。这次采访真正留下的东西，是一个把公司押在一条产线上的人，愿意让摄像机进去，拍下他还没搞定的时候的样子。白板上写着 2071，离 5000 还差一半多，他没有把白板擦掉。

如果你正在推进一件很难的事

这场 2018 年的工厂参观，剥掉马斯克本人的光环之后，剩下的是一套可以迁移的做法。下面几条，是可以直接拿去用的。

  • 把决策者放到问题发生的地方。不是远程看报表，是站在产线旁边。中间少一层传递，异常的处理速度就快一个量级。
  • 新技术分批上，一次只改一个变量。同时改三个，出问题时你连归因都做不到。马斯克自己承认这是 Model 3 踩的最大的坑。
  • 对“已经跑顺的环节”保持警惕。失败往往来自你默认没问题、因此不再盯着的部分，而不是你最担心的那部分。
  • 敢拆。那套复杂的传送带网络已经建好了，拆掉意味着承认前面的投入打水漂。不拆，整条线继续堵着。沉没成本在生产线上是最贵的。
  • 自动化之前先问一句：这个环节的异常处理有多复杂。异常越复杂，越该留人。机器人擅长重复，不擅长判断。
  • 对外承诺的每一个数字，最后都会折算成某个具体的人多等的几个月。定目标的时候把这个换算放在桌上。
  • 开诚布公的边界要算清楚。你有信息优势，对方没有。用你的信息去判断“这能不能开玩笑”，对方的感受不会跟着你的判断走。
