2014年伦敦Tesla门店：马斯克谈Tesla与SpaceX

Elon Musk talks Tesla & SpaceX at London Tesla store 2014

2013年，几台 Model S 在事故后起火。同一年，美国公路上大约有50万台汽油车起火。前者占据了全球科技媒体的头版，后者连地方新闻的版面都挤不进去。

2014年，伦敦的一家 Tesla 门店里，有人把这件事摆到马斯克面前，问他觉得媒体报道公不公平。他没有发火，先给了一句总结：

在这个行业里，你靠这把剑活着，就得死在这把剑上。我们做的每件事都会被放大。（马斯克）

然后他补了一组数字：Model S 的起火发生率是汽车行业的五分之一，可能是市面上最不容易起火的车型。可2013年关于它起火的报道量，超过了其他50万台汽油车起火事件的报道总和。

还有一组数字更少被提起：Tesla 的车至今没有造成任何一例死亡，也没有一例永久性伤害。

他承认公众的印象没跟上事实。很多人依然觉得这台车不安全，尽管它比路上跑的大多数车都安全。

这场访谈发生在第一批 Model S 运抵英国的时候。采访者一开口就摆了两个数字：当年预期交付3.5万台；11年前，这家公司还不存在。

你靠这把剑活着，就得死在这把剑上

采访者追问得很直接：这些负面声音，是不是来自那些被吓到的传统车厂？马斯克的回答带着点无奈，有些对手确实会出手，这在竞争里很正常。

但他相信真相最终会赢。理由很具体：现在有互联网，任何人花五分钟查资料、做横向对比，就能把事实拼出来。

采访者又问他，是不是太容易被这些话刺痛。他没有否认。

他说自己非常在意 Tesla 和 Model S，很难做到不动感情。这台车背后是很多人的血汗。他打了个比方：你的孩子去参加比赛，输掉了，可输的原因并不在实力上，你会很生气；如果有人用不实的话贬低你的孩子，你也很难平静。诚实的批评当然可以接受，问题是你没法对一个自己在意的东西摆出旁观者的姿态。

这段话解释了他后来在社交媒体上那些冲动的回应。他清楚自己会被放大，只是没法把自己摘出去。

他把这台车当成自己的孩子

"孩子"这个比喻不是随口一说，它撑起了整场访谈的语气。

一个创始人谈起自己的产品，通常有两种姿态。一种是路演式的，讲市场规模、讲增长率、讲竞争壁垒。另一种是手艺人的，讲哪里难、哪里差点做砸、哪里还差一口气。马斯克在这场访谈里几乎全程是后一种。

他讲到起火事件，第一反应是拿出发生率的分母，公关策略排在后面。讲到破产，先讲的是哪一年、差多少、谁帮了忙，公司愿景排在后面。

这种叙述方式有个副作用：听起来不太像一个 CEO 在讲话。它更像一个工程师在复盘。

2008年，离破产只差一点点

问到11年里最大的挑战，马斯克的答案落在财务账上。

是2008年没有破产。

那一年全球金融危机爆发，通用汽车和克莱斯勒相继破产，Tesla 距离破产只差一点点。撑住它的是两群人：一批极其投入的员工，和一批愿意继续下注的投资者。他把那一刻称为创建这家公司过程中最艰难的时刻。

把时间线摊开看会更清楚。Tesla 在2003年成立，第一款车 Roadster 在2008年才开始交付，Model S 到2012年才下线。也就是说，在拿到第一款量产轿车之前，这家公司已经在生死线上走了一遭。

同一段时间里，他还在运营 SpaceX。2002年成立 SpaceX，2003年入局 Tesla，2008年两家公司同时缺钱。这个背景让"11年"这个数字有了不一样的重量：它中间有好几次差点归零，绝非一段匀速生长的11年。

安全、性能、续航，三件事互相拉扯

技术上的挑战，马斯克说得很朴素：要造一台特别安全的车，还要性能好，还要跑得远。

这三件事在工程上互相拉扯。安全要结构强、要吸能区，车就重；性能要功率和扭矩；续航要装更多电池，电池本身又增加重量。任何一头拉满，另外两头就会被拖下去。

Model S 交出的答案是：一台豪华轿车，续航265英里，约合426公里，同时具备高性能。

这个数字放在2014年是个什么水平？当时市面上大多数电动车还在100英里上下徘徊，265英里已经接近不少汽油车加满一箱油的水平。更关键的是，它没有靠小车加轻量化去换续航，它是一台能坐五个人、能装行李的中大型轿车。

他还提到另一件事：这台车被全球一些最挑剔的汽车评论评为史上最好的车之一。对一个成立11年的公司，这个评价的分量不在奖杯，而在它证明了一件事：电动车不必是妥协的产物。

这个"不必妥协"很要命。早期电动车在公众心里的形象是慢、丑、跑不远、充电麻烦。要改变这个印象，靠的得是一台让人坐进去就想开走的车，宣传册上的口号起不了作用。

创立那天想做的事：造一台比汽油车更好的车

采访者问，11年前公司还不存在，你当时在想什么。

我们创办 Tesla 的时候，想证明一件事：可以造出一台真正有吸引力的电动车，一台真的比汽油车更好的车。Model S 做到了。（马斯克）

这句话的重心落在"更好"两个字上，"更环保"和"更省钱"都是后面的事。

环保是附加价值，好开、安全、跑得远才是产品本身。这个顺序一旦倒过来，产品就会变成一种道德义务：你买它是因为你应该买，而不是因为你想买。道德义务撑不起一个行业，只有让人觉得更好的东西才撑得起。

他后面讲到政府、讲到政策、讲到补贴，用的也是同一套逻辑。政策能给推力，产品力才是真正的引擎。

每年一亿台新车，电动车不到百分之一

话题转到英国。采访者提到，英国前些年关于环保的讨论很热，后来慢慢从议程上滑走了。为什么这件事要靠一家私营公司来推，政府是不是想得不够。

马斯克的回答不太客气：

世界各国的政府都会大声说自己在乎环境，但结果并不好，汽车行业尤其明显。（马斯克）

然后他把账算了一遍。全球每年生产9000万到1亿台新车，路上跑的总保有量大约20亿台。今年造出来的新车里，电动车占比不到1%。

这组数字放在一起，结论是冷的：就算从今年开始，全世界生产的每一台新车都是电动的，要换掉现有的20亿台车，也需要20年。而现实是新车里只有不到1%是电动的。

所以他直接说，需要更强有力的行动。美国政府、英国政府，所有政府都需要做得更多。他们在谈，但行动必须加速。他给了一个门槛：至少让新车里电动车占到1%。

采访者当场附和，1%是个非常低的门槛。

低到什么程度？它甚至算不上目标，只算一个起点。一个行业在1%的渗透率上停留太久，说明推动力主要来自政策口号，成本和技术还没跟上。他后面关于价格的那段话，其实是在解释为什么渗透率上不去。

五万英镑起步，三年后才有平价车

采访者指着眼前这台车，说这台配置大约8.5万英镑，问这玩意儿是不是只是富人的玩具。

马斯克承认，这个配置加了选装，起售价是5万英镑。

他没有回避"贵"这件事，直接给出了 Tesla 的三步路线：

  • 第一步，Roadster。一台跑车，更贵，产量更小，用来证明电动车可以很快、很酷。
  • 第二步，Model S。价格中等、产量中等，也就是他们当时站的位置。
  • 第三步，大众市场的平价电动车。

顺序不能反。他解释得很直白：必须先把 Model S 卖出去，赚到钱，才有资金去做那台高销量的平价车。他也坦率地说，他们想不出别的路径。

采访者追问平价车什么时候来。答案是大约三年。

这段对话在2014年听起来像一个承诺，回头看成了一条完整的因果链。技术降本需要钱，钱来自高毛利产品的销量，高毛利产品需要先被市场接受。先卖贵的，再做便宜的，这条路在太阳能、电池、芯片上都反复出现过。它的代价是，头几年只有少数人买得起。

这也是他面对"富人玩具"这个指责时最实在的回应。他没有辩解说我们其实很便宜，他的说法是我们暂时就是这么贵，贵是路径的一部分。

汽车这个形态还要再用很久

采访者抛出一个更大的问题：汽车到底是不是未来交通的最佳形态？马斯克自己提过 Hyperloop，谷歌在做无人驾驶，还有各种公共交通方案。为什么要修修补补一台车，不去想完全新的东西？

马斯克的回答很务实：人们就是喜欢车。这是他们主动选择的出行方式。所以只能去适应人们想做的事。

他补了一句：这不排斥 Hyperloop 或者公共交通，它们是互补的。电动车的路还是要走。

这个回答藏着一个产品判断。改变世界通常没法靠逼人换一种生活方式，更可行的做法是把现有生活方式里最糟糕的那部分换掉。人还是要开车，只是不用再烧油。

顺便说个背景，Hyperloop 的白皮书是2013年发布的，就在这场访谈前不久。他当时把方案公开，自己没去做，理由是手上两家公司已经占满了精力。这也解释了为什么他在访谈里把它说成"互补"，替代关系他从来没提过。

1969年能登月，现在只能到低轨道

话题转到 SpaceX。它比 Tesla 早一年左右成立。采访者问他当时想做什么。

他的出发点带着一股不服气：

人类1969年就能登上月球。现在勉强能到低地球轨道。这是能力的巨大衰退。（马斯克）

SpaceX 的目标，是把这条曲线扳回来，快速推进火箭技术，直到有一天能在火星上建一座城市，让人类成为多行星物种。

他半开玩笑地提了一句，Facebook 不会去干这件事。

这句玩笑背后有个严肃的判断：技术不会自动进步。登月之后的四十多年，航天能力没有继续上升，反而收缩了。一个领域如果没有人在里面死磕成本，它就会一直贵下去，然后越来越少的钱愿意进去。

下一趟去空间站，乘客是40只老鼠

2014年的 SpaceX 在做什么？马斯克给了具体进度。

当时他们为各类商业客户往轨道上发射卫星。NASA 是最大的单一客户，大约占发射量的四分之一。他们已经完成了多次往返国际空间站的货运任务，其中一部分运的是活体货物。

下一趟去空间站的任务，会带上40只老鼠。

他管这些老鼠叫"宇航员"。这个细节听起来像玩笑，实际上是能力的证明：飞船能维持生命支持系统，能带着活物上天、对接、再返回。

然后他给出了时间表：大约两年后送宇航员上天，之后继续往前走。

这个承诺后来没有兑现。SpaceX 第一次载人飞行是2020年，比时间表晚了几年。航天领域的延误是常态，看发布会时间表的人最好先打个折。

NASA是最大客户，也是绕不过去的伙伴

采访者提了一个尖锐的问题：登月已经过去这么多年，政府对太空的支持在退，私营企业被迫接手，这是不是一件可惜的事。

马斯克的回答先给 NASA 记了一功。SpaceX 和 NASA 是合作关系，NASA 是巨大的支持者，没有 NASA，他们到不了今天这一步。

然后他说了一般规律：商业技术公司在推进技术上比政府更有效率，尤其是当一项技术走出基础研究阶段之后。SpaceX 想做的，就是把技术开发的速度拉起来，比政府主导时快得多。

这个判断和他在 Tesla 的说法是同一套逻辑。基础研究、国家工程，政府有不可替代的作用。一旦进入工程化、降成本、批量生产的阶段，商业公司的效率优势就出来了。他举的例子其实很含蓄：NASA 出钱买服务，SpaceX 负责把发射成本打下来。

火星船票的价格，是一套中产房子

采访者抛出一个担心：太空私有化会不会变成狂野西部？历史上最冷酷的资本主义样本就是西部拓荒。太空会不会只让少数富人受益？

马斯克没有绕开。他说，要建成一座能自我维持的火星城市，必须让去火星的成本尽可能低。

要把搬迁成本压到大约相当于一套中产阶级房子的价格。这样才会有足够多的人愿意卖掉地球上的房子，搬到火星去。（马斯克）

他把这条线称为自给自足殖民地的门槛。

他拿英国在美洲的殖民地做类比：一开始去的是有钱人，英国政府出钱赞助一批人过去；后来慢慢地，任何人都能去。火星大概也是这个路径，先贵后便宜，先少数人后普通人。

至于目的地，他排了个序。地球和火星之间没有大的小行星，大块的小行星都在火星和木星之间。所以月球之后，要么去一颗很小的行星，要么直接去火星。火星更近。

火星着陆的时间表，他给的是11到12年。

这段回答里有整场访谈最硬的一个工程逻辑：殖民地能不能成立，最后落在单位成本上，技术炫技解决不了这个问题。能不能把人送过去是火箭问题，能不能让普通人付得起是经济问题。他在2014年就把这两个问题放在一起看。

采访者追问私立太空公司会不会变成狂野西部，他给出的答案其实就是一句：如果票价等于一套房子，去的就不会只是富人。

维珍银河卖的是五分钟失重

采访者提到理查德·布兰森的维珍银河，问 SpaceX 是不是在做差不多的事。

马斯克的回答直接把两家公司分开了。维珍银河更偏娱乐，给乘客一趟短暂、好玩的飞行，几分钟失重。SpaceX 的目标是火星殖民。

两者都叫商业航天，商业模式完全不同。一个卖体验，客单价高，客户数量少；一个卖运力，靠降低单位成本扩大市场。前者的天花板是富豪的数量，后者的天花板是轨道运输的总需求。

这个区分很重要。同样是上天，卖体验和卖运力需要的技术路径、定价策略、安全冗余都不一样。后来两家公司的走向也确实分开了。

他说自己是工程师，不是钢铁侠

最后一个问题很轻松。采访者提到，《钢铁侠》的导演乔恩·费儒说过马斯克是灵感来源，他小时候在南非读漫画长大，会不会把自己当成某种超级英雄。

他否认得很干脆：不会。他把自己看作一个工程师，试着造出一些重要的新技术，同时希望它有趣、够酷。

这个回答和整场访谈的调子是一致的。他谈起火率、谈续航里程、谈破产年份、谈发射频次、谈船票价格，没有一句落在愿景口号上。愿景在，但都落到了具体数字上。

这也是这段对话最值得留意的地方。一个在公开场合被反复塑造成"钢铁侠"的人，自己给出的自我描述是"工程师"。工程师的工作方式是：定义问题、拆解指标、面对取舍、接受时间表会延误。

这场访谈能带走什么

  • 看到负面新闻先找分母。Model S 起火率是行业五分之一，报道量却超过50万台汽油车起火的总和。判断风险看发生率和保有量，头条条数说明不了什么。
  • 看一家硬件公司的路线图，先看它有没有把"卖贵的"和"做便宜的"排成先后。没有高毛利产品的现金流，平价产品只是发布会上的口号。
  • 政策承诺对数字。全球新车里电动车不到1%，就算从今年起全部新车电动化，替换20亿台存量车也要20年。任何"全面转型"的说法，都可以拿这两个数对一遍。
  • 判断一项前沿技术是否真在进步，看它有没有在降单位成本。马斯克给火星定的门槛落在票价上，"能不能到"他没当成问题。
  • 区分诚实批评和虚假贬低。前者该接住并改进，后者可以争，但要清楚自己会为此付出情绪成本。
  • 看到"两年后实现"这类时间表，先打个折。SpaceX 2014年说两年后载人，实际是2020年。承诺的方向往往是对的，日期通常是乐观的。
  • 评估一个新兴行业的真实阶段，别用最贵那一款产品的体验下结论。8.5万英镑的配置不代表普及，5万英镑的起售价、三年后的平价车，才是渗透率的分水岭。
