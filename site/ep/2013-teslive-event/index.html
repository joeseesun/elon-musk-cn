2013年夏天，加州弗里蒙特工厂里坐满了几百个特斯拉车主。台上那个人给出的数字是：年化产量两万到两万五千辆。

同一时间，全球路上的汽车存量大约20亿辆，每年新造约1900万辆。按这个速度，把所有燃油车换一遍需要的时间，长到不方便算。

马斯克在这场车主自发组织的聚会上，没有从宏大叙事讲起。他先讲了一张行李箱地毯。

一张墨西哥地毯卡住了整条产线

有人问他，特斯拉会给老车主什么官方推荐激励，怎么建立一个像 PayPal 那样的病毒式增长循环。

马斯克的回答把问题转向了另一边。他说 PayPal 时期确实花了大量时间琢磨这件事，核心有三点：降低购买摩擦、降低推荐摩擦、让推荐人和被推荐人同时得到好处，双向激励才能转起来。

然后他说，特斯拉现在的麻烦不在需求端，在产线。

生产要提上去，整条供应链必须同步走。这辆车有几千个独特零件，哪怕只缺其中几个，我们也没法提产量，因为那样就有人拿到缺零件的车，他们会非常生气。（马斯克）

缺的那几个零件，有时候荒唐到没法解释。

有一批从墨西哥供应商发来的行李箱地毯，卡在边境。边境发生了毒品枪战。马斯克说这件事的时候特意加了一句"我没开玩笑，这是真事"。于是工厂院子里堆满了等着地毯下线的车。

这个细节把汽车制造的真相摊开了：决定产能上限的，往往不是那台最贵的电机，是最便宜的那块布。地毯不会是长期瓶颈，因为谁都能大量生产。但同样的逻辑套到电芯上，麻烦就大了。

真正的天花板是电芯

马斯克判断，未来几年压制特斯拉产量增长的主要因素，是锂离子电芯的产能。

特斯拉当时正在和松下一起扩产。他说得很直白：我们需要非常非常多的电池。

这条判断在后面的问题里反复出现。不管是有人问第三排座椅、问续航、问电动卡车，最后都会绕回同一件事：电池够不够，成本降不降得下来。

不缺汽车公司，缺一个强制函数

开场时马斯克解释了特斯拉存在的理由。

世界上汽车公司已经够多了，再多一家造汽油车的公司没有任何意义。但需要有一家公司去推可持续交通，推到人们能顺着它看到一个明亮的未来。

他说自己本来不觉得需要干这件事。当年通用推出 EV1、丰田推出第一代 RAV4 电动车的时候，他以为方向已经对了，以为通用会做 EV2、EV3，事情会自己走下去。

后来的事是，加州修改了法规，通用召回了所有 EV1，把它们集中在废车场压扁。车主们跑到现场，举着蜡烛守夜。

马斯克说他当时非常震惊。为一个产品办烛光守夜，这种事极其罕见。这说明需求是真实存在的，只是缺一个把事推下去的力量。

所以很清楚，那个强制函数必须来自一家新公司。（马斯克）

这段叙述里藏着一个常被忽略的点：特斯拉不是从"我要造车"开始的，是从"现有玩家在监管松动的一瞬间就撤退"这个观察开始的。

先造跑车再降价，是被逼出来的顺序

第一步是 Roadster。当时外界说，你们造不出一辆既好看、又快、续航又长的车。后来造出来了。外界接着说，没人会买。

那就谢谢各位买了。（马斯克）

他在这里停下来认真道谢。没有早期这批愿意为新公司新产品冒险的人，特斯拉不会存在。

关于为什么第一款车是跑车，他解释过一次，还为此写过一篇博客。有人以为特斯拉成立的动机是"富人缺跑车"，这个理解是错的。第一代技术必然是贵的，产量低，成本摊不开，无论做什么都贵。愿意为昂贵的新技术付钱的人，只有跑车买家。

三步走计划：Roadster 是验证技术可行，Model S 是中等价格中等产量，第三代车是低价格高产量。当时走的正是第二步。

上市公司的镣铐

在进入问答之前，马斯克先打了个招呼：作为一家公众公司，他说的每句话都会被媒体放大解读。这句提醒在后面的回答里体现得很明显，凡涉及未来产品，他的措辞都会收紧一档。

2.5万辆和1900万辆之间

有人问他，未来几年特斯拉最大的挑战是什么。

答案是规模化，以及规模化过程中的组织变形。公司变大之后容易得"大公司病"，变得官僚、僵硬。

他给了一组对照：特斯拉当时的年化产量在两万到两万五千辆，这在汽车工业里是极小的一滴。全球每年生产约1900万辆车，存量约20亿辆。要在这样的基数上完成能源结构切换，需要造出数量级完全不同的电动车。

所以必须大幅扩产，同时不能牺牲产品质量和售后服务。这三件事同时成立，难度就在这里。

传统车厂为什么不动

马斯克原本确信，一旦特斯拉证明"续航长、体验好的电动车有人买"，整个行业会醒悟，跟着转向。

结果并非如此。说实话这挺让人震惊的。（马斯克）

他观察到的行业动作，只做到满足监管最低要求为止。

他的推演是：这些公司只有在感受到竞争压力时才会真正行动。所以特斯拉必须把产量做到足够大，大到传统车厂不得不认真对待。

这里有个容易被误读的地方。马斯克明确说，他宁愿有竞争对手，也不希望特斯拉是唯一一个在推这件事的公司。他做这件事的目的是加速可持续交通的到来，如果别人一起做，目的达成得更快。

Model S 最值得骄傲的地方不是加速

有车主说，你有一屋子专家在这儿，讲点我们不知道的：一个过去没公开的设计决策，一个近期要来的功能。

马斯克的回答落在安全上。

Model S 开发过程中优先级最高的优化目标就是安全。当年在弗里蒙特工厂第一次发布这辆车，他开场就讲安全，放碰撞测试视频，结果现场反应冷淡。之后他就不怎么讲了。

但他认为这是团队最值得骄傲的部分。截至当时，Model S 没有出现过永久性伤害，也没有致死事故。他补了一句理性的话：从统计上看，随着车队规模到几万辆、行驶里程到几亿英里，这个记录大概率保不住。但到目前为止，记录还在。

为了拿到最高的安全评级，车里做了一些妥协设计。

车身和底盘几乎全铝，唯独 B 柱里嵌了一段高强度硼钢。这段钢是为了提升侧碰保护。马斯克说，如果当初把 B 柱设计对了，纯铝就能完成这个任务，结构更简单，也更轻。加上那几颗昂贵的航空级螺栓，他认为这里还有减重和优化的空间。

第三排座椅配的是双保险杠系统：一个铝的，一个钢的。设计门槛是，车在高速上被追尾时，第三排乘客不能出现永久性伤害。

自动驾驶是主动安全的极限

有人问，10年、15年、20年后，电动车、太阳能、自动驾驶、超级高铁这些东西叠加起来，会给社会带来什么实质变化。

马斯克的排序很明确。第一件事是让交通和能源变得可持续。这个说法甚至不需要环保理由支撑：不可持续的东西，随着稀缺加剧，必然导致经济崩溃。这是纯粹的经济问题。

他提到一个带讽刺意味的结论：所有交通方式都要电动化，火箭除外。

我希望火箭能电动，但实在很难绕过牛顿第三定律。（马斯克）

SpaceX 的下一代燃料是甲烷，可以用二氧化碳和水合成。这件事对火星补给同样关键，因为在火星上得就地造燃料。也就是说，太阳能发电、电解水、合成甲烷这条链条，既是地球上的能源解法，也是星际航行的基础设施。

至于自动驾驶，他的定义很克制：自动驾驶本质上就是主动安全的极限延伸。先做好主动巡航、车道偏离预警、路标识别，把主动安全一项项做扎实，做到某个程度，车就能在大部分甚至全部路程上自己开。

这件事特斯拉会在未来几年大力投入，但优先级排在电动化规模化之后。他也提到自动驾驶会改变生活，比如不用再找停车位，还有一些今天很难预判的变化。

最后他把话题拉回碳排放。他说人类正在跑一场疯狂的化学实验，这个实验极难逆转，必须停下来。

太空里没有律师

有人问，SpaceX 和特斯拉，哪个更难搞。

马斯克说这个问题不好答，因为两者的难点性质不同。

太空那头，几乎纯粹是技术挑战。

太空里没有律师。（马斯克）

当然规章还是有的，要满足联邦航空管理局、NASA、空军的要求，如果做过航天飞机相关项目，NASA 的规章体系会非常庞大。但法规在航天里的分量，跟汽车完全不在一个量级。

火箭也没有销售、服务、分销这一整套麻烦。

汽车这头，要应付50个州和几十个国家的规则细节，要应付经销商协会，还要应付一个更根本的事实：产品在用户手里跑，厂商控制不了别人怎么用它。

他的结论是两边都很难，很难说哪个更难。

现场变成了产品需求会

这场问答最有信息量的部分，是车主直接把用车问题丢上台，马斯克当场拍板。有几个决定是明确说"做"的。

事故后的自动响应。一位车主讲了自己的经历：他带着妻子和另一对夫妻出门，被追尾，Model S 保护得很好，没人重伤，对方的宝马 M5 直接报废。他的请求是，车能不能主动识别这种严重碰撞，然后关掉收音机、关掉还在响的警报、在中控屏上弹出快捷操作，比如拨911、进入拖车模式、拉起驻车制动，再给一些保护12V小电瓶的提示，因为他当时慌了神，小电瓶耗尽后整车断电，只能拖走。马斯克当场回应：这个建议不错，我们来做。

代步车被秒卖的问题。服务中心的代步车刚交付就被卖掉，车主修车期间没车可用。马斯克承认利润率太薄，车一卖掉就要尽快交给买家。他给出的解法是压缩代步车的占用时间，服务维修不该超过一两天，车修完就自然循环出去。他同时承诺第三季度开始，每周固定生产一批替换用的代步车，把第二季度那种混乱状态结束掉。

代客泊车限速。有人问能不能限制代客泊车时的车速。马斯克说这个功能车里已经有了，只是没开放给用户，可能年底随更新推出来。原因很具体：软件团队最近大量精力花在欧洲版本的国际化和多语言适配上，功能发布被压后了。

车机里的车主手册。一位车主建议把交付教程和保养提醒做进车机，车自己提示该保养了，弹出附近服务中心的可预约时段，一键预约。马斯克回应得很干脆，说纸质车主手册让他反感，为了一本手册去砍树，哪怕用的是再生纸，而车里明明有一块漂亮的屏幕。他推动把手册放进中控屏。

导航的三个毛病。一位车主列了清单：导航会让人从高速上硬拐进软糖工厂的停车场；交通路况图层缩放后不刷新，一直显示缓存旧数据；希望浏览器和导航打通，在 Yelp 上看到餐厅能一键把地址发到导航；希望能长按地图上某个点直接导航过去。马斯克承认这些都是好建议，也承认车主从预订到交付等得太久，但他说了电动车相对燃油车的一个结构性优势：这些功能推送过来，车主一分钱不用花，某天早上醒来，功能就在车里了。

马上要推的几个功能

马斯克在现场给了软件更新的时间表，一到两个月内：

  • 地图支持"北向上"显示，同时预加载地图瓦片
  • 可以通过手机热点共享网络，手机有 LTE 时能获得更快连接
  • 增加 Wi-Fi 连接能力

续航：500英里能做，但没人愿意付这个钱

有人问续航什么时候能再上一个台阶。马斯克说，如果只盯着续航，今天就能做出500英里续航的 Model S，问题是贵得离谱。

真正要解决的是找到那个平衡点：续航够长，长途出行不焦虑，价格又不至于高到荒唐。

关于节奏，他给了一个关键判断：电池能量密度、成本、续航的阶跃式提升，迭代周期大约是四到五年一次。特斯拉瞄准的是三年左右做出一次阶跃。

顺带更新了充电网络：Harris Ranch 的充电位从一个扩到了十个，充电功率从90千瓦提到120千瓦，正在铺开。

他还想做电动卡车

一位车主在工厂问过这个问题，得到了否定的答复，他又在会上问了一遍：电动皮卡和商用卡车能大幅减碳，什么时候能做。

马斯克的回答是他也想造，而且想清楚了一些技术细节。

卡车最麻烦的地方是载荷差异巨大，空载和满载的重量差太多，悬挂永远调不对，而且错得很离谱。他举了自己的经历：开一辆 F250 在405号公路上，路面的细密接缝引发共振，颠得他牙齿快掉了。空车时是这样，装上货就正常了。

解法是空气悬挂，实时根据载荷调整高度、角度和阻尼。再加上电池包放在底部压低重心，一辆操控好、任何载荷下都开得舒服的卡车是可以做出来的。

Roadster 老车主没有被忘记

一位 Roadster 车主说，大家都理解未来几年的重心在 Model X 和第三代车，但希望还留一点资源照顾最早那批用户，比如超充站的 HPC 适配，或者电池包的升级。

马斯克承诺明年会给 Roadster 车主做点特别的东西，具体不能讲，但他觉得会很酷。前提是今年要先过几道关：欧洲市场导入正在推进，超充网络在铺开，Model X 的设计和工程要在未来六个月里基本完成。

另外有人问 Model S 什么时候有 Hot Wheels 合金车模。马斯克说 Roadster 有，Model S 没有，玩具公司好像只给跑车做。他当场建议：你们给美泰写封信。

3.5万美元的第三代车，本质上是一辆2.5万的车

有人提了一个尖锐的问题：消费电子行业习惯往下打价格，汽车行业反过来，成功的都是往上走，往下走的经常把自己走没了。特斯拉习惯了早期采用者，用户群往下走之后，这些人的容忍度会低很多。加上电池产能的制约，怎么处理这个矛盾。

马斯克的回答是不太在意品牌策略这套东西。

我只是觉得需要造出非常多的电动车，因为我们必须把烧碳氢化合物的车换掉。如果这意味着我们的品牌没那么高端，我不在乎。（马斯克）

关于第三代车的定价，他给了一个算法：车价在3.5万美元左右，把省下的油钱算进去，实际相当于买了一辆两万多美元的燃油车。他还预期油价长期会上涨。

然后他加了一句贯穿全场的话：这件事我们一定会做，成不成功另说，但我们一定会做。

服务部门三个月翻倍

问答后半段，Model S 的项目总监 Jerome Guillen 上台。他三年前加入特斯拉，4月1日到岗，马斯克给他的任务是接管服务组织。

他说，把它做成最好的，让人们开心，别担心成本。（Jerome Guillen）

他的做法很具体。

服务组织在三个月里人数翻了一倍。他提到去年负责工程时，团队一年增长50%，当时觉得已经很夸张，现在三个月翻倍。4月招人极难，到7月容易多了，很多来自口碑极好的服务体系的技师主动来投，想围绕这个使命做事。

几个主要服务中心已经改成一星期七天营业，营业时间还会根据需要继续延长。

每天下午5点，他和工程师、区域经理一起复盘当天的所有服务案例。会上那位在 Harris Ranch 被卡住的车主被点了名，这件事当晚就会被讨论：为什么会出现，为什么必须重启设备才能充上电。他们的判定标准是，任何让车主无法出发的事件都属于最高优先级，不仅要解决，还要找到根因。

关于供应链和第三方对特斯拉的态度，Jerome 的回答比较克制，因为上市公司信息披露的限制。他说能讲的是招人变容易了，路上跑的车多了，公司更成功了，这些都在帮忙。其他的合作方，大概也有同样的光环效应。

几句值得记住的话

现场有位车主说，Model S 是他买过的最好的产品之一。也有人专程从新墨西哥州带了礼物来，说自己很长一段时间觉得没有未来，是这家公司给了他未来。

如果你也在做硬件产品，这场问答里有几条可以直接拿走

  • 先算清楚你的瓶颈在哪一端。马斯克直接拒绝了"做病毒增长"的提议，因为需求不是约束，产能才是。把增长引擎装在一个已经满负荷的产线上，只会制造交付事故。先诊断，再投入。
  • 把供应链拆到最小颗粒度去找风险。几千个零件里，只要一个缺货整条线就停。真正需要盘点的，是那些单一来源、低价值、容易被忽视的小件，它们最容易在没人注意的地方断掉。
  • 第一代产品定高价不是贪心，是数学。低产量摊不开成本，只有能接受溢价的那群人愿意付钱。想清楚第一代卖给谁，比想清楚第一代卖多少钱更重要。
  • 把用户现场提的需求当场分类。能做的当场说做，做不了的说明卡在哪。这场问答里被马斯克当场拍板的事故自动响应、车机手册、代客限速，都是低成本高感知的功能。
  • 建立每日复盘机制。Jerome 的做法值得抄：每天固定时间，工程和服务负责人一起过一遍当天的故障案例，判定标准是"任何让用户无法使用的事件都算最高优先级"，要求追到根因，不满足于修复。
  • 对用户坦诚你的排序。马斯克反复说自动驾驶优先级低于电动化规模化，续航提升要等到下一次电池阶跃，代步车会被卖掉是因为利润率太薄。把取舍讲清楚，比承诺做不到的事更能留住用户。
  • 把纸质的东西搬进屏幕。车主手册、交付教程、保养提醒、预约入口，这些完全可以由产品自己完成，省下的是人力，得到的是体验的一致性。
