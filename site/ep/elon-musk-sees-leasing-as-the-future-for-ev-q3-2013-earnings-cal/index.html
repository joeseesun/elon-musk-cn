马斯克认为租赁是电动车未来——Q3 2013 财报电话会

2013年11月5日下午，特斯拉第三季度财报电话会。一位分析师抛出一个尖锐的问题：北美交付量从二季度到三季度环比掉了650辆，是不是最早那批尝鲜的订单已经消化完了，需求见顶了？

马斯克的回答几乎是打断式的：北美三季度的预订量比二季度还涨了。交付少，跟需求没有关系。

这句话背后是当时特斯拉最拧巴的状态：它在主动压制一个市场的需求，去喂另一个市场。欧洲有一批客户已经等了两三年，公司不得不把北美的交付量卡住，先让那些人拿到车。

整场电话会里，马斯克反复回到同一个判断：特斯拉受限于产能，跟需求没关系。这跟传统车厂的处境正好相反。车厂通常最怕工厂空转，所以拼命促销、给补贴、压库存。特斯拉当时的情况是产能跟不上，促销只会制造更多拿不到车的人。

把这场一个多小时的问答拆开看，马斯克讲清楚了几件事：电池是唯一的硬瓶颈，超级电池工厂必须建，租赁会成为电动车的主流购买方式，第三代车的定价逻辑跟油车怎么算账，以及为什么2014年之前不该把销售版图铺得太快。

先把北美订单停下，去喂等了三年的人

电话会上有人问欧洲的进展。马斯克的回答很直接：欧洲现在还处在很早期的阶段，大概相当于美国当年的一月或二月。

但数据对比很硬。第二季度特斯拉在欧洲交付了零辆车，第三季度交付超过一千辆，最早一批车在八月初交到客户手上。两个月时间，从零到一千。

这中间隔着的是物流。特斯拉的车在加州弗里蒙特工厂造出来，不会整车直接上船，而是先做成半散件状态，运到荷兰蒂尔堡的组装厂，在那里完成总装和最终检查，再分发到欧洲十几个国家。马斯克说，从一辆车在加州下线到客户手里，大概要六到七周。

再加上订单积压，一位今天下单的欧洲客户，等待时间是三到四个月。

蒂尔堡的工厂在十月刚刚追加了投资，增加了产线能力。马斯克承认早期的物流确实有挑战，但现在基本捋顺了。

欧洲还有一层麻烦是电网。马斯克说，几乎每个国家的电网都有自己的小脾气，你作为消费者看到的是满世界五花八门的插头，特斯拉遇到的是同样的问题。挪威是当时人均销量最高的市场之一，但它的电网结构比较特殊，工程团队花了不少力气才确保车能在那里正常充电。

还有一个细节值得记下来。荷兰当时有一项税收抵免政策面临到期，还没确认续期。特斯拉做了个判断：如果政策真的不续，客户就亏了，所以优先把交付量往荷兰倾斜，让人赶在截止日前拿到车。后来政策续了，虚惊一场，但这个决策顺序说明了公司当时怎么排优先级。

北美这边，马斯克给的数字是：一年两万辆的规模可以撑住，甚至可能更多。欧洲大概是一万辆一年。他补了一句，如果不去主动压制，北美的需求还能更高，但那没有意义，交不出车只会让人不高兴。

真正的瓶颈是电芯，不是车

整场电话会里，电池被提到的次数远超其他任何话题。马斯克说得很清楚：产能的主要约束是电芯，其他所有非电芯的约束加起来都没这个关键。

特斯拉当时跟松下签了一份扩大供货的协议，四年 18 亿颗电芯。有分析师当场做了个心算：如果按 85 千瓦时的大电池算，这大概对应 20 万辆车。

马斯克的回应有点意思。他说别这么算，因为这 18 亿颗的分布是前少后多，越到后面年份对应的车越多。而且这份协议只是保底，后面还得再签。

他还提到一个当时外界猜测很多的事：三星也在接触。马斯克没有否认，只说松下车是主要伙伴，但面向高销量的第三代车，全球现有的锂电产能根本不够，必须凭空造出新的产能。

那个后来被反复引用的词就是这么来的：Gigafactory，超级电池工厂。

一座厂，等于今天全世界的锂电池产能

有分析师问，你们是不是考虑自己建电芯厂。马斯克说还没到正式宣布的时候，但可以聊聊思路。

他给的判断是：最可能的方案是建一座从原材料进厂一直到成品电池包出厂的完整工厂，跟合作伙伴一起做，地点大概率在北美，但也在看其他地方。

规模有多大？马斯克的原话是，相当于把今天全世界所有的锂电池生产塞进一个厂里。

这句话听起来夸张，但对照他说的另一个数字就合理了：如果要在原 NUMMI 工厂（现在的弗里蒙特工厂）做到年产 50 万辆，需要的电芯产能跟今天全球锂电总产量在同一个量级。

关于这座厂，马斯克讲了几个设计上的想法。

第一，审批不会是障碍。他说这会是一座非常绿色的工厂，大量用太阳能，基本上零排放，没有有毒物质流出。

第二，回收能力会直接建在工厂里。旧电池包从一头进去，另一头出来的是新电池包。

第三，也是最容易被忽略的一点，他把工厂本身当成一个产品来看。工厂是造机器的机器，机器有版本，工厂也有版本。所以团队在琢磨的是，这座超级工厂的 version 1 应该怎么设计。

原材料这块，马斯克说不用担心。锂的供应不是问题，全球储量很多。一颗电芯按重量算，主要成分是铝、镍、钴，锂大概只占电芯质量的百分之一到二。他还补了一句玩笑：电池包里质量占比最大的其实是铝壳。

他认为租赁才是电动车的归宿

整场电话会里，马斯克讲得最像布道的一段在租赁这个话题上。

有位分析师问，Model S 的动力总成成本已经跟传统豪华车差不多了，电池成本还在往下走，第三代车你们是继续溢价卖，还是平价卖，让客户从油费里赚回差价？

马斯克先给了定价锚点：第三代车目标价三点五万美元。然后他开始算账。考虑到当时美国的油价，这个价格相当于买一辆两万八千美元的油车；在欧洲，相当于两万两千美元。

接下来他抛出了核心观点：电动车应该以租赁为主，就像 SolarCity 做太阳能那样。

逻辑是这样的。买油车，你每个月付的是油钱加保养钱，油车天然需要更多维护。买电动车，你每个月付的是电费。如果采用租赁，客户不需要去操心「我开了五年省下的油钱能不能补回买车的溢价」，也不需要担心电池衰减和残值。每个月两张账单直接对比，省下来的钱当月就能感受到。

马斯克说，随着特斯拉的信用记录变好、残值数据变清晰，租赁的利率会越来越低，融资成本也会更低。他判断，长期看租赁会成为人们买特斯拉的主要方式。

这段话放在 2013 年看，是有前瞻性的。当时电动车的残值是个巨大的未知数，二手车市场几乎不给估值，租赁正好绕开了这个不确定性。

第四季度毛利率 25%，靠的是把积分剔干净

财报电话会的硬指标部分，马斯克给得比较干脆。

第四季度毛利率目标是 25%，前提是不计算零排放车辆积分（ZEV credits）的收入。他说这话的时候第四季度已经过了差不多一半，所以信心比较足，除非出现不可抗力。

有分析师追问积分到底贡献了多少。CFO 的回答是：影响很小，而且每个季度都在下降，这一季大概就一个百分点左右。

另一个被问到的是供应商返利。市场上有些传闻说特斯拉拿到了供应商的一次性补偿。马斯克直接否了：没有这回事，那一季的账很干净。

成本端还有一个改善被提到：单车人工成本在持续下降，加班时间在减少。马斯克说得很实在，工厂里能塞下的人数是有限的，所以人均产出必须提上去，否则产量根本上不来。接下来几个季度，员工总数还会涨，但每辆车对应的人头数会明显改善。

现金流：一边高速扩张，一边想挤出正数

第三季度特斯拉自由现金流是正两千六百万美元。全年算下来，预计净流出五千万左右。

有分析师问 2014 年的现金流怎么规划。CFO 说具体指引留到下次电话会，但目标很明确：用经营现金流去覆盖尽可能多的资本开支，最好是全部覆盖。

马斯克补充了思路。他说公司想做的事情是，在保持远高于行业平均的增速的同时，让手上现金有稳定的、小幅的改善。这两件事同时做到，就是很好的结果。

他拿第三季度举例：在全球铺了那么多基础设施、投了那么多增长，还能有正的现金流，这一季算是相当不错。

基础设施里最烧钱的是超级充电网络。目标是明年底把北美全部覆盖到位，一些高频路线会做双重甚至三重覆盖；欧洲这边，西欧基本覆盖，东欧的很多地方也能到。这些投入都发生在 2014 年，同时还要扩产、还要开发 Model X，即便这样，马斯克仍认为公司可以保持正现金流。

中国：软开业、过了认证、第一季度交车

有分析师提到当天早上北京市宣布的新政策：明年新增牌照里，大约 15% 留给电动车和插电混动，也就是两万个，到 2017 年这个数字会到六万。

问题是，进口车能不能算。

马斯克的回答是：特斯拉是纯电动车，应该符合条件。北京的门店已经做了软开业，交付预计在第一季度，二月或者三月。中国的认证流程已经全部走完，等于是拿到了监管层面的通行证。第一批车预计一月上船，二月到港。

他特别强调「软开业」这个词的含义：没有大张旗鼓地推广，基本上就是开门营业而已。即便这样，初期需求已经不错。

但他同时明确，不打算快速扩张销售版图。原因还是那个：产能受限的时候，把销售范围铺太开，只会把问题放大。所以第一季度的目标是把车送进中国、把服务体系铺好，为后面几个月的增长打地基。

有人问中国客户现在下单要等多久。马斯克的回答是「久得离谱」，建议想买的人尽早下单，因为等待时间看起来还在拉长。

关于电芯尺寸的一个反常识判断

有位分析师问了一个技术问题：自己建厂之后，是不是就不用再迁就 18650 这个规格了，可以换更紧凑、更简单的形态？

马斯克的回答很干脆。18650 指的是直径 18 毫米、长度 65 毫米，这个尺寸凑巧在工程上很合适。如果没有特别的优化理由，没必要换。就算换，也不会离这个尺寸太远。

接着他说了一句当时很多人不爱听的话：「电芯做得更大就更便宜」，这是个误解。特斯拉的经验里，还没有见过哪种大尺寸车用电芯在每千瓦时成本上真的更便宜。

关于技术进步节奏，他给了一个大概的周期：电池包和电芯技术在四年左右会有一次有意义的台阶式提升。特斯拉一年半前才重启生产，所以再过两年左右应该会有一次明显变化，中间可能有些小改。关键是，这次台阶必须赶上第三代车。赶上了，Model S 这些高价车型也能跟着受益。

他还提到，特斯拉在电芯优化上出力不少。外观上看电芯几乎没变，直径可能从 18.0 变成 18.3、18.4 毫米这种微小差异，但内部结构变化很大。这些工作主要跟松下一起做，马斯克评价松下的新一代电芯化学体系「管道里有让人兴奋的东西」。

Model X、戴姆勒和那辆撞穿墙的车

Model X 的时间表在这次会上被问了好几次。马斯克的回答是：明年年底可能有少量车交付，真正的高量产要到 2015 年。到那个阶段，Model X 的产量应该跟当时的 Model S 在一个量级，同时 Model S 的产量还要维持在高位。他承认这个量级意味着产能需要重新配置，可能在工厂里划出一块区域，用上 NUMMI 时代留下来的某条产线。

第三代车的设计工作，2014 年会正式启动。Model X 的造型在这几个月内就能定稿，之后设计资源会转到 Gen 3 上。

戴姆勒的合作也被提到。特斯拉会为奔驰 B 级电动版提供动力总成，马斯克说这是戴姆勒历史上最大的电动车项目，他认为这会是市面上最有竞争力的、买得起的电动车之一。

电话会快结束时，一位分析师问起马斯克之前说过的全家横跨美国的自驾计划。他说原定圣诞假期，但考虑到那条路线冬天日照最短、大部分时间在天黑开车，孩子可能玩得不开心，改到三月春假。

然后他讲了一件跟安全有关的事。有一辆 Model S 先冲过大约 17 英尺的路障，撞穿一堵厚实的混凝土墙，最后又撞上一棵树，车里的人没事。马斯克说这辆车的结实程度「像坦克一样」，实际情形比这个描述还要夸张。

这场电话会真正在说什么

把整场问答串起来，马斯克其实在解释一个跟当时主流叙事不太一样的公司形态。

传统车厂的瓶颈在需求端，工厂建好了就要想办法把车卖出去，所以有经销商库存、有促销、有季度冲量。特斯拉当时的瓶颈在供给端，电芯不够，工厂产能不够，物流通道不够。所以它的所有动作都指向同一个方向：把有限的产能投到最能建立长期优势的地方，而不是投到短期销量上。

这也解释了为什么它在需求最旺的北美主动踩刹车，为什么在中国只做软开业，为什么把交付优先给税收抵免要过期的荷兰客户。每一个看起来反商业的决定，背后都是同一个约束条件在起作用。

而解开这个约束的钥匙，马斯克认为不在车厂里，在一座当时还不存在的工厂里。

至于租赁，那是他对需求端的长期判断。电动车要让普通人算得过账，最直接的办法是把两张月账单摆在桌上，让人一眼看出哪个便宜。环保、加速性能、科技感这些卖点，在月供数字面前的说服力有限。租赁做的就是这件事。

这场电话会开完，特斯拉的股价在随后一段时间里继续走高。但今天读这段记录，更有价值的可能是那些当时听起来像远景规划、后来一条条兑现的判断：电芯是瓶颈、超级工厂必须建、租赁会成为主流、更大的电芯不一定更便宜。

这些判断在当时没什么人认同。

  • 评估一家高速增长的公司，先搞清楚它受限于供给还是需求。受限于供给的公司，短期销量下滑往往不是坏事，可能只是产能被调去了更该去的地方。看订单和预订量，别只看交付量。
  • 看财报时把一次性收入剔掉再看。特斯拉给的 25% 毛利率目标是明确不含 ZEV 积分的。补贴、积分、供应商返利这类东西会掩盖真实的盈利能力，剔掉之后才知道生意本身赚不赚钱。
  • 判断一个新技术能不能普及，看它的成本优势能不能当月结算。电动车的油费节省是每个月都在发生的，买车的溢价却是一次性付出的，这两笔账在时间上错位，消费者就算不清。租赁、分期、订阅这类金融工具的价值，就是把错位的账拉平。评估任何新产品的普及速度时，先看它的省钱效应是不是即时可感知。
  • 别默认「更大的零件更便宜」。工程直觉里常见的陷阱。特斯拉的经验是大尺寸车用电芯在每千瓦时成本上并不更便宜。遇到类似的技术选型判断，去查实际的单位成本数据，别靠直觉。
  • 看一家公司怎么排优先级，比听它怎么讲战略更准。荷兰税收抵免可能到期，特斯拉就把交付往那儿倾斜；产能不够，就停掉北美的推广。这些动作比任何战略 PPT 都更能说明它真正在乎什么。
