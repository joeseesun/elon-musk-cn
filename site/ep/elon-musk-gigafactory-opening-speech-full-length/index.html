要造五十万辆车，得先拥有全世界所有的电池工厂。这是2016年特斯拉算出来的一笔账，算完发现，这笔账根本算不通。

那一年，全球所有生产锂电池的工厂加在一起，产能差不多刚好够五十万辆电动车。手机、笔记本、相机、电动工具，全世界这些产线全算上，才勉强够一个汽车项目。

麻烦的地方在于，这样的工厂群在卫星照片上找不到。

基本数学是这样的：一年造五十万辆车，需要地球上每一家锂电池工厂，做手机电池的、做笔记本电池的、做汽车电池的，全部加起来才够。那显然这些东西没有被建出来，因为如果建了，你在卫星图上就能看见。所以要么我们想办法把这东西盖出来，要么就没有那些车。（马斯克）

2016年7月29日，内华达州斯帕克斯（Sparks），Gigafactory 1 的开业派对。马斯克和联合创始人 JB Straubel 站在一座还在施工的厂房里，面对几千人讲了一个多小时。整场活动没什么剪彩的仪式感，大部分时间在讲工厂怎么设计、物理公式怎么用在产线上、一个分子从矿山到成品车要走多少路。

这场演讲值得逐段拆开看。它讲的是一座厂房，但真正在讲的是制造业里一个被忽略很久的问题：为什么大多数工厂的建造方式，本质上和复印机没有区别。

你眼前看到的建筑，只占完工后的百分之十四

派对现场的那个空间，已经能装下几千人开演唱会。马斯克说，这只是最终建筑的百分之十四左右。

更夸张的是产能和面积的关系。相比最初的设计方案，这座工厂的产出能力提高了三倍。同样的占地面积，塞进去三倍的东西。按他的说法，最终这座工厂会做到大约 150 GWh（吉瓦时）的年产能。

150 GWh 这个数字单独看没什么感觉。换个参照：2014年全球锂电池总产量，所有用途加起来，大约是 30 GWh。

他家一个厂的规划产能，是全球总产量的五倍。

把工厂当成产品来设计，这句话听起来像口号，实际是整套方法论的地基

演讲里马斯克反复回到一个概念：工厂是一台造机器的机器（the machine that builds the machine）。

他觉得大部分人看工厂的方式是错的。工厂被当成一件无聊的事，像复印文件，像照目录采购。这家公司买一台设备，那家公司买一台，买回来往厂房里一摆，接上电，开工。

如果你用这套逻辑去设计产品，会显得很荒谬。造 Model S 的时候，从本田拿个保险杠，从这家拿个方向盘，从那家拿个电机，拼起来，那会像一台凯美瑞。（马斯克）

现场笑了。但这段话的推论很硬：既然造车要从零开始做整车设计，造工厂凭什么可以照抄目录？

Straubel 补了一句更具体的：特斯拉最好的几支工程团队里，有一部分人的工作就是排工厂布局，研究怎么在同样的占地面积里塞进更高的设备密度。电池成本能降下来，靠的就是这个。

这不是一台复印机，不是把别人做过的事情复制一遍。我们是在端到端地重新发明电池制造流程。（JB Straubel）

这套说法在2016年听起来有点自我感动。两年后回看，它反而被验证了，只是验证的方向和马斯克当时想的不一样。2018年 Model 3 产能爬坡卡住，他公开承认过度自动化是个错误，人来干那些活更好。工厂是产品这个判断没错，错在他一度以为这台产品可以接近无人化。

物理是唯一不会辩输的东西，所以用它来算工厂

马斯克在演讲里给了一个判断标准：物理是真的，其他一切都可以争论。

他把这个框架直接套到产线上，拆成两个变量。

一个是密度。工厂的根本效率，是有用的东西占总体积的比例。厂房里有多少空间真的在生产，多少空间在当仓库、当过道、当缓冲区。

另一个是流速。工厂的产出，等于产品穿过工厂的速度。

两个变量乘起来就是产能。他据此判断，这座工厂的生产能力还有至少五倍、可能十倍以上的提升空间。

这个框架听起来简单到不像话，但它解释了后面所有的设计决策。为什么整座工厂要在 CAD 里一个零件一个零件地画完，为什么设备之间几乎要贴在一起，为什么不能先盖个壳子再往里塞东西。

每根管道、每段电缆桥架，都在模型里

演讲中间，屏幕上放了一张图，是整座工厂的 CAD 模型。

不是建筑效果图，是施工级的模型。每一根管道、每一段电气线管、每一台设备的安装位置，全在里面。设备与设备之间几乎彼此接触，每一层楼都在追求最小的浪费空间。

很多工厂不是这么建的。你先盖一个壳子，然后把设备随机往里一放，就这样。这里完全不同。（马斯克）

Straubel 用的类比是芯片：这座工厂的设计思路，像一颗高密度、多层布线的先进 CPU。

马斯克接着往下推了一步，说未来制造业的样子会更接近高速贴片机（pick and place machine），在速度和密度上被极致优化。

他还顺手怼了一句当时流行的想象：手机和笔记本变强，靠的是提高运算速度和集成密度，从来不是造一台桌子那么大的电脑。制造业也是一个道理。

一个分子绕地球三圈，成本就没了

这座工厂做的另一件事是垂直整合。从最基础的原材料，一路做到成品电池包，全在一个屋顶下。

过去这是三段路。材料在一个地方提炼，电芯在另一个地方制造，电池包在第三个地方组装，中间隔着几趟洲际运输。

马斯克给了一个衡量制造成本的角度，全场最有洞察力的一句：

衡量制造效率的一个方法是看这个分子走了多远。如果它在一个地方被开采出来，运到地球另一边加工，再运回另一半加工，最后才进成品，中间绕了世界好几圈，那它必然很贵。你不能指望让东西绕着地球旅行还能便宜。（马斯克）

所以他给出的终局画面很朴素：一边是装满原材料的火车皮开进来，另一边是成品车开出去。

当时特斯拉的布局还是分开的，整车厂在加州弗里蒙特，电池厂在内华达。他说从 Gigafactory 2 开始，这两个东西要合到一个设施里。

六百多万平方英尺，能停一百架 747

为了让现场的人对规模有概念，马斯克给了几个换算。

这座建筑的占地面积大约六百万平方英尺，差不多五十六万平方米。按占地面积算，它会是世界上最大的单体建筑，体积上仅次于波音在华盛顿州的那个厂房。

能塞下大约一百架 747 客机。

他说到这里停了一下，又加了一句：还能塞下五百亿只仓鼠。

现场笑声很大。这个数字当然没意义，但它起到了作用，让一座抽象的巨大厂房变成了能被人脑处理的东西。

2014年全世界做了三十吉瓦时，这一个厂就要做五十

产能的时间表是这样的。

两年后，也就是2018年，做到每年 50 GWh 的输出。

2020年全部建成，做到 150 GWh 左右，够支撑一百五十万辆车，外加大量固定式储能电池包。

他把 50 GWh 这个数字和全球产量放在一起对比：2014年全世界所有锂电池产量约 30 GWh。也就是说，这一个工厂的产量，大致等于地球上其他所有地方的产量之和。

需要说明的是，这个时间表后来没有兑现。内华达工厂的产能爬升比规划慢了不少，150 GWh 是很多年以后才接近的数字。2016年那个派对上的乐观，事后看至少超前了好几年。但方向没有变，全球电池产能确实在随后几年里被这座工厂的示范效应推着往上走了好几倍。

Model 3 的结果，把时间表整体提前了两年

演讲里有个细节值得留意。他说 Model 3 的反响远超预期，五十万辆的年产目标被提前了整整两年，所以明年这座建筑的面积几乎要翻一倍。

这里有个背景：这座工厂是在 Model 3 发布和预订之前就动工的。没有订单数据，没有市场需求验证，先砸钱建产能。

很多人怀疑需求够不够撑起这样一座工厂。我们在 Model 3 发布之前、在那些预订数字出现之前就开始动工了。这件事能成，功劳在你们这些客户身上。（马斯克）

这是整场演讲里他少有地把话说得比较软的地方。一家制造企业押注需求曲线，赌注是一百多亿美元级别的资本开支，赌的方式是在需求出现之前先建供给。

材料一直都在，所以回收是一笔划算的账

现场有人问电池回收，马斯克说回收会放在这座工厂内部做。

理由很实在：因为回收的是自己设计的电池包，知道模组长什么样，可以造出专门针对这一种电池包的回收机器。回收一个已知的电池包，可以做到非常精确；回收一个随便什么电池包，效率就上不去。

他接着讲了一段大多数人确实没想过的东西。

一块锂电池，就算你用了十五二十年，到期那天，当初装进去的所有材料都还在里面，一点都没散到环境里去，也没被烧掉。所有金属、所有有价值的材料都还在。而今天做一块新电池，材料是最贵的那部分。如果我们能把同一批材料几乎零成本地送回工厂，整个材料预算就能大幅下降。（马斯克）

这段话说的是电池和石油的根本差别。石油烧掉就没了，锂一直在。这是后面他反驳"锂资源枯竭论"的伏笔。

地热、风电、屋顶光伏，工厂自己给自己供能

他还提了一句：这座工厂全部建成后，运行会完全依靠可持续能源。

三种来源。地热用于温度控制，风电从别处输过来，屋顶铺太阳能。三者组合起来，供给整座工厂。

这个细节在演讲里一带而过，但它和前面的回收逻辑是同一套思路：尽量把一个东西的全生命周期成本关进自己可控的边界里。

每个大洲都得有一个，因为运输本身就是成本

有人问会不会在欧洲建厂。马斯克的回答比问题更进一步：

每个大洲至少需要一个 Gigafactory。原因还是那个分子走多远的逻辑，把车运半个地球的物流成本和能源消耗太高了。

他的排序是，先把内华达做饱和，然后在欧洲建一个，在亚洲建一个（中国），也许再考虑其他地区。本地化生产，去匹配本地的需求。

回头看，这个判断准得有点意外。上海工厂2019年动工、当年投产，柏林工厂落在欧洲。八年后的全球电池和电动车格局，基本就是沿着这几句话铺开的。

初期三分之一的电池给储能，长期大致对半

有人问产能怎么在车用和储能之间分配。

马斯克说初期大约三分之一给固定式储能，百分之三十到三十五，随着时间推移两者会大致持平。

他给的理由是从能源转型的总账倒推：如果算全球转向可持续能源需要多少电池容量，车用和储能的需求量级差不多。

这个比例判断在当时看有点激进，因为2016年的储能市场还很小。但 Powerwall 和 Powerpack 当时已经在这座工厂里生产了。

第二部分总体规划：四件事，一句话一件

演讲里他提到了"特斯拉总体规划第二部分"，还开了个玩笑说没多少人看过《反斗神鹰2》（Hot Shots! Part Deux），所以这个第二部分基本是保密的。现场笑了一下，然后他讲了四件事。

  1. 太阳能加储能。做漂亮的太阳能屋顶，配上电池。
  2. 覆盖所有主要车型细分市场。目的是尽快把世界从石油上挪开。
  3. 做到比普通司机好十倍的自动驾驶能力。他给的理由是每年有120万人死于交通事故，这里面能救的命太多了。
  4. 让你的车加入共享车队。不用车的时候，在手机上点一下特斯拉 App，就能把车加进共享车队，也能随时撤出来。可以设定使用权限，只给五星用户、给任何人、或者只给家人。想收回的时候再点一下，车自己开回来。

关于第四条，他的观察是：大部分车一天里绝大多数时间都停在某个停车场里，完全没被使用。共享能大幅提高一辆车的使用效率，也能摊薄拥有一辆车的成本。

现场有人喊了一句 Pokemon Go，马斯克接了个梗，说可以让车去帮你抓精灵。这是他整场演讲里唯一一次顺着玩笑往下走。

锂是宇宙里第三多的元素，储量从来不是问题

提问环节有人问锂的供应。马斯克的回答可以单独拿出来当科普看。

锂是宇宙中第三常见的元素，排在前面的两个是氢和氦。氢在地球上都被锁在水和碳氢化合物里，找不到游离态；氦是惰性气体，不跟任何东西结合，基本上飘走了。

锂是金属，不会飘走。

所以任何含盐的溶液里都有锂，海洋里锂的总量极大。任何一个干涸的古盐湖床里也有大量锂。世界上锂的实际储量，远远超过交通电动化所需要的量。

他还补充了一个常被误读的点：锂只占一块电池大约百分之二的成分。名字叫锂离子电池，锂是活性成分，但重量占比很小。

所谓"锂峰值"，纯属胡说八道。因为一旦这些电动车被造出来，你就不需要更多锂了，你可以一直重复使用、反复加工，永远用下去。（马斯克）

这个逻辑和石油确实不同。石油是一次性消耗品，采一桶少一桶。锂是循环使用的功能材料，用完了还能回炉。

不做燃料电池，下一个重点是紧凑型 SUV

关于产品线，他说得很克制。短期不会做燃料电池，因为必须保持专注，尤其是 Model 3 这个阶段。

下一个优先项是紧凑型 SUV。再往下，他们有个挺有意思的想法，在 Model X 的平台上做一个小巴那样的车。他说如果你把 Model X 做得像个小巴士，能装下的人会多得让人意外。

然后他讲了专注这件事，语气比前面都严肃：

专注极其重要，因为能做的事太多了。但如果我们不专注，风险就是最后一件事都做不成。（马斯克）

还有人问下一代 Roadster。他说很想做，但那属于甜点，现在得先做买得起的大众市场车型。

对面有一千倍的钱，所以这场变化只能从人这里来

演讲快结束时，有人问普通人能帮上什么忙。马斯克的回答把话题拉到了化石燃料行业的舆论战上。

你们觉得这件事是真的，但外面有很多人不这么觉得，这让我很震惊。化石燃料行业有一场不间断的宣传攻势，他们只是在保卫自己，这可以理解，但那场攻势从不停。他们的钱比我们多一千倍。这场变革只能从人民这里来。（马斯克）

他还预判美国大选期间这类宣传会变得很疯狂。

这段话放到今天看，比2016年更成立。能源转型这些年最大的阻力从来不在技术侧，在叙事侧。

一些顺带说出的判断

提问环节还散落着几个短判断，都值得记下来。

工厂现在的员工规模大约一千人，扩产到 150 GWh 之后，大概会到一万人左右。

所有陆路运输最终都会电动化。特斯拉目前不打算做船，但如果没人做，他们会做。

Model 3 的设计在演讲前几周刚完成。他提到这已经是第三代产品，很多部件和系统是从 Roadster、Model S、Model X 一路迭代过来的，所以团队心里有底。

关于火星，他在开场时提了一句，电动车在火星上会很合适。这是全场最轻的一句，但也埋着后面十年的走向。

这场演讲真正在讲什么

如果只看数字，这是一场产能发布会。150 GWh、五十万辆、六百万平方英尺、一万人。

但它真正的价值在方法层面。马斯克在这次演讲里提出了一个可以迁移到任何制造业场景的思考方式：

把工厂当产品设计，用物理学而不是会计学来衡量它。密度和流速是两个变量，密度决定效率上限，流速决定产出速度。所有关于 CAD 建模、垂直整合、设备紧贴、原料一端进成品一端出的决策，都是这两个变量推出来的结论。

第二个可以带走的东西是那个"分子走了多远"的衡量标准。任何一个制造业企业，只要画一遍自己产品的物料路径，几乎一定能找到成本被运输吃掉的地方。这个动作不需要任何新技术，只需要一张地图。

第三个是他对锂的判断。储量不构成约束，回收才是终局，因为电池里的材料从来不会消失。这个视角能帮人一眼看穿很多关于资源枯竭的恐慌叙事。

至于那些没兑现的时间表，2018年的 50 GWh 没到，2020年的 150 GWh 也没到。这次演讲里最该被记住的教训恰好就在这儿：他判断对了工厂的重要性，却在自动化程度上高估了机器、低估了人。

如果你在做制造业或者能源相关的生意，可以从这里带走几件事

  • 把你的工厂或产线画一遍完整模型。不用等到要建新厂，现有的产线也画。每一台设备、每一段物流路径、每一个缓冲区的位置都标出来，然后算一下有用空间占总体积的比例。这个数字大多数企业不敢算，一算就知道钱漏在哪。
  • 算一遍你产品的分子旅行距离。原材料从哪来，中间经过几个地方，每段运输的成本和能耗是多少。垂直整合的机会往往就藏在这条路径上最长的两段之间。
  • 把"密度"和"流速"当成两个独立的 KPI 来管。密度对应单位面积或单位体积的产出能力，流速对应产品穿过整个流程的时间。这两个指标改善的空间通常比想象中大得多，而且不需要买新设备。
  • 如果你在做电池、光伏或者储能相关的事，把回收当成设计环节而不是环保环节。产品设计阶段就决定好了它将来好不好拆、好不好回收。设计时多花的心思，会在材料成本上还回来。
  • 在需求被验证之前建产能是高风险的押注，只在一种情况下成立：供给本身就是需求的瓶颈，而且你能把单位成本做到别人做不到的位置。判断清楚自己是不是处在这种局面，再决定要不要学这一套。
  • 别低估人的作用。这家公司在2018年用惨痛的代价学到了这一课。自动化能解决重复劳动，解决不了柔性装配和异常处理。产线设计时给人留出位置，通常比全自动方案更快、更便宜、更容易改。
