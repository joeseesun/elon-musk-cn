Tesla Model 3交付活动：马斯克演讲（2017年7月，4K）

2017年7月28日，加州弗里蒙特工厂外面搭起了台子。特斯拉要交付第一批Model 3，一共30辆，车主大半是自家员工。

按行业惯例，这种夜晚应该说漂亮话。马斯克上台说的却是另一套：接下来至少六个月，欢迎来到生产地狱。

有句话是这么说的，如果你正在穿越地狱，那就继续往前走。（马斯克）

他把这句话当成祝福送给台下的工程师。一场本该庆功的发布会，被他讲成了施工动员会。想弄明白他为什么这么说，得先看这台车到底难在哪里。

墙上那幅画没有屏幕，是车头灯投出来的

先上台的是设计总监弗朗茨·冯·霍尔茨豪森（Franz von Holzhausen）。他说自己等这一刻等了很久，然后感谢了弗里蒙特工厂的员工、Gigafactory的同事、全球各地的特斯拉员工，还有在线上看直播的人。他说没有这些人，这事根本做不成。

讲完他往旁边一站，让观众把注意力放到身后那面墙。

墙上出现了一台Model 3的影像，线条清晰，尺寸巨大。马斯克接过话，专门解释了这个画面的来源：那不是一块屏幕，那面墙就是工厂本身的一部分，画面是Model 3自己的车头灯投射上去的，没有布线，没有外接电源。他还提醒线上观众，注意画面里出现的人，那些人不是演员，就是工厂里的工程师。

这个开场的设计意图很清楚。一台车的灯能当投影仪用，说明它的电控和光源做得足够精细。他把工程能力当成舞台效果来展示，比任何参数表都直观。

仪表盘消失的理由：车以后自己开

Model 3内饰最扎眼的地方，是传统仪表盘没了，所有信息集中在中间一块横屏上。

这个决定当年被骂得很惨。马斯克的解释是：车会越来越自动化，你不需要那么频繁地低头看仪表。既然如此，把仪表盘做成一块固定的、必须正对着驾驶员的屏幕，本身就是为旧时代设计的。

设计团队的说法是，他们在每一条曲线、每一个细节、每一个内饰和外饰的角落上都反复较劲，包括很多用户根本不会注意到的地方。最后拿出一个非常简洁干净的方案。简洁不是省事，是因为加东西容易，减东西难，减法要顶着内部所有人的质疑做。

这个逻辑值得单独拎出来。多数车厂做内饰的思路是堆叠：屏幕越多越好，按键越全越好，看着高级。特斯拉反过来，把信息密度压缩到一块屏上，用一块屏的成本和一块屏的注意力，去换一个更空的驾驶舱。

前提是自动驾驶真的会来。这个前提如果成立，减法就是对的；如果不成立，用户就得天天在一块屏上找空调温度。

全自动驾驶的硬件，现在就得装上去

马斯克在现场说了一句容易被忽略的话：现在下线的每一台特斯拉，包括Model 3、Model S、Model X，都已经装好了实现全自动驾驶所需的全部硬件。

他报了具体配置：8个摄像头、12个超声波传感器、一个前向雷达，算力超过10 teraflops。

10 teraflops这个数字放在2017年很夸张。那会儿主流车型的辅助驾驶芯片算力还在个位数 teraflops 徘徊，车厂的做法是够用就行，功能上线了再升级硬件。特斯拉选的是另一条路：先把算力堆上去，功能慢慢用软件推送。

这条路的代价是每台车都背着一份暂时用不上的成本，好处是用户不用为了新功能换车。对一家当时还在亏损的公司来说，这是相当冒险的赌注，等于把宝贵的整车毛利提前押在一个尚未兑现的承诺上。

他敢押的理由，是软件迭代的速度远快于硬件换代。硬件的生命周期是十年，软件是三个月。硬件预埋一次，剩下的交给OTA（空中升级）。

外面比Model S小，后排头部空间反而更大

Model 3的尺寸比Model S小一圈，价格只有一半。设计上最难的一关，是外部尺寸缩小之后，内部空间不能缩。

弗朗茨的解法是从Model X上搬来的。Model X有一个贯穿前后的玻璃车顶结构，坐进去像坐在直升机座舱里，头部空间非常开阔。他们把类似的结构挪到Model 3的后风挡区域，让后排乘客头顶的空间不被溜背造型压掉。

马斯克说这是Model 3最难的设计挑战之一。要做溜背造型，又要保证后排能坐成年人，这两个要求在传统车身上是互斥的，只能靠结构和材料重新做一遍。

工程侧的压力同样大。Model 3要继承Model S和Model X的大量特性，同时把零件数量、重量和成本全部压下来。三件事同时成立，任何一个指标放松，车价就守不住35000美元。

碰撞测试视频放完，观众自己会判断

发布会中间放了一段碰撞测试的对比视频。一边是Model 3，一边是沃尔沃。

马斯克的原话很克制：沃尔沃被公认为世界上最安全的车之一。然后他说，看完这段视频，你更愿意坐在哪一台车里发生碰撞，应该很明显。

视频里展示了正面碰撞、侧面碰撞和翻滚测试。他没报任何碰撞测试分数，也没说拿了几个星，就让画面说话。这个处理方式比念参数更狠，因为观众的眼睛会自己下判断。

电动车的结构优势在这里体现得很直接。没有发动机，前部是空的溃缩区；电池铺在底盘，重心极低，翻滚风险天然更小。这些是平台决定的，不是靠加配置堆出来的。

13000个零件，少一个就停线

接下来这段是全场信息密度最高的部分。

马斯克说，Model 3有13000个独立零件。这些零件大约三分之二来自北美，三分之一来自世界其他地区。

然后他放了一张图，图上密密麻麻全是点，他形容这张图看起来像被洲际导弹轰过。每一个点代表一个供应商或者一个零件。他说，13000个零件里，任何一个出问题，整条产线就得停。

为了讲清楚这件事有多脆弱，他举了个不客气的例子：哪怕只是一个零件缺货，哪怕只是洗手间里的某个东西没到位，生产都可能被打断。

这段解释了一个外面看不懂的现象：为什么一家车厂的产能爬坡曲线总是比预期慢。因为产能不是一条线，是一万三千条线同时推进，任何一条掉队，整车的下线数量就是零。木桶效应在汽车制造里被放大到极致。

特斯拉当时的处境更难。它是一家新公司，供应商给它的优先级不高，备选供应商也少。传统车厂有几十年的供应商网络可以调度，特斯拉只能一家一家去谈。

沙漠里长出的全球最大电池厂

供应商讲完，镜头切到内华达。

马斯克描述Gigafactory那块地最初的样子：什么都没有，就是一片沙漠。等到建成，它是世界上最大的电池工厂，产能会比全球其他所有电池厂加起来还多。

这个工厂负责电池包、电机和动力总成。弗里蒙特负责车身和整车组装。两个地方必须严丝合缝地配合，才能达成最初的目标：每周5000辆。他估计再往后一年，会朝每周1万辆走。

为什么电池厂要单独建到荒郊野外？因为电池产线的占地面积大得离谱，而且耗电量惊人。加州的地价和电价撑不住这种规模的扩张，只能去内华达。

这也解释了特斯拉当时的垂直整合思路：核心零部件不外包，自己造。电池占整车成本的三分之一以上，交给供应商就是把最大的一块利润和最大的一个风险都交出去。

5000辆一周是及格线，1万辆是下一步

回到产能这个话题。

马斯克说，接下来六到九个月是最大的挑战，要把产能从一个极小的规模拉到大规模量产。他把这个过程称为进化，用词很生物学。

他也解释了为什么这么谨慎。Model S和Model X都经历过同样的阶段，团队知道那段路有多难受。这次只是把难度再放大一个量级，因为Model 3的预订量远超前两款车。

他的目标很直白：尽最大可能加速爬坡。他也提到了推特上天天有人问他“我的Model 3在哪”。他说这话时语气有点无奈，说车正在造，这个周末就在造。

每周5000辆是什么概念？一年约25万辆。这个数字在2017年对一个新车型来说相当激进，大众高尔夫全球年销量也就这个量级。一个只有十几年历史的公司，第一款走量车型就要冲这个数字，压力可想而知。

充电桩数量年底翻三倍

马斯克说，除了“我的车在哪”，用户问得第二多的问题是：充电怎么办。

他的回答是，超级充电网络（Supercharger）的数量在年底之前会变成原来的三倍。之后的目标是让车主几乎可以去任何地方。

他特别点了几个区域：欧洲、澳大利亚、美国缅因州、墨西哥湾地区。然后补了一句更大的话：地球上的任何地方，只要有电，你就能充电，超级充电桩只是让这件事更快。

这句话背后是充电焦虑的真实分布。多数人一天开不到50公里，家里有插座就够了。真正焦虑的是长途，是那种一年几次、一次几百公里的出行。超级充电网络本质上不是解决日常充电，是解决心理障碍。用户买车前会想“我能不能开回老家”，这个问题不解决，订单就签不下来。

35000美元能买到什么

参数环节，马斯克给了两个版本。

标准版：35000美元，续航220英里（约354公里），0到60英里/小时加速不到6秒，最高时速130英里（约209公里）。

长续航版：续航310英里（约499公里），0到60英里/小时加速约5秒。

他补充了一句：同等价位里，不管是烧油的还是用电的，都找不到更好的车。

这句话如果放在今天看，已经被市场验证过了。放在2017年，其实是个大胆的断言。当时35000美元能买到的燃油车，从紧凑型豪华轿车到中型SUV，选择非常多，而且没有续航焦虑。

Model 3要赢，靠的不是参数碾压，是把使用成本压到极低。电费远低于油费，保养项目少了一大半，没有发动机、变速箱、火花塞、机油。一辆车开五年，省下来的钱能抵掉相当一部分车价。这是很多人算完账才明白的事。

50辆试制车到场，30辆当天交车

现场停着50辆Model 3，全部是这个月生产的，用来做整车验证。其中30辆当天交付给车主。

马斯克特意说了一句，这些是真正的量产车，不是展车，不是手工打造的样车。台下坐着的车主，有些人为了排队订车，专程飞到别的州，就为了早一点在名单上排到前面。

他对着这些人说：我们知道这对你们很重要，我们真的在乎，我们会尽一切可能让你们的车早点到。

这段话听起来像客套，但对一家当时被无数人质疑“能不能造出来”的公司来说，把30辆车钥匙真的交到用户手里，比任何承诺都有说服力。

先买Model S和X的人，在替Model 3付账

交付时间上，马斯克说了实话：现在下订Model 3，大概要等到明年年底。

然后他转了个弯：如果现在订Model S或者Model X，一到两个月就能提车，因为这两款车已经在量产。

接着他说了一段商业模式的大白话：买Model S和Model X的客户，等于让Model 3成为可能。S和X赚到的钱，全部投进了Model 3的产线。

这段话把特斯拉当时的现金流结构讲得很清楚。高端车型利润高，用来养低端车型的研发和产线；低端车型走量之后，再反哺整个体系。传统车厂也这么干，但通常是在同一个品牌内部完成，特斯拉是从零开始搭这套循环。

所以早期买S和X的那批人，某种意义上是在给后来的Model 3车主补贴。马斯克当众把这层关系说破，也是一种聪明的销售话术：你现在多花的钱，不是被公司赚走了，是被投进了下一台车。

为什么要在庆功夜讲地狱

整场发布会的信息结构很有意思。

前半段是产品：设计、空间、安全、参数、价格。后半段全是制造：13000个零件、供应商分布、电池厂、产线爬坡、每周5000辆。产品只占三分之一，制造占了三分之二。

这个比例本身就是一种表态。2017年的特斯拉，最大的不确定性不在产品定义，而在能不能把车造出来。马斯克把发布会的重心放在制造上，等于提前给市场和用户打预防针：车是好车，但你们要等。

他用的那个词也很准，生产地狱。地狱不是失败，是必经之路。原型车到量产车之间的那道坎，所有硬件公司都要过。区别在于，有的公司过坎时没人盯着，特斯拉过坎时全世界都在看直播。

把最难的部分公开讲出来，是一种风险管理。预期先降下来，后面即使延期，市场的反应也不会那么激烈。这套打法他后来用了很多次。

对做硬件的人来说，这场发布会最值得记下来的不是参数，是那张像被导弹轰过的供应链图。13000个点，每个点都可能让整条线停摆。任何一款硬件产品，从能做出来到能稳定做出来，中间隔着的是这13000个点的管理能力，而不是设计能力。

  • 评估一家硬件公司的量产能力，先问零件总数和供应商分布，再问单一供应商的占比。零件数量超过一万的产品，任何一级供应商掉链子都会让产线归零。
  • 做产品规划时，把“能不能造出来”和“造出来要多少钱”分开算。前者看供应链，后者看垂直整合的深度。核心零部件自制的比例，直接决定毛利的天花板。
  • 预埋硬件前先想清楚软件迭代的节奏。硬件预埋只在软件能持续升级的前提下成立，否则就是每台车背一份用不上的成本。
  • 看发布会时，注意演讲者把时间花在哪。产品讲得多，说明难点在产品；制造讲得多，说明难点在产能。后者往往意味着更长的等待周期和更大的交付风险。
  • 如果你的产品要经历产能爬坡，提前把预期公开降下来。主动讲“接下来会很难”，比事后解释延期要便宜得多。
  • 对早期高价版本的用户，明确告诉他们钱去了哪。让他们知道自己买的不只是一台车，而是下一代产品的一部分，这比打折更能留住人。
