2015年6月的特斯拉股东大会，马斯克上台第一件事，是认错。

股价和增长曲线都放在后面，他先专门讲了一件营销上的蠢事：我们推出了双电机版本，但没跟用户讲清楚，双电机意味着全轮驱动。

有两个电机，它们连着四个轮子，但这个连接关系对很多潜在客户来说不清晰。这真的是我们自己的错，我们一开始就应该把它叫做全轮驱动版 Model S。（马斯克）

一家公司的创始人，在股东大会上花时间复盘一个命名失误，这件事本身就说明了他怎么看待产品：技术再强，说不清楚等于白做。

每年增长 50%，汽车工业里没有先例

2015年的特斯拉，处在一个奇怪的阶段。车已经卖得动了，但离“主流”还差得远。

马斯克给出的数字是：未来几年，年均增长大约 50%。他补了一句，不一定每年都精确是 50%，但平均值可以达到。

互联网公司做到 50% 不算什么。汽车公司做到这个数字，近乎荒谬。

原因很具体：一辆车有几千个独立零件，几百家供应商分布在全球。增长意味着整条供应链同步放大，多招几个销售解决不了问题。任何一个环节掉链子，产线就停了。

马斯克在台上说，这种增速对汽车公司来说“前所未有”。他也承认，维持起来很难，但会尽可能久地维持。

这句话背后的底气，来自接下来的产能布局。这件事后面会讲到。

双电机：传统全轮驱动是“哑的”，特斯拉是毫秒级反应

双电机版本真正的价值，马斯克解释得挺技术，但用一句话能听懂。

传统全轮驱动，是一个电机加一根机械轴。这根轴是“哑的”，它没有智能，有延迟，前后轮之间的扭矩分配是固定的，或者只能做很粗糙的调整。

特斯拉的做法是两个电机，一个管前轮，一个管后轮。前后扭矩可以在毫秒级动态调整。

这个反应速度意味着什么？电机的响应快到，从控制系统的角度看，车几乎是静止的。所以它能做到传统全轮驱动做不到的操控水平。

还有一个更实用的好处：冗余。

这就像一架双引擎飞机。如果一个电机坏了，你还能靠另一个电机继续开。（马斯克）

如果你被堵在荒郊野外，这个能力落到实处，就是能不能回家的问题。

双电机还带来一个商业上的好处：它显著扩大了可触达市场。有一大批人只买全轮驱动的车，之前根本不考虑特斯拉。现在他们可以考虑了。

顺带还降低了 Model X 的风险，因为 Model X 用的是同一套动力总成。

自动驾驶：他每周在自己车上刷两三个版本

2015年的 Autopilot，硬件方案是：前向雷达、前向摄像头、360度超声波，覆盖车身周围约5米。

这套硬件能实现的是“高速自动驾驶”，加上自动泊车和私人场地的召唤功能。

马斯克说了一句很能体现他工作方式的话：他每周在自己车上测试两三个版本的自动驾驶软件。有些周变好，有些周变差。

他给的时间表是：如果进展顺利，月底能推给早期体验用户，也就是那个“公开测试”项目。

他特意强调，发布前测试必须彻底。“这是件很棘手的事。”

70D 和北美市场份额：高端轿车销量第一

70D 这款车的设计目标很明确：提供一个“全包”的入门选择。

全轮驱动、超级充电、自动驾驶硬件、导航这些便利功能，全都包含。哪怕你买的是不加任何选配的基础版，拿到手的依然是一个完整的产品。

市场反馈超出预期，超过三分之一的客户选了 70D。

然后马斯克放了一张图：北美高端豪华轿车的市场份额。特斯拉是第一。

他说，如果能把这种成功复制到全球，销售增长空间很大。即便在北美，特斯拉在西海岸和南部很强，但东北部很弱。加拿大整体还有空间，墨西哥当年晚些时候要开业。

这个逻辑很朴素：在一个细分市场证明自己能拿第一，然后把这个证明复制到更多细分市场和更多地区。Model X 进 SUV 市场，Model 3 进更便宜的市场，都是同一套打法的延伸。

Model X：可能比 Model S 作为轿车更优秀

跳票已久的 Model X，当时的说法是三四个月后开始交付。

马斯克对这款车的评价很高，高到有点出人意料：

Model X 作为 SUV，可以说比 Model S 作为轿车更优秀。（马斯克）

他把重点放在几个关键功能上：鹰翼门、第二排座椅的设计，还有一些外界不知道的细节。

这里有一段值得所有做产品的人抄下来的话。他说，这些功能必须提供真正的功能性和真正的价值提升，不能让人觉得是花架子。实用性和美学都得有真正的改进，才算做对了。

“gimmicky（花架子）”这个词，是硬件产品最容易掉进去的坑。鹰翼门如果只是为了酷，就是个营销道具；如果它解决了狭窄车位上下车的问题，就是工程价值。

Model X 当时的状态是：在抠最后的细节，离上市很近了。

超级充电网络：三年从零到覆盖全美

马斯克用了一个比喻：像打了激素的巨藻，疯长。

他讲了一个很少被提及的细节。2012年 Model S 刚上市时，全美没有任何一个超级充电桩。更夸张的是，前六个月买车的用户，根本不知道世界上有超级充电桩这回事。

车里其实装了一个高压直流旁路装置，用户完全不知道它的存在。

第一批超级充电桩2013年初才开放。到2015年，只用了两年，已经可以靠超级充电网络走遍美国大部分地方。

欧洲和亚洲会复制同样的密度。最终目标是，靠超级充电网络可以走遍世界任何地方。

技术上还有一个有意思的升级：液冷线缆。

线缆液冷之后可以做得很细、很柔软。以前充电像跟一条大蛇搏斗，现在是一根细细的软线。有用户插上这么细的线，以为设备坏了，其实是下一代产品。

液冷还留了提升功率的空间。

Powerwall：被骂之后，功率翻倍，价格不变

特斯拉能源（Tesla Energy）发布 Powerwall 和 Powerpack 之后，市场反馈有好有坏。

马斯克的处理方式很直接：把负面反馈听进去，改产品。

Powerwall 的功率从 2千瓦持续、3.3千瓦峰值，提升到 5千瓦持续、7千瓦峰值。功率翻倍多，价格不变。

他解释了一个媒体经常搞混的地方：Powerwall 有两种用法，一种是备用电源（UPS），一种是每日循环。

这是两件完全不同的事。每日循环算的是经济账，或者追求完全脱离电网。备用电源只负责一件事：停电的时候，你家还有电。

备用这块，7千瓦峰值意味着，除了空调，家里所有电器都能接上去。要带空调，装两块，因为全家峰值负荷大概11到15千瓦，包含空调。

循环寿命的差异，马斯克给了具体数字：低循环版本大约1200次，高循环版本5000次。5000次按每天一充放，是15年。1200次那个，每天循环也能撑三四年。

他补了一句：备用版本也别怕用，一周循环一次，能用十年。两种版本的实际循环能力差距大概是四到五倍，但没有想象中那么绝对。

经济账这块，马斯克说得很实在。美国大部分地区，白天和晚上的电价差不多是平的，没有套利空间。所以纯算钱，美国家庭装每日循环版不划算。

德国、澳大利亚这类分时电价明显的国家，每日循环版的经济性非常好，哪怕你完全不在乎可再生能源。

交付优先级也讲得很清楚：优先给已经装了太阳能的人，不一定是 Solar City，任何兼容的太阳能系统都行，Solar City 优先。原因是太阳能系统本身带交直流逆变器，Powerwall 不用再买一个，成本省下来了。

最终目标价格：Powerwall 约3500美元，安装人工和成本约500美元，总共4000美元左右。

Powerpack：被低估的一块，公用事业侧的账更好算

马斯克在问答环节补充了一段很重要的信息，很多人忽略了。

特斯拉能源的销售，80%甚至更多会来自 Powerpack，客户是公用事业公司和大型工业客户。家庭用的 Powerwall 只占小头。

原因是价格和成本的区别。

公用事业公司白天和夜间的发电成本差异很大，峰谷用电比至少2比1，有时更高。这个成本差异真实存在，只是他们没有按这个差异向用户收费。

所以从平准化度电成本的角度看，公用事业公司有三个选择：升级老电厂、建新电厂、买电池组。第三个选项在账面上很直接。

马斯克说了一句很重的话：

即便可再生能源不在考虑范围内，光是电池，就能让全世界大概一半的发电厂关掉。（马斯克）

他还讲了配电系统的浪费。所有电线、变压器、变电站，利用率都远不到满负荷。用电池把负荷在整个系统上拉平，公用事业公司不用多铺线、多买变压器，就能从现有电网里榨出更多价值。

锂电还有一个被低估的优势：紧凑。

其他电池方案理论上每千瓦时成本低，实际上很高，而且体积大。体积大在公用事业场景是致命的。你要在变电站加缓存，得扩站。在美国大部分社区，扩站意味着买下别人的房子推平，邻居还不同意。这是巨大的麻烦。

特斯拉的 Powerpack 够紧凑，能塞进现有变电站。这是交钥匙方案。大企业客户和普通消费者一样，喜欢低麻烦、插上就能用。

工厂：涂装车间的产能是每周一万辆

这一年的产能投入，是理解“50%增长”从哪来的关键。

在 Lathrop（斯托克顿附近，中央山谷）开了新的铸造和机加工中心。大量铸件、机加工、铸锻工作转移过去，产出的零件装进 Model S。腾出来的弗里蒙特工厂空间，用来做整车总装。

弗里蒙特装了新的冲压线，自动化程度更高，主要服务 Model X 的冲压件。

新的 SX 车身产线，自动化更高，柔性更好。光车身线这一块，产能大约是现有产线的三倍。注意，三倍说的只是这一个环节，整个工厂没有三倍。

最贵的是新涂装车间。设计产能是每周一万辆车，也就是每年50万辆。这个产能是为了覆盖 Model 3 的量。马斯克说，据他们所知，这是全世界最先进的涂装车间。

涂装是汽车制造里最容易被低估的瓶颈。一座能涂50万辆车的车间，意味着特斯拉提前三四年为 Model 3 准备好了最贵的那块基础设施。

超级工厂：明年年中一期投产，三四年满产

超级工厂的进度，马斯克说网上有很多博主、无人机视频在拍，搜一下就能看到。

时间表：一期建筑明年年中投入运营，开始生产电池组。满产大概需要三到四年。

产能设计：电池组层面50 GWh，电芯层面35 GWh。差额靠从全球其他地方采购电芯补上。

这个产能对应每年50万辆车，外加15 GWh 留给固定储能。

问答环节有人追问：Powerwall 和 Powerpack 发布之后，这个测算还成立吗？

马斯克的回答是：固定储能的需求比预期高，正在考虑扩大超级工厂的产能，来满足这块需求。

这是整场股东大会里最重要的一个信号，虽然它听起来很平淡。一家公司同时被两头的需求拉扯，车不够卖，储能也不够卖，产能就是唯一的护城河。

CFO 退休：一段少见的动情时刻

演讲结束前，马斯克把 CFO Deepak Ahuja 请上台，宣布他当年晚些时候退休。

他说 Deepak 干了七年，经历了各种艰难时刻，始终冷静稳定。会留任到找到新 CFO 并完成交接。

Deepak 的回应很动情。他说在马斯克手下工作是一种荣誉，发现了自己超出想象的潜力。他把离开特斯拉比作“放手自己的孩子”，因为2008年就加入了，那时候有的只是热情、改变世界的愿景，和有限的资源。

他还说，这段经历像坐过山车，大概跟未来坐 Hyperloop 的感觉差不多。

一个 CFO 在股东大会上讲出这种话，说明这家公司当时的氛围。工资大概率是次要的。

问答环节：那些没被剪进新闻的细节

第一位股东问了一个反向问题：你有什么想问我们的吗？

马斯克愣了一下，然后认真回答了：你们觉得我们应该优先做什么？

他接着说，特斯拉的目标很直接，加速可持续能源的到来，尤其是可持续交通。人类要有好的未来，地球生命要有好的未来，就必须解决大气中二氧化碳过量的问题，最终还要避免碳氢化合物稀缺带来的经济灾难。

所以任何能推进这个目标的事，他们都想听。让车更有吸引力、更便宜，储能产品同理，都是关键方向。

这段对话暴露了一个事实：马斯克把股东大会当成了某种用户调研现场。他是真的在问。

关于超级工厂，有人问特斯拉会不会接受“超级工厂订单”，像卖产品一样卖工厂。

马斯克说，先建好第一个再说。眼下的重点是确保一号超级工厂建对。这会是未来几年非常难的挑战。明年第一部分投产，大概三到四年满产。

他说，在满产之前，就要想好二号、三号超级工厂放在哪。但在一号工厂完全跑通之前，不应该分散精力到多个项目上。

这个回答很马斯克：长期规划要有，但资源不能铺开。

“自动驾驶真正的问题是多少个9”

一个十年级的学生提问，说他准备买一辆 85D，想跑洛杉矶到拉斯维加斯之间的往返，问 Autopilot 够不够安全，会不会车与车之间通信，会不会开源。

马斯克的回答分三层，每一层都值得单独拎出来。

第一层，Autopilot 第一版的定位，是飞行员用的自动驾驶。它减轻驾驶负荷，但飞行员仍然要盯着。你不能打开它然后睡觉。

第二层，真正能睡觉的自动驾驶，需要冗余传感器和所有配套，是几年后的事。这是个极其困难的工程问题，难在 corner case，也就是边角场景，而边角场景非常多。

自动驾驶真正的问题在于它有多少个9的可靠性，能工作只是最低门槛。（马斯克）

他还给了一个具体标准：自动驾驶至少要比人类驾驶安全10倍，在统计意义上，才能建议用户打开它然后睡到目的地。

10倍这个数字对应的是公众接受度和监管门槛，随口说不了。技术上的“能用”，和商业上的“敢用”，中间隔着一个数量级的可靠性。

第三层，车与车通信。会有一些，主要是交通速度数据，用来优化导航。但路上 Model S 太少，大部分车不是特斯拉，通信只能是零星的。

至于开源，马斯克的回答很干脆：不开源软件，担心漏洞被利用。操作系统用的是 Linux，但应用代码不开源。

有人问怎么成为 Autopilot 测试用户，他说：你得在早期体验项目里。全场笑了。

Auto Steer：政府不是障碍，工程才是

有人专门问自动转向（Auto Steer）的时间表，以及政府有没有阻力。

马斯克说，他每周测试好几个版本的自动转向。大部分周变好，有些周变差。

难在哪？转向接管本身极难，还要考虑硬件故障。某个硬件系统挂了，或者 CAN 总线通信出错，各种问题都要调试。

当时的传感器只有前向摄像头、前向雷达和超声波。前向碰撞有一定冗余，但计算机只有一套，而且是一串计算机串联。任何一个环节挂了，自动转向就失效。

他的判断是：谨慎乐观，月底能推给早期体验用户。

政府那边没有问题，原因很关键：它属于驾驶辅助功能，转向责任仍然在人身上。就像飞机的自动驾驶，飞行员仍然对飞行负责。

这个定性决定了监管路径。一旦被归入“辅助”，就不需要等待自动驾驶法规；一旦被归入“自动”，整个合规流程是另一回事。

换电为什么失败：200个邀请，四五个人试，每人一次

这一段是整场问答里最有意思的商业教训。

特斯拉在洛杉矶到旧金山之间建了换电站，Harris Ranch。股东问换电的预约方式和终身免费充电的账怎么算。

马斯克的回答很坦率：试的人非常少。

他们先发了一轮邀请，大约200个。结果总共四五个人想试，而且每个人都只试了一次。

然后他们决定把邀请扩大到所有加州车主。但他预期，全体用户的行为跟那个初始样本差不多，因为人们根本不在乎换电。

给读者的行动建议

这场股东大会的信息密度很高，真正能拿来用的，是几条判断方法。

  • 看马斯克的时间承诺，要分两层。他说“技术可行3年”，和“监管批准再1到3年”，是两个完全不同的东西。前者是他能控制的工程问题，后者不是。任何关于自动驾驶、火星、机器人的时间表，都该这么拆开看。
  • 评估一家硬件公司的增长，看产能扩张的具体动作。50%的增长率是结论，涂装车间每周一万辆、车身线三倍产能、超级工厂50 GWh，才是支撑结论的证据。只看增长率会误判，看产线才看得懂。
  • 储能产品值不值得买，先查你所在地的分时电价。美国大部分地区峰谷电价差不多，每日循环版算不过账。德国、澳大利亚这类分时差价明显的市场，经济性非常好。同一款产品，在不同电价结构下是完全不同的生意。
  • 讨论自动驾驶，问“多少个9”，别问“能不能”。能工作是最低门槛。真正决定它能不能商用的，是可靠性比人类高多少倍，以及监管愿不愿意接受这个倍数。马斯克给的门槛是10倍。
  • 判断一个功能是不是花架子，看它有没有解决具体问题。鹰翼门如果只是酷，就是营销道具；如果它让窄车位上下车变容易，就是工程价值。这个标准适用于你看的所有产品发布会。
  • 学马斯克认错的方式：具体、认领、给修正。他的原话是“我们应该一直把它叫做全轮驱动版 Model S”，没有停在“沟通上有一些不足”这种层面。认错认到具体动作，才叫认错。
