Tesla香港特别活动：马斯克与乔恩·麦克尼尔（2016.1.25）

Tesla Hong Kong Special Event - Elon Musk & Jon McNeill - Jan 25, 2016

2016年1月25日，香港。特斯拉办了一场车主活动，马斯克专程飞过来。

他站在台上给了一个判断：香港会成为全世界人均电动车最多的城市。

放在当时，这话听着有点悬。香港大部分居民住在公寓楼里，自家停车位装不了充电桩；公共充电点数量不少，功率却低得可怜；街上跑的特斯拉还是个新鲜东西，大部分人只在视频里见过。

香港的充电难题有它的特殊性。住宅多是高层公寓，停车位在楼里，产权分散，装一个充电桩要过物业、电力公司、其他业主好几道关。公共充电点倒是不少，很多是早年建的慢充，一小时充不了多少电。车主白天开车，晚上找不到地方充，体验就断了。

马斯克清楚这些。他第二天就要跟香港政府开会，谈的正是充电。

但他还是说了那句话。他看到的是另一层东西：一个城市如果率先把电动车普及到很高比例，就一定会先撞上所有问题。充电网络怎么铺，电网怎么扛，老旧建筑怎么改造，这些在别的地方还没暴露，香港会先遇到。

我认为香港会率先摸索出怎么做充电，怎么处理电网上的大量电动车，所有这些问题。然后它就会成为世界其他地方的好例子。（马斯克）

香港是个实验室。实验成功，全世界抄作业；实验撞墙，全世界避坑。

这场活动分两半：前半段马斯克讲特斯拉的进展和计划，后半段问答。问答比演讲有意思，车主问的都是真问题：充电装不了怎么办，服务等三个月怎么办，自动驾驶到底靠不靠谱。

先用贵车证明电动车不是高尔夫球车

马斯克把产品路线讲得很直白，三步走。

  • Roadster，2008年推出，产量低价格高，用来证明电动车可以很快很酷
  • Model S 和 Model X，中等价格中等产量，主力产品
  • Model 3，大约两年后推出，低价格高产量，走量车型

这个顺序有讲究。电池成本高的时候，只有卖高价才能覆盖成本，顺便把品牌和技术口碑立起来。等电池成本降下去，再往大众市场走。硬件创新大多走过这条路：先卖给愿意为新技术付溢价的人，再卖给普通人。

很多人以为特斯拉是先做高端车赚钱，再做便宜车走量。实际的重点在别处。高端车的真正作用是验证技术、摊薄研发、建立供应链。电池、电机、电控这些东西，第一款车做出来成本极高，只有高售价才能撑住。等供应链成熟，成本曲线下来，才有条件做大众车型。

特斯拉的总体目标就一句话：加速可持续交通的到来。

尽我们所能，让可持续的未来早一点发生，而不是晚一点。（马斯克）

Model S 的任务很特殊。它要同时完成两件事：做一辆好电动车，做一辆全方位的好车。

在此之前，人们对电动车的印象是什么？高尔夫球车。慢、丑、续航短、开着没面子。这个印象不打破，电动车永远是小众玩具。

我们非常努力地让电动车成为最好的车。这非常重要，因为以前人们对电动车的印象就像高尔夫球车，慢、丑、续航短。我们必须证明电动车可以是最好的车，可以快，可以好看，操控可以很好，续航可以很长。（马斯克）

结果还算争气。绝大多数车主表示愿意再买一辆 Model S，拿了年度车，Consumer Reports 说这是他们测试过的最好的车。

马斯克接着讲安全。特斯拉的打法是先拿五星安全评级，再谈别的。

Model S 的溃缩区比任何燃油车都长，因为车头没有发动机。座舱很刚性，电池包铺在底盘上，重心低。全轮驱动版本零到百公里加速不到3秒，续航接近500公里。

这些参数放在一起，目的只有一个：让电动车成为燃油车的真正替代品。环保爱好者的小众妥协，撑不起一个产业。

还有一个细节马斯克很得意：车会越用越好。传统汽车买回家，软件就固定了，十年不变。特斯拉通过 OTA 更新，车会持续改进。这个逻辑今天看很平常，2016年还是新鲜事。车的价值从出厂那一刻往后延伸，用户买到手的除了机器，还有后续几年的软件迭代。

Autopilot 也一样。马斯克说，这套系统会随着软件更新越来越好，直到传感器套件的物理极限。摄像头、雷达、声呐、GPS 一起工作。

他提到第二天要跟政府谈 Autopilot 的审批，话说得很谨慎：

我谨慎乐观，明天的会谈会有好结果。（马斯克）

从5个人到15000人，从600辆到5万辆

马斯克放了几组数字。

2004年，特斯拉只有5个人。现在接近15000人。

5年前，一年造600辆车。现在一年5万辆。

累计省下的汽油超过1.5亿升。

大中华区的布局：15家店，覆盖7个主要城市，几百个超级充电桩，还有更多目的地充电桩。澳门今年年底开业。

2016年下半年有几件事：Model X 到香港，新建一个大型服务中心，充电网络大幅扩张。

然后他把视角拉到最大：

每年生产的新车和卡车超过9000万辆，其中不到2%是电动车。要把世界过渡到可持续能源，还有很长的路要走。这只是个开始。（马斯克）

这句话是整场演讲的底色。香港市场再热闹，放在全球9000万辆的盘子里，也只是很小的一块。但马斯克要的就是这个效果：先在一个城市做透，证明模式可行，再复制。

香港最大的瓶颈：800个低功率公共充电桩

第一个提问的车主问得很直接：大部分车主装不了自己的充电桩，公共充电设施不好，超级充电网络的扩张速度跟不上新车增长，这很快就会成为香港的瓶颈，特斯拉打算怎么解决？

马斯克说，这正是他第二天跟政府要谈的题目。

他的方案分几层。

第一层，升级现有公共充电桩的功率。香港大概有800个甚至更多的公共充电点，但功率都很低。

我认为正确的做法是把它们升级到更高功率，同时让其他电力公司也能用。（马斯克）

第二层，特斯拉愿意把技术拿出来，帮政府升级公共充电站。

第三层，改建筑法规。理想情况下，如果业主申请在楼里装充电设施，应该有义务提供。

马斯克的底层逻辑很简单：最好的充电方式，是在你给手机充电的地方给车充电。

如果你必须去第三个地方充电，那通常不理想。最方便的是手机在哪充电，车就在哪充电。当然，长途驾驶除外。（马斯克）

这句话点出了电动车普及的真正难点。超级充电桩负责长途和应急，日常充电必须发生在家里或者公司。一个城市如果只有公共快充，没有家用慢充，车主的体验会一直别扭。香港的问题更典型：大部分人住在高层公寓，车位是共用的，装充电桩需要物业、电力公司、业主三方同意，流程长得让人放弃。

服务被吐槽，销售总裁承认增长太快

问答环节最尖锐的问题来自一位老车主。他说自己是香港第一批右舵 Model S 车主，等车等了两年，车很好，交付后的服务也曾经是香港标杆。但最近，预约服务要等3到4个月，等个小零件要3到6周，出了事故只能去全城唯一一家修理厂，等几个月，价格还贵。怎么才能回到当年的服务水平？

这个问题是 Jon McNeill 接的。他是特斯拉全球销售总裁，但他说自己的头衔后半截是服务，所以这问题归他。

他的回答很坦诚：场地几个月前就不够用了。

我们建一个超过10万平方英尺的销售、服务和交付中心，但产能上线速度不够快，坦白说，我们需要空间干活。（麦克尼尔）

他还说，光有空间不够，工作方式也得改，这个流程会在新场地启用之前就开始。

问题出在哪？需求增长比预期快，香港的车保有量涨得比他们预测的快，服务能力落在了后面。现在的状态是追赶，目标是回到世界级服务。

衡量标准有两个：车主满意度，以及当天完成维修的比例。

我们的目标是把维修对你的生活影响降到最低。如果出了问题，我们希望你的车离开你的时间不超过一天。（麦克尼尔）

这段对话值得单独拎出来。特斯拉当时在全球都在经历同样的阵痛：车卖得太快，服务网络跟不上。香港只是把这个问题放大了，因为地方小，场地难找，一个城市只有一家修理厂，没有缓冲。

售后是硬件生意里最容易被低估的部分。卖车是一次性收入，售后是长期关系。车主对品牌的印象，往往在第一次出问题、第一次进修理厂的时候定型，提车那天的兴奋撑不了太久。特斯拉在香港的口碑滑坡，根子就在车卖得太快，修理厂没跟上。

Autopilot 不叫自动驾驶，是怕你想歪

有位做电动车推广的提问者说，Autopilot 上线以来，媒体报道的全是事故，正面案例很少。心理学上一条坏消息需要五条好消息来平衡，特斯拉能不能主动分享一些 Autopilot 救人或者避免事故的案例？

马斯克的回答很实在：确实有很多干预案例，但特斯拉没问过车主能不能公开。

我们不想给任何人压力。如果你愿意分享，可以。（马斯克）

提问者追问，能不能做匿名统计，或者聚合数据。

马斯克说，用统计方式呈现可能更合适。他最近看到一个直方图，对比 Autopilot 和手动驾驶的车道位置分布。

Autopilot 状态下的概率分布比手动驾驶紧密得多。人手动开车的时候，车道位置的变化其实相当大。把这个放出来可能是个好主意，让大家看到 Autopilot 的车道保持比人更稳。（马斯克）

这个思路值得多说两句。个案容易被质疑挑选样本，统计分布很难反驳。马斯克提到的车道位置直方图是一个很聪明的指标：它绕开了事故归因的争论，直接展示行为差异。要让外界相信机器开得稳，最有力的话术就是让数据自己开口。

现场有位车主分享了自己的体验：用了几个星期 Autopilot，到达目的地时精神好很多。马斯克接过话，解释了这个功能为什么叫 Autopilot。

我们叫它 Autopilot，是希望人们把它理解成飞机上的自动驾驶。这个意思并非飞行员可以放弃责任或者睡觉，那很危险。它的作用是减轻工作量，让你开得更轻松。（马斯克）

这段话是整场活动里最重要的产品定义之一。Autopilot 这个名字故意选得含糊，既借了飞机自动驾驶的成熟感，又留住了驾驶员仍然负责的余地。后来几年围绕 Autopilot 的争议，很多都跟这个命名的边界有关。2016年马斯克已经把话说得很清楚：它的作用是辅助，替代不了人。

这里还有一个更深的点。媒体传播天然偏爱事故，因为事故有画面、有情绪、有故事。避免事故的案例没有画面，只有什么也没发生。自动驾驶公司如果只等用户主动分享，正面叙事永远是缺失的。马斯克当时松口说可以做统计，算是意识到了这个问题。

车机不建应用商店，让你的手机投屏

有人问，什么时候能在车上装 App，像手机一样下载应用。

马斯克的回答否掉了自建生态这条路：

从应用的角度看，更合乎逻辑的做法是允许 iPhone 或安卓上的应用投射到中控屏上，而不是创建一个新的应用生态。这大概会是我们未来的重点。（马斯克）

这个决策在2016年看很务实。车企自建应用商店，做不过苹果和谷歌，开发者不愿意为一个小众平台单独适配。让手机投屏，等于借用了手机生态的几十万应用，车机只负责显示和交互。

代价是车机长期依附于手机。但对当时的特斯拉来说，把精力放在 Autopilot 和三电系统上，比做一个没人用的应用商店划算得多。

电池里的锂，用得越来越少

最后一个问题关于锂。有环保人士质疑特斯拉电池大量使用锂，开采和回收都有环境代价。

回答是：随着时间推移，特斯拉电池里的锂用量在减少。

负责电池工程的团队进步非常快。你能从续航看到，也能从电池里用的锂的量看到。我们希望在业务的每个环节都把影响降到最低。（马斯克）

他还提到，90 和 70 这两个型号用的是新的电池技术，特斯拉在探索新的技术路线。

这个回答不算详细，方向很清楚：提高能量密度，减少每度电对应的材料用量。电池成本下降和材料用量下降，本来就在同一条曲线上。同样的续航，用更少的锂，意味着更低的成本和更小的环境足迹。

9000万辆的盘子里，电动车还不到2%

整场活动，马斯克反复回到一个坐标系：全球每年生产9000万辆新车和卡车，电动车占比不到2%。

这个数字让香港的热闹显得很小，也解释了特斯拉为什么要在这样的城市下功夫。

一个城市的电动车渗透率越高，暴露出来的问题就越真实。充电怎么布，电网怎么改，法规怎么调，服务怎么跟上，这些问题的答案得在街上跑的车里找，实验室给不了。

香港地方小，密度高，政策灵活，是天然的试验场。马斯克说香港会成为全球人均电动车最多的城市，他赌的是香港会先把坑踩一遍，购买力反倒次要。

对特斯拉来说，香港的价值落在经验上，销量只是副产品。

2016年的这场活动，放在特斯拉的历史里只是一个小节点。但它把电动车普及的真实难点摊开了：造车本身算不上最难的部分，充电、服务、法规、用户预期这些配套环节才是。这些问题到今天也没有完全解决，只是换了个城市、换了个市场重新出现。

给技术从业者的几条参考

  • 判断一个新技术能不能铺开，先看它最脆弱的环节。特斯拉在香港的瓶颈是充电桩功率太低、服务场地不够。车本身没问题，参数再漂亮，基础设施拖后腿，普及就会卡住。
  • 产品定义要先把品类偏见打掉。Model S 的第一任务是做成一辆最好的车，电动只是它的动力形式。大部分用户不会为了环保忍受一辆难看的车，却会为了一辆好开的车接受电动。
  • 命名是产品的一部分。Autopilot 借了飞机自动驾驶的成熟感，又留住了驾驶员仍要负责的余地。名字越含糊，越需要在说明书和沟通里把边界讲清楚。后来围绕 Autopilot 的争议，大多来自这条边界没被讲透。
  • 售后网络是硬件公司的隐形负债。车卖得越快，这笔债滚得越大。香港一个城市只有一家修理厂，需求一涨，等待时间立刻从几天变成几个月。扩张速度要按服务能力倒推，订单量只能作参考。
  • 媒体叙事天然偏向事故。避开事故没有画面，只有什么也没发生，正面案例永远不会自己浮上来。想让外界看到真实的安全水平，得主动做统计、做分布。
  • 找能公开的客观指标，少等用户讲个案。车道位置的分布、人工接管的比例、同一天完成维修的比率，这类指标不带情绪，很难被质疑挑选样本，比十条感人故事更有说服力。
  • 小市场可以当试验场，别只当销量表上的一行。密度高、政策灵活、用户挑剔的地方，会先把配套问题暴露出来。在一个城市把充电、服务、法规跑通，经验能直接复制到下一个市场。
  • 平台型决策要想清楚借谁的生态。自建应用商店听起来完整，实际做不过手机厂商。把手机投屏到中控屏，省下的是几年研发，付出的是长期依附。这个取舍要在资源最紧的时候做，等有余力了再补就晚了。

回到那场活动本身，参数都可以查，难得的是马斯克对时间的判断。

他在2016年说，这只是个开始。九年过去，全球电动车占比从不到2%爬到了两成左右，充电桩从稀缺变成标配，Autopilot 的争议从命名边界变成了责任归属，香港依然是全球电动车密度最高的城市之一。

当年那些被车主当面提出来的问题，充电装不了、服务等三个月、自动驾驶靠不靠谱，换个城市、换家公司，今天还在被问。
