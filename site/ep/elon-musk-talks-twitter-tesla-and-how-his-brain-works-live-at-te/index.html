2014 年，特斯拉那年卖了 6 万辆车。马斯克说，2020 年我们要做到一年 50 万辆。2020 年，特斯拉交付了 499550 辆，差一点就是分毫不差。

同一个人，2016 年在 TED 舞台上说，全自动驾驶今年就能实现，一辆车从洛杉矶开到纽约，全程零干预。六年过去了，这个承诺还没兑现。

一次准得吓人，一次差得离谱。2022 年 4 月，TED 的 Chris Anderson 在温哥华的剧场里，把这件事摊开问了马斯克。

他的回答，比任何一条推文都更能说明这个人的脑子是怎么转的。

自动驾驶为什么骗了所有人六年

马斯克的第一反应是自嘲：「我不想吓着你，但我不是永远都对。」

接下来他解释，为什么偏偏是自动驾驶这么难预测。

原话大意是，这个领域有太多假曙光。你以为自己抓住了问题，觉得有把握了，然后「不对，你只是撞到了天花板」。

他把进展画成一条对数曲线。这词听着抽象，其实很好理解。

你学骑自行车，第一天进步巨大，从摔跤到能骑十米。第二天能骑五十米。第三天能骑两百米。你觉得再练几天就能参加环法了。然后你发现，从「能骑」到「骑得好」之间，横着一道看不见的墙。

自动驾驶也是这样。工程师把每一个小问题的进展叠起来看，是一条又一条的对数曲线，先陡后平。回头看在哪儿踩了坑，一清二楚。当时身在局中，每个坑都像是最后一道坎。

马路是给眼睛和大脑修的，不是给电脑修的

马斯克给了一个他后来反复引用的判断：

道路网络的设计对象，是生物神经网络，也就是人脑，加上视觉，也就是人眼。红绿灯的颜色、路面的标线、行人抬手示意的动作，全是为这两样东西优化的。

想让机器开车，你就必须把「真实世界的人工智能」和「视觉」这两件事解决掉。摄像头加硅基神经网络，去对接一个为眼睛和生物大脑设计的世界。

这么一讲，那个绕了六年的弯子就清楚了。自动驾驶从来不是汽车工程问题，它是通用人工智能的一个子问题。一家车企去解 AGI，难怪时间表一次次往后推。

这次他还是赌上了：「这可能是出名的不祥之言，但我确实有信心今年能解决。」

Anderson 追问，你说的是事故概率低于人类平均水平？马斯克说，是的，今年。

然后他自己补了一句：一年后我们可能又坐在这儿，说又一年过去了，还是没成。

Anderson 问了个更尖锐的问题：你是不是故意把时间表说得激进，用来逼团队拼命？

马斯克的回答只有一句：「不这样，什么都做不成。」

从四个轮子到两条腿

访谈里最反常识的一段，是他顺带宣布：特斯拉今年最重要的产品开发，是人形机器人 Optimus。

为什么造车造到一半去造人？

逻辑是递进的。既然为了让车看懂世界，你必须解决真实世界的人工智能，那么这套能力可以迁移。一辆车就是四个轮子的机器人，把轮子换成腿，剩下的问题就变成工程问题。

他列了两件当时还缺的事：机器人得有足够的智能，在没人明确指令的情况下自己在真实世界里导航、干有用的事；以及大规模制造的能力。

这两样恰好是特斯拉最擅长的。剩下的就是设计 actuators（执行器）和传感器，凑出一个人类体型的机器人。

Anderson 说，很多人根本没意识到这有多大。马斯克回：「这会比汽车更大。」

应用场景他讲得很具体。机器人真正理解你家的三维结构，知道每件东西在哪儿、应该在哪儿，还能认出这些东西。然后你可以让它收拾房间、做晚饭、割草坪、给奶奶端杯茶顺便给她看家庭照片、陪孩子玩接球。

Anderson 问，能不能当伴侣，包括性伴侣。

马斯克说，那大概不可避免，然后补了一句，我确实向互联网承诺过要造猫娘机器人。

听着像玩笑，但接下来这段是认真的。

一个不能远程更新的停机开关

话题转到安全，马斯克主动提出了一个设计：

机器人身上装一块本地 ROM 芯片，不能通过空中下载更新。里面写死一条规则，只要有人喊「停、停、停」，机器人立刻停下。任何人喊都有效。

远程改不了。想改，得物理接触那台机器。

他还说，人形机器人应该被监管。「我不喜欢被监管，但我认为这件事对公共安全很重要。」

这话从一个以讨厌监管著称的人嘴里说出来，分量不一样。

2.5 万美元的机器人，对上 4 万美元的年薪

时间表：今年内会有一个有趣的样机，明年可能有用，两年内大概率能成。之后就是逐年快速提升可用性、降低成本、扩大产量。

成本，马斯克说不会高得离谱，低于一辆车。Anderson 追问是不是两万五美元左右，他没有否认。

接下来这段需要停下来算一算。

一个年薪三四万美元的工人，你得年年付。一台两万五千美元的机器人，一次性买断，工作时间更长，不休假。

这笔账摆在任何一家工厂老板面前，答案都很清楚。

Anderson 问，世界该多担心失业。

马斯克的回答跟主流担忧相反：现在已经是劳动力严重短缺，未来还是短缺。不会是人没活干，而是活没人干。

他描述的结果是一个富足世界。任何商品和服务，想要的人都能得到，价格便宜到荒谬。

这个判断能不能成立，取决于分配制度跟不跟得上。马斯克没在这个访谈里展开，他只说了方向。

他为什么突然想买下城市广场

节目现场的另一半，是几个小时前刚发生的事：马斯克向 Twitter 发出收购要约。

Anderson 提醒他，上周你亲口说「我不想拥有 Twitter，那是通往痛苦的配方，所有人都会怪我」。

马斯克先认了这句：所有人还是会怪我，100% 是我的错，会有不少箭射过来，会很痛苦。

然后给出理由。

Twitter 已经成了事实上的城市广场（de facto town square）。要有一个人人都能包容地说话的地方，人们既要真的能自由发言，也要感觉自己在自由发言。这两件事缺一不可。

他把这上升到文明层面：Twitter 作为公共平台的信任度越高，文明风险越低。这不只关乎美国，也关乎世界上其他地方的自由。

他还澄清了动机：不为赚钱，也不为垄断。私有公司股东人数上限大约两千人，他会按法律允许的上限尽量多保留股东。他承认自己技术上付得起全现金，但强调这跟套利无关。

「我强烈的直觉是，一个被最大程度信任、尽可能包容的公共平台，对文明的未来极其重要。」（马斯克）

把算法扔上 GitHub

收购之后要改什么，他讲了两条。

第一条，算法开源。代码放到 GitHub 上，谁都能看，谁都能指出问题，谁都能提修改建议，像给 Linux 或 Signal 提 PR 那样。

第二条，任何对单条推文的人工干预都要留痕。被加强曝光了，被降低权重了，用户能看见这个动作发生过。不能有黑箱，不能有幕后手动操作。

他认为黑箱推荐很危险。有些内容莫名其妙被推上来，有些莫名其妙沉下去，外界完全不知道发生了什么，这本身就是问题。

另有一条更接地气：编辑按钮。会来的。

但有个细节他想了很久。你发一条「马斯克真棒」，两百万人转发。然后你把这条改成「马斯克真烂」，那两百万转发的人全被坑了。

他的方案是：编辑只在很短的时间窗口内开放，而且一旦编辑，转发和点赞全部清零。

他还说自己对具体方案持开放态度，欢迎别人出主意。

优先级最高的一件事，反而不是这些。是清理垃圾账号和诈骗机器人军团。「我每看到一个加密货币骗局就给我一枚狗狗币的话，我大概有一百亿枚狗狗币了。」

至于狗狗币本身，他说就是好玩，别押上全部身家，我喜欢狗，也喜欢梗，狗狗币两样都占。

三条推文，一条比一条过界

Anderson 把最难的问题摆上桌：你自称自由言论绝对主义者（free speech absolutist），那是不是什么话都能说？

马斯克的第一个边界是法律。Twitter 在任何国家运营，都得遵守当地法律。不能直接煽动暴力，不能在电影院里喊失火，那是犯罪。

Anderson 举了一组例子，一层层加压。

第一条推文：我讨厌政治家 X。完全合法。

第二条：我希望政治家 X 不存在了。也合法，就像现在很多人对普京说的话。

第三条：我希望政治家 X 不存在了，配一张他脑袋上压着瞄准镜准星的照片。开始变味。

第四条：上面那些，再加上他的家庭住址。

Anderson 的意思是，总得有人来判断哪条过界。算法能做到吗？还是必须靠人的判断？

马斯克的回答很克制。他说，坦白讲，我没有所有答案。

但他给了一条原则：拿不准的时候，让推文留着。处于灰色地带的内容，让它存在，只是别去主动推荐它。

他对删除要极度不情愿，对永久封禁要极度谨慎。限时封禁比永久封禁好。

然后他给出判断言论自由是否存在的标准，这句话值得单独拎出来：

「你不喜欢的人，说了你不喜欢的话，如果这种情况能发生，我们就有言论自由。这很烦人，但这是言论自由健康运作的标志。」（马斯克）

世界首富拥有城市广场，这事怎么解释

Anderson 把反对者的声音原样搬上台：我们同意 Twitter 是极其重要的公共空间，它是全世界讨论生死问题的地方，那它怎么能由世界最富有的人拥有？

马斯克的回应分两层。

第一层，机制上约束自己。算法开源，人工干预留痕，他个人不会去编辑别人的推文。

第二层，拿同行做对比。扎克伯格同时拥有 Facebook、Instagram 和 WhatsApp，股权结构设计成哪怕传到马克十四世，这些实体还在他手里。

这话的意思是，媒体所有权集中不是他开创的，他只是把话挑明了。

那笔旧账：funding secured

访谈里有一段主动翻旧账，很多人不知道。

2018 年，马斯克发推说考虑以每股 420 美元把特斯拉私有化，资金已到位（funding secured）。SEC 起诉他证券欺诈，他最终和解，卸任董事长三年，罚款两千万美元。

四年后他在 TED 舞台上说，那句话是真的。

「SEC 知道资金确实到位了，但他们还是发起了公开调查。」（马斯克）

他说当时特斯拉财务状况岌岌可危，银行告诉他，如果不同意跟 SEC 和解，就停止提供营运资金，特斯拉会立刻破产。

「这相当于有人拿枪指着你孩子的头。我被迫向 SEC 认罪，非法地，那些混蛋。这让它看起来像是我撒了谎，而我没有撒谎。我被迫承认我撒了谎，只是为了救特斯拉的命，这是唯一的原因。」（马斯克）

这段话可以看成情绪宣泄，也可以看成一条重要的背景信息：他后来对监管机构的敌意，有很大一部分来自这次他认为的强制构陷。

同一段里他提到，特斯拉是股市历史上被做空最多的股票。空头在用「做空加造谣」（short and distort）的组合拳，铺天盖地的负面报道影响了招聘，也影响了卖车。

「他们想让特斯拉死，想得要命。」（马斯克）

Anderson 劝他，别把时间浪费在这些争斗上，人们更想买你的梦想。马斯克承认自己是个「mixed bag」，但补了一句：真相对我来说很重要，是一种病态程度的重要。

如果人生有一个编辑按钮，他删哪一年

Anderson 从观众提问里挑了一个：如果能回到过去改一个决定，你改哪个？

马斯克的答案跟 Twitter、跟特斯拉私有化都没关系。

他最后悔的商业决定，是没有和 JB Straubel 一起从头创办特斯拉。

这里他花了点篇幅纠正一段他认为是编造的历史。他强调，他投资时的特斯拉是个空壳公司，没有员工，没有知识产权。公司是他和 JB 一起创建的。至于「另一个联合创始人 Martin Eberhard 创建了公司」这个说法，他认为是假的，而且对方把澄清这件事当成了人生使命。

这个细节值得留意。JB Straubel 是那个痴迷电池、懂电池的技术联合创始人，后来离开特斯拉创办了电池回收公司 Redwood Materials。马斯克后悔的，是当年没有绕开那个现成的壳子，自己重新搭一个干净的公司架构。

三年地狱，换来一句话

Model 3 产能地狱。Anderson 问，是不是因为你当时高估了工厂自动化的可行程度，过度自动化差点把公司拖死？

马斯克的回答先纠正问题的框架：特斯拉最值得说的事，是造出了电动车原型，也做到了小批量生产，但这些都不是重点。

一百年来有几百家汽车创业公司。彭博统计过一次电动车创业公司，数到了近 500 家。造原型不难，小批量也不难。

真正难的是达到量产还不破产。做到这件事的上一家美国车企，是 1920 年代的克莱斯勒。

然后他承认，Model 3 那条产线，从电芯到电池包到驱动单元到电机到车身线到涂装车间到总装，几乎所有环节都搞砸了。

他在 Fremont 和内华达的工厂里住了三年，在产线上到处跑，跟团队一起熬。他刻意站在车间地面上，让熬得最苦的人看得见他。「他们受的苦，我受得更多。」

2017、2018、2019，他说这是他人生中最长的三年剧痛，没有别的办法，差一点就没挺过去。

Anderson 问，值不值。马斯克的回答是，不做特斯拉就死了。

然后他说了一句可以拿去当标题的话：

「事到如今，我觉得我比地球上任何活人都更懂制造。我能告诉你那辆车里每一个零件是怎么造出来的。」（马斯克）

三百太瓦时，才是他真正在算的数

访谈里他提到正在写新的总体规划，核心词是规模。

为什么死磕规模？因为要把一个严重依赖化石燃料的庞大经济体，转成可持续能源经济，量不够就等于没做。

路径他讲得很清楚：发电靠风、光、水、地热，他也说自己相信核能。风光是间歇性的，所以必须有固定式储能电池。然后交通全面电动化。这三件事做到，可持续能源的未来就成立。做得越快，环境风险越小。

所以谈规模，谈的是吨位，利润率的账另算。衡量单位是电池产量，而且要是可持续方式生产的。

他给出的数字是：大约需要 300 太瓦时的电池储能，才能把交通、电力、供暖制冷全部电动化。这大概是当时全球已装机量的 1000 倍。

顺带一个容易被忽略的点：电池回收。一个报废的电池包大约值 1000 美元，里面的原材料相当于高品位矿石。所以别以为那会是一堆没法处理的垃圾。

一个把话听成字面意思的孩子

放到这段 SNL 开场白时，马斯克念了自己的台词：「我是今晚创造历史的人，第一个主持 SNL 的阿斯伯格综合征患者，至少是第一个承认的。」

Anderson 问他，你怎么理解自己的阿斯伯格。

他的描述很平实。每个人的体验不同，他自己的情况是社交暗示不直观。别人能凭直觉听出弦外之音，他只会按字面理解，说出来的话是什么意思，他就当成什么意思。后来才发现不是这样，别人说的和想的不一样，他花了不少时间才搞明白。

他说自己的童年并不快乐，相当艰难。读了非常多的书，看了很多电影，从书里慢慢补上了别人天生就有的那部分能力。

Anderson 提了一个很温柔的假设：会不会正因为社交信号那扇门被关掉了一部分，脑子被推向了另一条路，让他能往世界的深处看？

马斯克说，有可能。然后给了个更朴素的技术视角：他觉得整夜一个人对着电脑敲奇怪的符号很有意思。大多数人觉得这不叫好玩，他是真的喜欢。

物理学是一种对真相的执念

Anderson 试着总结马斯克创新的方法：他同时看见三种可能性，科学的可能，技术的可能，还有经济的可能，也就是这东西到底能不能便宜地造出来。三者对齐的时候，他就有了信念。

马斯克的回答把源头指回了少年时代。他说自己有一种对真相的执念，病态程度的执念。所以去学物理，因为物理研究的是宇宙里可以被证明的真理，而且是有预测能力的真理。没人逼他学，是内在的兴趣。

然后是计算机科学和信息论，用来理解逻辑。他甚至提到一种观点：信息论可能比物理更基础。

42 是个玩笑，问题才是正经事

十几岁的时候，马斯克陷入过关于生命意义的抑郁。他读宗教文本，读哲学，还读了一堆德国哲学家。他说十几岁读德国哲学绝对不明智，会掉进很黑的地方。

救他的是《银河系漫游指南》。这本书看着是搞笑，其实是本伪装成笑话的哲学书。

这场访谈真正给出的东西

把 80 分钟的对话压缩成一条线，马斯克展示的其实是一套可复用的思考方式，跟他的具体项目关系不大。

可以马上做的事

  • 把手上那个一直推不动的项目拿出来，问一句：卡住的到底是表面问题，还是它底下那个一直不愿承认的更难的问题。马斯克花了六年才承认自动驾驶的地基是真实世界 AI，你不用花六年。
  • 下次给团队定目标，允许自己把时间表说得激进一点。但配套做一件事：把「可能是假曙光」写进计划里，每三个月检查一次是不是撞到了对数曲线的平台期。
  • 如果做产品，把「算法可解释」当成一条硬指标。用户能不能看见自己的内容被加强还是被压制，这个体验差距会越来越值钱。
  • 评估任何自动化或 AI 工具的价值时，用马斯克那笔账的算法：一次性成本，对上被替代的年度人力成本，再加上工作时长和不休假的系数。算完再决定要不要上。
  • 如果你对某个领域有执念，别急着把它当成缺陷。马斯克把「整夜一个人敲奇怪符号」这件事说成享受，很多人只是没找到自己愿意整夜敲的那个东西。
  • 找一本你以为只是搞笑的書重读一遍。《银河系漫游指南》在马斯克这里是本哲学书，有时候答案不重要，把问题问对才重要。
