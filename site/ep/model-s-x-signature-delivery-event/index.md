2026 年 6 月，弗里蒙特工厂总装线的尽头，最后一批 Model S 和 Model X 交到了车主手里。14 年前，同一块竹地板上摆的是第一批车。

开场短片里有人问：Model S 到底是为了什么？回答只有一句，为了打破一个咒语。

这样一个靠一台车改变行业认知、拿过《Motor Trend》年度车、还被这本杂志评为"史上最好的车"的产品，在全球电动车渗透率冲到 17% 的这一年被停产了。

马斯克、设计负责人 Franz von Holzhausen、车辆工程负责人 Lars Moravy 三个人在生产线的末端聊了将近一个小时。气氛介于追悼会和发布会之间：前半段回忆 14 年前怎么从零造车，后半段宣布这条线要改产机器人。

## 那个咒语叫"电动车等于高尔夫球车"

2010 年前后，公众对电动车的印象是：慢、续航短、难看、不好开。马斯克在台上的形容是"一台加上了华丽装饰的高尔夫球车"，开它像穿着一件苦行僧的毛衣，你必须牺牲掉一点灵魂，才配得上"环保"两个字。

这个印象不是靠广告能改的。它需要一台真车，一台人们愿意为了它本身而买、而不是为了补贴和环保道德而买的车。

> 「我们做 Model S 的目标，从来就是造出最好的车，任何类型里最好的车，而不只是最好的电动车。」（马斯克）

这句话在当时听起来像吹牛。一家从没造过整车的公司，要在 18 个月内做出一台能和豪华轿车抢市场的车，还要拿年度车。

结果它拿到了。而且不只是当年度的年度车，后来还被评成"世纪最佳"级别的车。马斯克说这话的时候，语气里带着一种"我也没想到能这么顺"的意外。

## 一支车库乐队，站在温布利球场里演出

Model S 的设计是在 SpaceX 工厂后面的一角开始的。特斯拉当时没有设计工作室，也没有工程中心，团队小到可以挤进一个帐篷。

每个周五，他们把 1:1 的油泥模型推出来，一路推过 SpaceX 的厂房，推到 Jack Northrop 大道路边，就为了在自然光下看一眼车身比例对不对。路过的车都能看见他们在干什么，没人关心。

Franz 用的比喻很准：一支车库乐队，站在温布利球场里演出。心里要征服世界，台下没有观众。

这台车还是特斯拉第一台从头自己造的车。更早的 Roadster，除了动力总成，车身是路特斯（Lotus）做的。电机、电池包、充电机这些电气部分归特斯拉，剩下的归别人。

所以当年有人问马斯克：一家从没造过整车的公司，要造出一台能拿年度车的车，成功率多少？

> 「我说实话，这个概率很低。不过我们打算试一把。」（马斯克）

这段话里有个细节值得留意。他没有说"我们算过，成功率 30%"。他说的是"很低，但我们打算试"。很多后来被证明正确的决定，在做出的那一刻并不具备可论证的胜率，只有一个愿意承担失败的团队。

## 没有市场调研，只有"我自己想要什么"

团队没有做焦点小组，没有发问卷，也没有请咨询公司。产品定义的方式非常土：把自己想要的东西列出来，塞进车里。

空气悬挂要不要？要。大屏要不要？要。就这么定了。

这个决定在 2012 年是疯的。那时候车里没有大屏这个东西，iPad 还没发布。特斯拉只能用给笔记本电脑做的屏幕和零件，然后自己写软件让它跑起来。

十四年后，几乎每台车中控都有一块屏，没人觉得稀奇。稀奇的是第一个做这件事的公司，连驱动屏幕的软件都得从零写。

另一件被全行业抄走的东西是整车 OTA。车越用越新，这在 2012 年听起来像开玩笑。马斯克说他开了哥哥那台最早的创始人版，编号在前 20 台以内，本来以为会一身毛病，结果开起来还挺好。

> 「那些老车今天比我们刚交付的时候更好用。很大一部分原因就是它能持续升级。」（马斯克）

"不做市场调研"这句话容易被误读成不听用户。他们真正的做法是：把"我自己也是用户"当成最可靠的需求来源，然后用 OTA 和快速迭代去修正判断错误。前者负责方向，后者负责纠偏，两件事缺一不可。

传统车企很难复制这套流程，原因不在技术。实体按键背后是一整条供应链、一套沿用了三十年的人机工程规范、还有经销商的反馈机制，每一样都在把人往回拉。没有历史包袱，反而成了特斯拉当时唯一的优势。

## 用爱设计出来的产品

全场最不像企业家发言的一段，是马斯克解释 S 和 X 为什么能成。

> 「那些车是用爱设计出来的。每一个细节，包括大部分人看不见、甚至不知道存在的部分。我们放进去，是因为我们爱这个产品。」（马斯克）

他接着说，这跟爱孩子是一个道理。你不会用一张表格去衡量该怎么对孩子好，你就是会把事情做到那个份上。用户看不见全部细节，但能感觉到。

这段话如果单独摘出来，很像鸡汤。放在现场语境里就不一样了，因为说这话的人刚刚报了一串数字：97% 的零件在 14 年里被换过，整车零件数量比初代少了 40%。

持续 14 年给一台车做这种强度的迭代，没法靠 KPI 驱动。KPI 会告诉你"这个车型已经到生命周期末端了，别再投入"。只有真的在意那台车的人，才会在第 12 年还在改一个没人看得见的支架。

他给所有做产品、做服务的人的建议，也就一句：做你真心喜欢的东西，客户能感受到那份喜欢。

## 97% 的零件被换掉，产能翻了两个数量级

今天下线的 Model S 和 Model X，只有 3% 的零件还是当年那批。外观看起来只是几次改款，工程上早就不是同一台车。

产能的变化更直观。Lars 回忆 2015 年 12 月 31 日，他们在厂门口连夜交付 500 台 Model X，全公司像过年一样庆祝。今天同样的数量，6 个小时就干完了。

弗里蒙特工厂连续四年是全球产量最高的汽车工厂。这条线现在要改产 Optimus。

现场还专门谢了供应商。这个致谢不是客套，后面讲电池的时候能看出来，特斯拉早期真正的瓶颈几乎全在别人的产能表上。

## 从 0.1% 到 17%，前五年看不出趋势

Model S 量产那几年，全球在售的电动车几乎是零，销量占比不到 0.1%。上个季度，这个数字是 17%。

挪威现在新车绝大多数是电动的，中国的新车里有接近一半是电动的。马斯克在台上专门谢了这两个国家。

他当年被反复告知两件事：一，长续航的电动车造不出来；二，就算造出来，也没人买。

他的回答是，如果车真的够好，人自然会买。他顺手调侃了一句：总有人说人们太爱汽油了，不会看电动车一眼，可没人往手机里加汽油。

这句话背后是个挺硬的判断。消费者爱的从来不是汽油，是汽油能提供的体验：随时能加、跑得远、不用等。当电池把这三件事都解决了，剩下的只是时间和价格。

0.1% 到 17% 这条曲线最容易骗人的地方在于，它在最初五六年几乎是平的。站在 2013 年看，没人能确定这是个趋势还是个笑话。

## 电池的真正瓶颈，写在别人的产能表上

锂离子电池是另一个卡点。当年的全球锂电池产能是按手机市场规划的，喂不饱一台车。

特斯拉做的事是说服供应商扩产，扩到他们觉得"这辈子不可能有人用掉这么多"的程度。内华达的超级工厂建成后，基本把全球锂电池产能翻了一倍。

Lars 说，电池和电驱这条能力，后来撑起了储能、超充，甚至 Optimus。起点就是 Model S 的电池包。

效率的数字也在这条线上滚动。Lars 报了一个数：现在特斯拉有车型的能耗做到 165 瓦时每英里，大约是初代 Model S 的一半，是通过认证并量产的车里最省电的。

从 300 多瓦时每英里降到 165，这个进步幅度比大多数人以为的要大。它不来自某一项突破，来自电驱、电控、热管理、风阻、轮胎十几个环节每年各降几个百分点。

## Model X：汽车里的法贝热彩蛋

Model X 被马斯克叫作"汽车里的法贝热彩蛋"（Fabergé egg）。他承认这台车某种程度是傲慢的产物：鹰翼门、六座布局、一直延伸到后排头顶的全景风挡，每一项都在给自己找工程麻烦。

车上有很多小机关，很多人开了几年都不知道它们存在。

这台车在台上的评价是"不可思议"，也是特斯拉证明自己能把极端设计做成量产的证据。它卖得比 Model S 少，但把一堆后来用在别的车型上的技术提前验证了一遍。

## 为什么停产一台还在赚钱的车

台上有人替所有人问出了这个问题：这么好的车，为什么要停？

马斯克的回答很直接：因为有了更好的东西。未来的方向是自动驾驶。

他的判断是，随着时间推移，绝大多数汽车不会有方向盘和踏板。自己开车会变成今天的骑马：有人骑，但基本没人骑着去上班。

他还给了另一个理由，很实际：未来二手 Model S 和 Model X 会很值钱。停产加限量版，历来是保值的推手，他把这句话自己说出来了。

从制造角度看，这笔账更清楚。产能是工厂里最稀缺的资源，一条线占着，就意味着另一条线没地方放。Model S 和 Model X 共用一条低节拍产线，年产量和 Model 3、Model Y 差着一个数量级。当一款新产品的预期规模比它大十倍，挪产能只是时间问题。

难的部分不在算术，在情感。Lars 说他 18 年前入职第一天做的就是 Model S，14 年前站在这里交第一批车，今天站在这里交最后一批。他把这件事形容成"把一件好东西交出去，给更好的东西腾地方"。

## 自己开车，会变成骑马

整场活动里，马斯克对未来的判断集中在一点：车的终局是没有方向盘。

这个判断在特斯拉内部并不新，从 Hardware 1 装在 Model S 上那天就开始了。Lars 特意提了这段历史：自动驾驶的硬件第一代、第二代，都是在 S 和 X 上先跑起来的，然后才有今天这套能在大部分场景下自己开的能力。

逻辑上也说得通。一台车 90% 的时间停在车位上，剩下 10% 的使用时间里，绝大部分是重复的通勤路线。当软件能把这段时间接管，车的价值定义就从"驾驶机器"变成"移动空间"，方向盘和踏板自然成了累赘。

对现有车主来说，这个转变有个直接后果：老车的价值不再是机械性能，而是它有没有足够的算力和传感器。这也是马斯克敢说"二手 S 和 X 会很值钱"的底气。

## 这条线的下一批住户是机器人

Fremont 的产线要改产 Optimus。

> 「我的预测是，Optimus 会成为有史以来最大的产品，任何品类里最大的那个。」（马斯克）

Lars 给了更具体的时间表：明年年底前后，弗里蒙特会成为西半球生产机器人最多的地方。产线设备正在德国、多伦多和中西部的自动化团队那里制造，他特别强调那些照片是真的，不是渲染图。

马斯克在台上还开了个玩笑：第一批 Optimus 交付的时候，机器人自己走上台就行，不用人递钥匙。

把这两件事放在一起看，这家公司的自我定位已经变了。S 和 X 证明的是"一家新公司能造出世界上最好的车"，Optimus 要证明的是"同一套工程和制造能力可以搬到车以外"。Fremont 在这个叙事里的角色一直没变：先小批量把新东西造出来，再复制到全球。

## 签名版：签名红，白内饰，没有明天

为了纪念，特斯拉做了一批签名版（Signature Edition）：复刻当年的签名红车漆，白色内饰，把能给的全给上，数量很少。台上直接交付，念到的名字里有最早的车主、供应商，也有陪了公司十几年的老朋友。

Franz 说他以前总被朋友问，最好的 Model S 什么时候出。他的回答永远是明天，因为明天一定比今天更好。

"这一次没有明天了。这就是最好的那一台。"

马斯克最后致辞的时候玩了个梗。他说本来想说"我的心与你们同在"，但上次这么说惹了麻烦，于是改口说了两遍"爱你们"。

这场活动没有发布任何新车。它做的是一件更少见的事：一家公司公开给自己最重要的产品做总结，同时宣布下一件事比它更大。

对看这篇文章的人来说，能带走的东西大概有这些：

- 想买二手 Model S 或 Model X 的，停产和限量版确实是价格支撑，但老车的风险集中在三电保修期限、中控屏幕老化、门把手和空气悬挂这几处，看车时优先查维修记录和电池健康度，别只看车漆和里程。
- 做硬件产品的，把 OTA 和模块化当成长期能力，而不是首发卖点。14 年换掉 97% 的零件，靠的是当初就把接口和架构留出了余量。
- 做产品定义的，"不做市场调研"不等于不听用户。更可靠的做法是把自己变成最挑剔的用户，再用快速迭代纠偏。
- 判断技术拐点时，记住 0.1% 到 17% 这条曲线在前五年几乎是平的。渗透率没到 5% 之前，任何新品类看起来都像笑话。
- 做供应链的，新品类早期真正的瓶颈往往不在自己工厂里，在供应商的产能规划表上。谁能说服上游为一件"不可能有人用掉这么多"的事扩产，谁就先跑出来。
- 如果接受"自己开车会变成骑马"这个判断，那么驾照、停车位、通勤时间这些资产的定价逻辑会慢慢变。现在不必行动，但值得开始观察。
