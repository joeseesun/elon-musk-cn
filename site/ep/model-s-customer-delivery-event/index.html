Model S 客户交付活动

Model S Customer Delivery Event

2012年6月22日，加州弗里蒙特。特斯拉把第一批Model S交到了车主手里。在交车之前，这款车已经攒下超过10000份订单，而绝大多数下订的人，连方向盘都没摸过，甚至没坐进去过。

一家只造过Roadster这款小众跑车、累计交付约2300辆的公司，现在要交出一辆真正意义上的四门豪华轿车。它押上的赌注是：电动车可以成为世界上最好的车，而不只是环保人士的妥协方案。

这场交付活动上，加州州长来了，特斯拉的三位核心人物轮流上台：首席技术官JB Straubel（斯特劳贝尔）、首席设计师Franz von Holzhausen（弗朗茨·冯·霍兹豪森）、CEO Elon Musk（马斯克）。每个人的发言都值得细看，因为它们拼出了这家公司当时对电动车的全部判断。

2300个Roadster车主，10000个盲订用户

活动开场，主持人先摆出两个数字。

第一个是2300。这是当时在全球各地开着Roadster的车主数量。主持人说，今天能站在这里，靠的就是这2300个人，“他们教给我们的一切，都装进了Model S里”。

第二个是10000。这是Model S当时的预订用户数。主持人专门强调了这句话：“他们中的大多数人，从来没开过这款车，甚至没坐进去过。”

这句话的分量在时间点。2012年，电动车在全球范围内仍然是边缘产品，续航焦虑、充电设施、电池安全，每一个问题都被反复质疑。在这种环境下，10000个人愿意为一辆还没量产的车付订金。他们手里没有任何试驾体验，唯一的依据是对这家公司的信任。

主持人说，代表所有Roadster车主、Model S预订者、以及在场的和线上的每一位员工，他只想说三个词：“We did it.”（我们做到了。）

这句话背后站着一个隐含的对手。他说，过去几年里有太多人断言“这一天永远不会到来”。特斯拉的处理方式很干脆：不去想这些人，只想那些让这一天成为可能的人。

加州州长站台：这从来算不上常规生意

第一个上台的嘉宾是加州州长杰里·布朗（Jerry Brown）。他的发言里有一句关键判断：

“在把特斯拉做起来的人眼里，这从来算不上常规生意。它需要巨大的勇气、巨大的风险承担、大量的资金，当然，也离不开政府的帮助。是我们所有人一起做成的。”（杰里·布朗）

他主动提到了外界的批评。美国其他一些地方的人喜欢拿加州开玩笑，说加州不知道怎么把事情做成。布朗的回应是：不管是硅谷、特斯拉、医学研究还是环境议题，加州确实有自己的问题，但你们所在的地方，正在引领这个国家，甚至引领世界。

他把这款车定义成“胆识的又一个例子”，还讲了一句挺有意思的话：“我很高兴别人花钱造出了好东西。”他特别提到，政府、企业、银行和投资人、以及真正把东西造出来的工人，这几环缺一不可。用他的原话说，最后把东西变成现实的，是干活的人。

这番话说得客气，指向却很明确。2012年的特斯拉刚从美国能源部拿到贷款，外界对“政府补贴电动车”的争议正大。州长站在交付现场，等于给这件事做了一次公开背书。他临走时还留了一句祝愿：希望这些车先按千辆来，再按万辆来，然后是十万辆、百万辆。

斯特劳贝尔：九年前的一个简单想法

接下来上台的是JB Straubel，特斯拉联合创始人兼首席技术官。他负责的是整辆车的动力系统。

他回顾了公司的起点：大约九年前，几个人抱着一个简单的想法出发，要建立下一家伟大的美国汽车公司，造出世界上最好的车，而且是不烧一滴石油的车。

注意他的措辞顺序。他先说“最好的车”，然后才补了一句“不只是最好的电动车”。这个顺序在整场活动里反复出现，是特斯拉当时最核心的话术，也是它和传统车企最大的分野。

斯特劳贝尔说，到了今天这个节点，可以毫不怀疑地讲，这两件事都做到了。但比看到车下线更让他骄傲的，是这支团队本身。特斯拉当时刚刚突破2000名员工，他称之为一个相当了不起的里程碑。

他把特斯拉的组织逻辑讲得很清楚：把世界上最聪明、最有动力、最优秀的一批人聚在一起，扔到一个足够难的问题上，然后放开手，让他们的创造力、好奇心和兴奋感自由发挥，同时给一个非常明确的任务：让交通变得可持续，造出世界上最好的车。

这段话听起来像管理学鸡汤，但放在2012年的汽车行业里，它确实是个异类。传统车企的研发流程是层层审批、平台复用、成本控制优先，而特斯拉当时的做法更接近硅谷创业公司：先钉死一个极端目标，再倒推技术路径。

冯·霍兹豪森：四年前那颗红色药丸

设计师Franz von Holzhausen的上台方式很特别。他用了《黑客帝国》的梗。

四年前，他走进霍桑市一座火箭工厂里的一个小房间，坐在一个人面前。那个人伸出拳头说：你可以选蓝色药丸，也可以选红色药丸。他选了红色，掉进了兔子洞。他看着台下的观众说：“看看今天现场这么多红色，你们大概也都选了红色。”

那个伸出拳头的人是马斯克。那次会面之后，两个人开始讨论Model S应该长成什么样。Franz说，马斯克当时给了他一张清单，上面列的东西“按任何想象都不等于一辆轿车”：

  • 能坐七个人
  • 最好的空气动力学效率
  • 最低的重心
  • 市面上所有轿车里最快的零到六十英里加速
  • 最强的功能性
  • 而且必须是世界上最好看的车

Franz当时的反应是：“天哪，我是不是选错药丸了。”

他回到那栋大楼后面的一顶小帐篷里，那里只有四个人。2008年，他们就在这种环境里开始雕塑一款车，目标是挑战世界上最好、最大、最强的对手。八个月后，他们拿出了原型车，命名为Model S。

三年多之后，站在交付现场，Franz逐条核对了那张清单：最安全的轿车、能坐七个人、空气动力学效率最高、重心最低、比一些跨界车还实用、而且可能是市面上最好看的轿车。他说自己可能有偏心，但每一条都兑现了。

他最后讲了一句话，算给整场活动定了个调：“如果这就是我们的起点，那我们要去的地方得有多远。这个兔子洞很深。”

马斯克：Model S 要打破一个魔咒

马斯克上台后，第一件事是解释这款车为什么存在，性能参数留到后面再说。

“Model S 到底是为了什么？它是为了打破一个魔咒。这个世界一直有一种幻觉，认为电动车不可能和汽油车一样好，认为你如果选择电动车，就是在接受一个更差的产品。Model S 根本上的意义，就是打破这个幻觉。”（马斯克）

他把话说得很直白：一辆电动车完全可以成为世界上最好的车，这才是这款车真正重要的地方。

接着他列了“每一个重要维度”：性能、安全、操控、内饰、技术、交互界面、造型美学。他的判断是，Model S 在每一个维度上都做到了根本性的更好，而这归功于特斯拉的团队。

这段话要放回2012年的语境里理解。当时市面上能买到的电动车，绝大多数由小型车改装而来，续航短、性能弱、内饰廉价。消费者对电动车的印象就是“为了环保牺牲体验”。马斯克做的事，是把因果关系倒过来：消费者买它的理由，应该是它本身足够好，环保只是顺带的结果。

这个逻辑后来成了特斯拉整个产品战略的底层代码。从Model S到Model 3到Model Y，每一款车的第一卖点都落在性能、智能、设计上。环保被放在了结果的位置，理由在别处。

感谢名单里藏着的产业信号

马斯克接下来念了一长串感谢名单，这段内容信息量很大，值得逐条看。

他先感谢了特斯拉内部的核心成员：负责技术的JB Straubel，负责整体产品、美学和交互体验的Franz von Holzhausen，负责制造的Shu和Doug，Model S项目负责人Jerome，以及负责财务的Deepak。他说这是一次“不可思议的团队努力”。

然后他感谢了美国国家公路交通安全管理局（NHTSA）的一位代表。原话是：

“我们和NHTSA共享一个目标，就是让汽车交通变得安全得多。我们希望通过Model S在汽车安全领域树立一个新标杆。”（马斯克）

这句话后来被验证了。Model S在NHTSA的碰撞测试中拿到当时最高的安全评级，成为第一款获得五星评级的电动车。马斯克在交付现场就埋下了这个伏笔。

他还感谢了美国能源部，以及一位叫Mike Mates的代表。他说：“我们希望真正对得起能源部，证明当初的支持是有道理的，证明这里产生了实实在在的好处。”

这段感谢并非客套。特斯拉在2010年拿到能源部4.65亿美元贷款，这笔钱是Model S能够量产的关键。2012年正值美国大选年，政府对新能源企业的贷款被反复攻击，特斯拉需要公开证明这笔钱花得值。

这座工厂曾经雇佣5000人

马斯克专门讲了工厂本身的历史。这个厂区在还叫NUMMI（新联合汽车制造公司）的时候，曾经雇佣过5000人。那是丰田和通用合资运营的工厂，2010年关闭后被特斯拉买下。

特斯拉当时有2000名员工，马斯克说，长期目标是超过NUMMI当年的雇佣规模。他特别提到，特斯拉雇了很多前NUMMI的工人，想证明一件事：高科技制造业、汽车制造业，可以在加州做，甚至可以在湾区做，而且能造出世界上最好的车。

这段话针对的是当时美国制造业外流的普遍焦虑。很多人认为汽车制造只能去劳动力便宜的地方，加州这种高成本地区做不了。马斯克在交付现场给出的是一个反例，虽然当时这个反例还很小，只有2000人。

这个反例的分量得放到更长的时间轴上看。NUMMI时代的5000人是流水线上的规模制造，而特斯拉当时招进来的是工程师、软件开发者、电池专家和设计师混编的队伍。用同样的厂房、同样一片土地，做的是另一种制造业，这是马斯克真正想展示的东西。

交付仪式：车钥匙是一辆微缩的Model S

讲完这些，交付正式开始。

马斯克先介绍了“特斯拉个人交付”这个概念：车可以送到任何让你微笑的地方。家里、办公室、度假的酒店，甚至有人要求在迪士尼乐园交车，因为那里让他们微笑。第一批三辆车就是用来测试这个服务的，两辆发往伊利诺伊州芝加哥，一辆发往加州帕洛阿尔托。

接着是发钥匙环节。第一位车主是Jeff Skoll，eBay前总裁、慈善家。马斯克把钥匙递给他，顺便展示了这把钥匙的设计：

它是一辆微缩版的Model S。按后备箱位置，后备箱打开；按前备箱位置，前备箱打开；按引擎盖位置，车门解锁。整车造型就是钥匙造型。

这个细节在当时的汽车行业里相当罕见。传统车钥匙是一个塑料方块加几个按钮，特斯拉把它做成了一个品牌符号。这种对细节的处理方式，后来成了特斯拉产品的标志性特征。

接下来上台的车主包括Nancy、Billy、Tim Draper（风险投资人、德雷珀大学的创办人）、Constantine。Nancy在台上说了一句挺动人的话：“这辆车是献给马斯克和整个特斯拉团队的，我们为你们骄傲。谢谢你们造出一辆漂亮的车，谢谢你们造出一个我们可以为之骄傲的未来。”

Tim Draper的发言更直接：“谢谢你们所有人造出这辆不可思议的车，太棒了。也希望你们将来能成为马斯克那样的人，这家伙太厉害了。”

最后所有人上台合影，州长也上来了。主持人喊“三、二、一”，全场一起喊“Tesla”。

这场交付真正改变了什么

回看这场2012年的活动，它没有发布什么惊人的新技术，没有公布什么激进的产量目标，整场氛围更像一场公司内部的庆功会。但它标记了一个转折点。

在此之前，电动车在主流认知里是一个细分品类，是环保主义者的选择，是政策驱动下的产物，是“虽然不方便但为了地球忍了”的妥协。Model S要做的，是把这套叙事整个换掉。

马斯克在台上讲的那句话是整场活动的核心：“这个世界的幻觉是，电动车不可能和汽油车一样好。Model S 就是为了打破这个幻觉。”

从结果看，这个判断后来被市场验证了。Model S在2013年拿下美国豪华轿车销量冠军，超过奔驰S级、宝马7系和奥迪A8。一款起售价超过7万美元的电动车，在传统豪华车最核心的价格带里赢了。

更重要的变化发生在认知层面。2012年之后，整个汽车行业开始认真对待电动化，传统车企陆续发布电动车规划，电池成本开始快速下降，充电网络开始铺开。这条曲线的起点，很难说不是这场交付。

回头看那三个上台的人，各自讲的东西其实拼成了一套完整的逻辑。斯特劳贝尔讲的是为什么做这件事，把能源从石油里解放出来；Franz讲的是怎么把互相冲突的需求塞进同一个车身里；马斯克讲的是这件事对消费者意味着什么，把购车理由从“环保”换成“更好”。技术、产品、市场，三块拼图缺一块都不成。

给今天读者的三个可操作结论

这场十三年前的活动，对今天做技术、做产品、做内容的人，仍然有几个可以直接拿走的东西。

  • 把“品类劣势”重新定义为“品类机会”。当年所有人都在讨论电动车的短板，特斯拉选择把话题换成“电动车能不能成为最好的车”。当你在一个被普遍看衰的领域里做事，最重要的动作是换掉评价坐标系，别在旧坐标系里辩解。
  • 先钉死极端目标，再倒推技术路径。马斯克给Franz的那张清单，七座、最快加速、最低重心、最高空气动力学效率，每一条单独看都和其他条冲突。设计师的本能是砍需求，Franz的做法是回到帐篷里从零开始想办法。很多产品的平庸，是从“这个做不到”开始的。
  • 细节是品牌最便宜的广告。一把车钥匙做成一辆微缩的车，成本不高，但每个拿到钥匙的人都会拍照、都会讲给别人听。在产品同质化的阶段，能被用户主动传播的细节，比任何广告投放都有效。

最后提醒一句。这场活动最值得记的东西，藏在台下那10000个盲订用户身上。在任何行业里，愿意在你还没证明自己之前就下注的人，永远是最稀缺的资产。识别他们、兑现承诺、别让他们后悔，这件事比任何技术突破都更能决定一家公司能走多远。
