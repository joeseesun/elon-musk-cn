桑迪·芒罗（Sandy Munro）拆过几乎所有在售的电动车。2021 年他开着一台 Model 3 跑了几千英里，在镜头前说了一句很重的话：这套座椅是地球上最好的，没有之一。

同一场对话里，马斯克回忆起早期 Model S 的座椅，说他坐过的车里没有比那更糟的。"如果你想要坐在一个石头做的蘑菇上，那就是早期 Model S 的座椅。"

从石头蘑菇到地表最好，中间隔了差不多十年，也隔着一堆外人看不见的麻烦。

这场一对一访谈发生在 SpaceX 位于德州博卡奇卡的基地。芒罗刚参观完火箭产线，进门时看到一行字，"通往火星的门户"。两个人从座椅聊到一体压铸，从自动驾驶聊到做空机构，把特斯拉当时的工程路线和马斯克本人的判断都过了一遍。

芒罗是那种很少给好评的人。他做了一辈子制造，看车的方式跟普通消费者完全不同，先拆，再量，然后算成本。所以他说"最好的座椅"时，分量不太一样。

## 产能爬坡期买特斯拉，等于抽盲盒

访谈刚开始，芒罗就抛出一个具体到有点尴尬的问题。

他手上这台 2021 款 Model 3 有些小毛病，而他在路上遇到的另一台白色内饰的 Model 3 完美得挑不出错，"随便谁来做也就这个水平了"。两台车出厂时间只差一个月。

马斯克的回答没有绕：**"把生产线拉起来的那段时间，几乎不可能把每个小细节都做对。"**

他给了一个很实用的说法。朋友问他什么时候该买特斯拉，他的建议是：要么在最早期买，要么等产能稳定之后买，中间的爬坡阶段别碰。

原因不复杂。产线在垂直爬升的时候，所有参数都在变，而很多参数之间的耦合关系，只有真正跑起来才暴露。

马斯克举了漆面的例子。产线提速之后，原本留给漆面多烘干一两分钟的时间没有了，漆没干透就被推到下一道工序，出问题的概率直接上升。

"如果这些事我们提前知道，就会提前解决。但产线一提速，问题才自己冒出来。"

他也承认芒罗过去那些批评都是准的。Model 3 上一边缝隙对得上、另一边对不上，这种事确实发生过。改善发生在 2020 年底，甚至就在 12 月这一个月里，团队把注意力集中到缝隙和漆面上，质量提升了一大截。

这里有个容易被忽略的背景数字。**特斯拉是过去一百年里，第一个实现量产规模的美国新造车公司，上一个做到这件事的是克莱斯勒。**

马斯克对这件事的表述很直接：原型车相对容易，而且好玩；把一款可靠的产品以可负担的价格做到量产，痛苦到难以形容。

芒罗接过话头说，他 2018 年拆过一台 Model 3，后来拆 Model Y，那时候有人问该买哪台车，他第一次开口推荐了 Model Y。现在这台 Model 3 让他愿意给出第二个推荐名额。

一个拆车老炮愿意点名推荐，比任何广告都值钱。

## 座椅为什么必须自己做

芒罗对座椅的评价近乎失控。他说自己开吉普牧马人，在那种座椅上坐一小时就得去找脊椎按摩师，可能还得动手术；而他们在特斯拉座椅上连续坐了几个小时，一点疲劳感都没有。

马斯克解释了设计目标：**把压力峰值抹平。**

屁股疼的原理很朴素，座椅某个局部顶着你的身体，形成压力峰值，把那一块的血液循环切断，疼就来了。所以座椅设计真正要做的事，是让压力均匀铺开。

他顺手自嘲了早期产品。早期 Model S 的座椅糟到什么程度？他打了个比方，坐上去像坐在石头蘑菇上，唯一的希望是你的身体能自愈，座椅不能。

转机来自设计部门。弗朗茨·冯·霍尔茨豪森（Franz von Holzhausen）的设计工作室做了一把定制座椅，马斯克坐进去，第一反应是"这椅子太棒了"。接下来的问题变成了工程题：怎么让量产座椅拥有手工定制的手感，又不能太贵。

答案是自己做。

芒罗提到，很多主机厂不愿意自己做座椅，理由是应该外包。他的观点相反，凡是人手要接触的部件，都该自己做，那才是知识沉淀的地方。

马斯克同意了，还补了一层原因：**跟供应商合作，几乎不可能做出这种效果。**

供应商的逻辑是快速出货、摊薄成本。他们会把底下的骨架，那些焊接件或者铸件，反复复用到所有客户身上。结果就是各家座椅外面看起来千差万别，里面几乎一样。你没法要求供应商为你的手感重新开一套骨架，成本不允许。

自己做还有第二个好处，可以持续迭代。今天这套座椅相比早期 Model 3 已经改了很多轮，每一轮都能把上一轮的教训吃进去。

## 自动驾驶的头号指令：不许撞

芒罗抛出的下一个问题是路。

他试用了 beta 版自动驾驶，发现出问题的地方不在车上：有些路段根本没画线，有些路段线画在正中间，有些地方旧匝道和新匝道叠在一起，锥桶和闪烁的红灯混成一团。他的原话是，如果让他自己开那段路，他都不知道该往哪走。

车子跟着地上的线走，把他吓得不轻。他后来说，那之后他干脆不走最右车道了。

马斯克的回应定了一个原则。

> "即使路面标线完全画错，即使一个 UFO 停在马路中间，车也不能撞上去。自动驾驶系统的首要指令是不撞车，这条盖过一切。"（马斯克）

他不否认清晰的标线有帮助，但系统不能依赖标线正确。有人会故意去骗这辆车，车不能被骗过去。**安全性必须建立在最坏的路况和最怪的人类行为之上。**

马斯克还告诉芒罗，右侧车道偏好是可以改的设置。芒罗当场表示回去就要关掉。

接下来是全场情绪最高的一段。

芒罗体验了当时的 FSD beta。他说自己坐过 F-18 的座舱，也在模拟器里飞过 C-17，知道自动驾驶能干什么不能干什么，但从没见过这种东西。他的评价是：比 Model 3 上现有的版本准得多，风格甚至有点激进，前面有缝它就钻，能自己完成左转，而左转是很多人咬定做不出来的动作。

他给出了一个很大胆的判断：这套系统救下的人命，会比安全带、安全气囊和过去所有汽车安全发明加起来还多。

数字支撑得住这个判断。**全球每年大约有 100 万人死于交通事故，约 1000 万人受重伤。**这是人类自己制造的最大非自然死亡来源之一。

但马斯克对推送给全部车主这件事异常谨慎。他描述了一个危险的中间状态：系统 99.9% 的时间表现很好，好到让人放松警惕，可它偏偏处理不了剩下的边角情况。人在这种状态下最容易出事。

所以他宁可多测一段时间。**把半成品交给用户，比晚一点交付更危险。**

## 代码行数是负资产

芒罗问了一个工程师式的老问题：这套系统有多少行代码？

马斯克的回答让提问者有点意外。他不认为代码行数是衡量好坏的标准，恰恰相反，他倾向于认为行数多是坏事。

他给出的内部记分规则很具体：**删掉一行代码加两分，增加一行代码加一分。**

在神经网络主导的系统里，这个指标更没意义。真正跑的是海量的矩阵运算和点积，代码行数跟能力之间没有对应关系。他估计整套系统也就几十万行，而且他希望更少。

这个思路跟芒罗的"减少零件"是一回事。芒罗很多年前数过轮罩区域有多少个零件，结论是这里应该是一个整体。两个人在这件事上碰了一下，后面的对话就全绕着这个展开了。

## 五十个各自正确的答案，拼出一个弗兰肯斯坦

马斯克对轮罩区域那段历史的复盘，是整场访谈里信息密度最高的部分。

问题的起点听起来完全合理。工程师会问：做这一小段车身，最好的材料是什么？做那一小段，最合适的工艺是什么？

特斯拉的材料科学团队可能是全世界最强的，很多人同时在 SpaceX 干活。所以他们给出的每个答案都成立，**50 个答案单独看全对，合在一起不成立。**

马斯克用了四个字概括这类错误：对错误问题的正确答案。

后果是一连串连锁反应。异种金属接在一起，会产生电偶腐蚀，得加密封；不同材料之间的缝隙得填；有些地方必须用铆钉，有些必须点焊，有些得用结构胶配合点焊。凑在一起看，像一具弗兰肯斯坦。

最痛苦的是填缝。马斯克说，在缝隙之间打密封胶可能是整个工厂里最折磨人的工位。工人干上几个小时，手上稍微抖一下，胶固化出了一点瑕疵，就留下一个小孔，整车密封性出问题，直接变成质量事故。

他用了一个更根本的说法：**组织结构的错误，会原封不动地印在产品上。**车身被切成那么多小块，是因为组织里就有那么多各自为政的小组。

解法是把它变成一个铸件。

没有缝隙，不用打胶，没有异种金属，车身车间可以大幅缩小。具体数字是：Model Y 的后车身一体铸件，让车身车间面积减少了 30%。Model 3 的车身线上大约有 1000 台机器人，仅后铸件这一项就砍掉了 300 台；等到前车身也改成铸件，还能再砍 300 台。

马斯克特意强调，机器人数量也不是什么值得炫耀的指标，越少越好。

芒罗听到这里情绪上来了。他自己的车间里摆着一套前、中、后三个铸件，摆了 15 年。这些年无数工程师和高管路过，都会说"这个想法不错"，然后没有一个人真去干。原因是他们已经把身家押在车身车间上了。

他唯一的不满，是特斯拉没在 Model 3 上就这么干。

马斯克的解释是关于节奏的。Model 3 和 Model Y 是主力产能，是在高速公路上以 80 英里时速跑着的车，你没法边跑边换轮胎。**要重做工厂，需要一个不会炸掉公司现金流的窗口。**柏林和德州的新工厂就是这个窗口。

新工厂的三件式结构是：后面一个铸件，前面一个铸件，中间是结构电池包。

## 今天的电芯，是按一袋土豆的方式在运输

结构电池包是马斯克说他从公司创立之初就想做的事，一直拖到 2021 年才动手，因为它是个耦合问题。

在高速研发阶段，工程团队习惯把问题拆开：电池归电池，车身结构归车身。合在一起做，任何一头出问题都会拖垮另一头，等于把整家公司押上去。现在 Model 3 和 Model Y 稳产了，新工厂在建，才有本钱把两件事捏到一起。

马斯克对现状的批评很尖锐。**今天所有车里的电芯，都是被当成一袋土豆运着的，它们的结构价值是负的。**

负价值有两层。一层是电芯完全不为车身刚度做贡献；另一层是它们必须被隔离起来，防振动、防冲击，否则电芯会撞上电池壳体内壁。

为了这个隔离，你得往车里塞额外的质量。质量本身又拖累了续航和操控。

结构包的做法是把电芯用泡沫粘死，让电芯本身承担剪切载荷。那层粘接泡沫同时扮演两个角色：胶，以及阻燃剂。**一个零件干两件事。**

为什么能变硬？马斯克用复合材料打比方。上下两张碳纤维蒙皮中间夹一层铝蜂窝，重量没增加多少，弯曲刚度暴涨。电池包的上盖和下盖就是蒙皮，中间密密麻麻的电芯圆柱壳就是蜂窝。

芒罗补充说，他自己拿木块做过演示，在电池日之后放了段视频，解释载荷怎么传递、为什么更安全。那是他们频道播放量最高的一期，因为一堆人跑来告诉他这事行不通。

刚度带来的是驾驶感受。马斯克把几个概念串起来讲：车身的自然频率高、扭转刚度好，开起来就"紧"；质量越往中间集中，极性惯性矩越小，转向越利落。

他给了个所有人都能懂的画面：花样滑冰运动员把手臂收起来，转速立刻就上去了。

芒罗的总结比马斯克还狠。他说这不是一箭双雕，是一箭三雕：车身刚度上去了，零件数量下来了，安全性也上去了。

## 为什么大型铝铸件不能淬火

聊到一体压铸的具体工艺时，马斯克讲了一个很少有人提到的材料难题。

铝铸件想要获得好的力学性能，通常需要热处理，有时还要水淬。问题是，**一个一米多长的薄壁铸件一旦经历剧烈淬火，就会像薯片一样翘曲。**他用的词是"变成椒盐卷饼"。

老款 Model S 的前后铸件就吃过这个亏。它们必须热处理，于是尺寸没法做大，一大就变形，没法量产。

解法是自研合金，让材料在铸态下就能拿到足够的强度和延展性，跳过所有会让零件变形的后处理。延展性同样重要，因为它决定了碰撞时材料是断裂还是变形吸能。

芒罗在这段里插了一句感慨：他跟人说大型铸件充型只要四到六毫秒，没人信，因为大部分工程师没学过材料。

马斯克接得很快。他在斯坦福读研时本来要去的就是材料科学系，后来把这个计划搁置， фактически 退学了。他说材料科学是工程学科里最有用的一门课之一。

芒罗提到一个对比。福特在 70 年代末到 80 年代初的那轮收缩里，把材料研发砍掉了，从那以后就不再自己发明材料。其他主机厂也基本如此。

他的判断是：**大厂现在最该做的事情之一，是把这些能力收回公司内部。**电动化之后不再需要发动机厂和变速箱厂那么大的面积，一个小电机加一个单速减速器就够了，腾出来的空间和预算该投到材料上。

## 12 伏是个退化电压

芒罗问线束。他拆 Model Y 的时候本来期待看到大的变化，结果拆下来的线束看着跟以前差不多。

马斯克没有辩解，直接承认这块还有很多改善空间。

他先纠正了电压问题。**12 伏在汽车上是个退化器官。**这个标准来自燃油车时代，早就该淘汰。他主张的低压标准是 48 伏左右，理由很实在：以太网供电（PoE）跑的就是 50 伏上下，手机、摄像头这些设备天天用着，没人觉得危险。车身低压系统完全可以到那个水平。

电压提上去，同样功率下电流就小，导线直径可以大幅缩小。铜是钱，重量也是钱。

更重要的目标是把电力和数据放到同一根线上。现在的车还在用大量点对点的专线，未来应该走高速总线，把数据丢到总线上，让节点自己取。**线束越少，整车越轻，装配越简单，成本越低。**

他也交代了进展。新款 Model S 和 Model X 终于换上了锂离子 12 伏电池，体积更小，容量大得多，日历寿命和循环寿命跟主电池包对齐，"早该这么干了"。

## 从骑马送股票，到做空机构

话题转到做空，马斯克的语气变了。

他先讲了一个历史。做空这件事的起源，是股票凭证还靠人马在城里之间运送的年代。纽约的经纪商要从芝加哥调一张凭证，路上得走三天，为了不让交易卡住，就有人说"凭证正在马上，我保证它到，你先付钱"。这个约定俗成的漏洞，后来变成了一个产业。

他的问题在于，这个漏洞被用在了谁身上。

> "做空今天的使用方式，本质上是针对公众的。绝大多数股东根本不知道做空存在，知道的人里又只有极小一部分懂得怎么用空头头寸获利。这实际上是打着市场效率旗号的对公众的攻击。我个人认为它不道德。"（马斯克）

他提到一个反差：全世界九成以上的公司是私营公司，私营公司没法被做空，可照样运转得很好。所以那套"做空提升市场效率"的说法站不住脚。**恶习披上了美德的外衣。**

特斯拉被这套机制打过两次。一次是 2013 年，一次是 2017 年到 2019 年。他描述的做法叫"做空加抹黑"：先建立空头头寸，然后动用一切手段把公司名声搞臭。他说那段经历的强度大到让人对人类失去信心。

芒罗在这件事上的态度更直接：一群人可以仅仅为了完成本月的业绩指标，就把一家公司碾死，他从来不是做空者的粉丝。

## 领导力不该从商学院空降

芒罗主动提起了马斯克那句关于 MBA 的著名评论，说自己多年来一直是同样的立场：员工想读硕士，公司出钱；想学机械，出钱；想学木雕，也出钱；想读 MBA，一分不给。

马斯克把逻辑讲完整了。

问题不在商学院教的东西，在于一条被走偏的路径。**通往领导岗位的路，应该是一路做有用的事爬上来，而不是读完一个高知名度 MBA 之后空降成老板。**

空降的人往往擅长做幻灯片，讲得很好，但不清楚东西到底是怎么做出来的，也不知道做好产品真正需要什么。

他补了一句限定，说自己没有全盘否定 MBA。他在宾大读的是沃顿本科加物理双学位，对商学院有直接接触，还给本科生和 MBA 当过两个学期助教、批改过作业。

他真正反感的，是那种"我要直接空降当老板，而不是挣来这个位置"的心态。

## 电动车超越燃油车的时间点

芒罗提到通用汽车宣布 2035 年全面电动化，然后问马斯克怎么看拐点。

马斯克说，他几年前就公开讲过，纯电对燃油的交叉点在 2030 年。当时台下不少高管听完跑来跟他交流，而华尔街分析师的预测是 2045 年电动车占比 15% 左右。

现实跑得比分析师快。加州当时的电动车份额已经到 8% 并且在往上走，欧洲开始在政策上直接排斥燃油车。他的修正判断是：**十年之内，多数新车销售会是纯电。**

他顺带说了一句不太客气的话：很多人希望一切维持原样，回到所谓的"过去好时光"。这个愿望跟物理规律没关系。

## 没有自动驾驶的车，会像马一样

访谈快结束时，马斯克给了一个远景判断。

他说，未来一辆没有自动驾驶能力的车，受欢迎程度大概会跟马差不多。马还在，人们还养马，但没人拿马做日常通勤。

芒罗接了个很有意思的梗。他说从前有人喝醉了在马车里睡着，马会自己把他拉回家。从这个角度看，自动驾驶只是把这件事还回来。

马斯克顺着往下讲，说这两件事他们真的打算做进车里：**如果检测到你睡着了，车会直接送你回家；如果检测到你的身体出问题，比如心脏不适，车会直接开去急诊室。**

这一段听起来像玩笑，但背后的数字一点都不轻松。全球每年约 100 万人死于车祸，约 1000 万人重伤。马斯克重复了那句话：得赶紧干。

芒罗最后说，这辈子最让他兴奋的事，是坐在那台车里看风景。以前他只能盯着车道线，现在可以抬头看看周围，手还放在方向盘上，随时能接管。

这句话其实是整场访谈最好的注脚。技术成熟的标志，不是让人惊叹，是让人放松。

## 这场对话能拿来用的东西

- 打算买新势力品牌的车，避开产能爬坡期。要么订最早那批，要么等产线稳定半年以上再下单。中间那几个月，装配一致性最差。
- 评估一家制造企业，别看它有多少台机器人、多少行代码、多少个零件。看它敢不敢把这些数字往下砍。删掉一行代码加两分，增加一行加一分，这个记分规则可以直接搬到自己团队。
- 做产品决策时警惕"对错误问题的正确答案"。每个子系统单独看都最优，合起来是灾难。判断信号很简单：接口处需要大量补丁、密封、转接，就说明切分错了。
- 凡是用户身体要接触的部件，尽量自己做。外包给别人，底层平台会被复用到所有客户身上，你永远拿不到那个手感。
- 遇到自动化系统的边界问题，先看基础设施。路面标线画得乱七八糟，再强的感知也救不回来。系统设计要以最坏输入为前提，不能以环境配合为前提。
- 别在半成品阶段大规模推给用户。99.9% 的可靠性最危险，它让人放松警惕，然后被剩下那 0.1% 干掉。
- 带团队别迷信空降的商业教育背景。让做过实事的人上来，产品里印着的，永远是组织结构的形状。
