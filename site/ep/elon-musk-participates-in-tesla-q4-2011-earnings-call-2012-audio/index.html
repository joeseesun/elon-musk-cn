2012 年初，特斯拉开了一场财报电话会。会上马斯克说了一句话：特斯拉再也不需要融资了。

原话是 "Tesla does not need to ever raise another financing"。他紧接着补了一句，可能会想要融，但不需要。

这句话放在当时听着很狂。2011 年全年，特斯拉经营性现金流是负的 2.9 亿美元上下。Model S 还没交付，工厂刚从丰田手里接下弗里蒙特的旧厂房，第一款真正面向大众市场的车还停在样车阶段。华尔街那阵子天天在算它能撑几个月。

后面一个多小时，分析师轮番追问现金、产能、认证、竞争、电池成本，马斯克的回答基本围绕一个判断：特斯拉已经过了那个最容易死的坎。这场电话会的信息密度很高，很多当年听起来像吹牛的话，后来都被验证了。

Model X 的预订量，超过了 Model S

马斯克开场没聊财报，先聊 Model X。

他的原话是，Model X 是特斯拉历史上卖得最好的产品，而且领先幅度很大。这话有意思的地方在于，Model X 当时只是一台刚发布的概念车，价格没定，配置没定，交付时间也没定，客户只看到几张图和一个轮廓，就掏钱下了订。

我们从客户的角度想不清楚他们会怎么反应，结果 Model X 明显是个全垒打，客户用钱包投了票。（马斯克）

他甚至在电话会上直接做起了销售：如果你对 Model X 感兴趣，建议现在就交定金。

这件事对理解特斯拉的产品节奏很关键。传统车企的逻辑是先做市场调研，再做产品定义，最后定价开卖。特斯拉反过来，先扔一个足够激进的产品出去，看市场反应，反应好就加速，反应一般就调整。Model X 的预订数据，本质上是一次低成本的市场验证。

更反常识的是，Model X 开放预订之后，Model S 的预订量没有下降，反而上升了。分析师专门问了蚕食问题，马斯克的回答是，人们看到你有不止一款产品，会觉得这个品牌更靠谱，就像一家店多摆几个招牌，进店的人反而更多。

从卖电池包，到卖整套动力总成

电话会里最实质的业务进展，是戴姆勒的合作升级了。

此前特斯拉给戴姆勒供的是电池包和充电器。这次马斯克确认，开始为戴姆勒提供整套动力总成，包括电机、电控、电池在内的完整系统。

这个变化的分量比听起来大。卖电池包，你只是供应链上的一个零件商，议价能力有限，客户随时可以换人。卖整套动力总成，你进入了对方的整车开发流程，切换成本高得多，单价也完全不是一个量级。

分析师追问戴姆勒这块业务 2012 年能做多大。马斯克的回答很直接：今年戴姆勒这块的收入，可能超过过去所有交易的总和。

他还确认，除了戴姆勒和丰田，还有别的厂商在谈，但不肯说具体是谁。

这里有个容易被忽略的细节。特斯拉当时对外的定位一直是一家整车厂，但它同时在闷声做供应商生意。整车业务烧钱，供应商业务收钱，两条腿走路。这个结构在 2012 年那会儿救了特斯拉的现金流。

Model S 先交贵的，收入全压在下半年

2012 年的收入指引是 5000 台 Model S，加上 Roadster 在欧洲和亚洲的销售，加上丰田的零部件业务，再加上一些 OEM 的开发服务收入。四块拼起来，构成全年的营收盘子。

交付顺序直接改写收入曲线。

第一批是 Signature 系列，1000 台，几乎把所有选装件都装上了，是最贵的那批车。之后是 300 英里续航版本，再往下是 230 英里版本，最后才是 160 英里的入门版。

这个顺序直接决定了收入曲线。分析师问收入会不会后置，马斯克说会，而且很明显。上半年交的是高配，下半年才放量，全年收入严重偏向后半年。

他还提到一个时间点：配置器（configurator）上线之后，才能真正看清客户到底选了什么。在那之前，所有的订单结构都是估算。

这段对话里藏着一个做硬件的人都该记住的判断方法。看一家硬件公司的收入指引，不能只看台数，要看交付顺序和配置结构。同样是 5000 台，先交顶配和先交入门版，营收能差出几千万美元，毛利率也完全不同。

为什么不怕合作伙伴抢生意

有分析师问了个很尖锐的问题：特斯拉给梅赛德斯做动力总成，梅赛德斯品牌会不会反过来蚕食特斯拉？

马斯克的回答用了两组数字。

第一组是市场规模。全球汽车市场一年大概 8000 万辆，Model S 满产是 2 万辆，占比不到千分之三。特斯拉和合作伙伴加起来在这个市场里都是零头，谁抢谁的生意，这个担心太早了。

第二组是竞争坐标系。他强调，判断 Model S 跟谁竞争，不能把它跟所有电动车放在一起比，那个池子里从高尔夫球车到日产 Leaf 什么都有，没有意义。该比的是豪华中大型轿车和豪华 SUV：奥迪 A6、A8，保时捷 Panamera，宝马 5 系、7 系。

这个坐标系的选择很讲究。把自己放进"电动车"这个类目，你就永远是个小众选项，客户拿你和 Leaf 比价格。把自己放进"豪华轿车"这个类目，客户拿你和 A6 比性能、比配置、比体验，价格敏感度完全不同。

他还提了一个更深的判断标准：如果特斯拉的整车工程跟不上，只剩下动力总成能打，那特斯拉就会退化成一家动力总成公司。这句话说得很清醒，一家公司的身份由它最强的那块能力决定，不是由它自己怎么介绍决定。

研发费用降了，但成本没消失

这场电话会里有一段会计细节，很多听的人会滑过去，但对看懂财报很关键。

2011 年全年研发费用 2.08 亿美元。管理层说，2012 年第二季度开始，每季度会有 1500 万到 2000 万美元的制造相关费用从研发科目转到销货成本（COGS）。

有分析师追问：这算是成本下降吗？

回答是，这不是成本消失，是会计重分类。Model S 进入量产之后，原本记在研发里的试产、工装、制造准备费用，按会计准则要挪到销货成本里去。

所以看 2012 年的研发数字，不能只看绝对值的下降，要看结构。真实的研发投入确实在减少，因为 Model S 的开发进入尾声，样车和测试的支出大幅下降。但减少的幅度没有报表上看起来那么大，一部分只是换了个地方记。

2012 年研发费用大致落在 2 亿美元上下，跟 2011 年差不多。真正的下降要等到下半年 Model S 量产之后。

资本开支这边，2012 年计划 2 亿到 2.2 亿美元，而且严重偏向上半年。原因很实在：供应商的工装和设备要付尾款，验收签字就得给钱。马斯克说，这里面大部分是 Model S 的收尾支出，一部分是 Model X 的启动支出，还有门店、服务中心和超级充电桩的投入。

他还提了一个对后面几年影响很大的判断。Gen 3 的研发和资本开支，会比 Model S 低得多，因为工厂、平台、车架、零部件都能复用。有些零件在 Model S 和 Model X 上看不出区别，本来就是同一套东西。同一套平台摊到第二款、第三款车上，边际成本会掉得很快。

每千瓦时 200 美元的电池，路线图怎么走

电池成本是整场电话会里技术含量最高的一段。

分析师提到，马斯克在底特律车展上放过一张幻灯片，说电池成本降到每千瓦时 200 美元不是不可能。问题是想知道，这个数字里有多少是工程上已经跑通的，有多少是还没想清楚但相信迟早会发生的。

马斯克的回答分了两层。

第一层是电芯层面。他说未来不远的将来，电芯成本降到 200 美元以下是有可能的，这个判断比较有把握。

第二层是电池包层面。包成本要把热管理、安全系统、结构件、BMS 全算进去，这是另一个数字，也是特斯拉最核心的机密之一。他没有给出具体的包成本数字。

关于降本路径，他给了一个很实用的框架。降本有两个来源：规模效应和材料体系变化。

规模效应是连续的，产能爬坡、良率提升、采购议价，每年都能挤出一点，这是渐进式的。

材料体系变化是跳跃的，换一套正极材料或者电解液配方，成本可能一次降一大截，但周期很长。因为新化学体系要过循环寿命、日历衰减、安全性、低温性能这一整套验证，实验室里跑通了，到大规模量产还要好几年。

他给的节奏是：材料体系的迭代大概三年一次，中间靠规模效应逐年改善。这个节奏对判断整个行业的成本曲线很有参考价值，别指望电池成本每年腰斩，也别以为它不降。

三万美元的车，可能比原计划来得早

分析师问，如果不需要融资也能活，那多出来的钱会往哪投，会不会加速 Gen 3。

马斯克的回答改了一个既定计划。

原本特斯拉的路线是：Roadster 之后做 Model S，Model S 之后做下一代 Roadster，再之后才是面向大众市场的 Gen 3。

这次他说，技术可扩展性的进展比预期快，Gen 3 会提前，下一代 Roadster 往后排。

我们原本打算先做下一代 Roadster，但现在对技术能扩展到更大销量的信心足够了，所以可以更早做第三代车，一台三万美元左右的车。（马斯克）

为什么顺序会变？因为 Roadster 是低产量高价车，一台卖十万美金以上，一年卖几千台，摊不开研发成本。Gen 3 是三万美元级别，一年能卖几十万台，同样的研发投入摊到每台车上就便宜得多。技术成熟到一定程度，做便宜车比做贵车更划算。

这也解释了为什么他一直强调平台复用。Model S 和 Model X 共用平台，Gen 3 再复用一部分，每一代车的开发成本都在被前面的车摊薄。

五星安全不是门槛，是目标

关于 Model S 的认证进度，这段对话有两个技术点值得记下来。

第一个是模具。Model S 的冲压模具来自富士的冲压厂，特斯拉的做法是，在模具运到弗里蒙特之前，先在富士那边用同一套生产模具试冲，把件寄回来，跟自己冲压机上冲出来的件做比对，确认没有实质差异。这样模具一到，装上去就能直接用。马斯克说，全部模具会在第二季度初到位，留出足够的验证时间。

第二个是安全认证。美国的汽车安全认证是自我认证制，厂家自己测、自己申报，NHTSA 事后抽查。所以拿不拿五星，不构成销售的法律前提。

但马斯克把目标定得很高。他说原本预计平均四到五星，某些单项可能只有四星，现在看起来所有类别都拿五星的可能性越来越大。

最难的一项，是第五百分位女性（身材娇小的女性）在更高速度下的正面碰撞。这个场景一直是碰撞测试里最难通过的，因为假人小、坐姿靠前、气囊和约束系统的匹配难度大。他说这一项也基本拿下了，正在跟外部工程伙伴一起做最后的优化。

他还补了一句，就算法规不要求，特斯拉的目标也是造出路上最安全的车，内部甚至拿"虚拟六星"当目标。这话听着像营销，但结合他后面讲的"如果车不够完美，不会先给汽车记者试驾"，逻辑是一致的。

真正的底牌，是超级充电桩

整场电话会里，马斯克唯一一次用扑克术语打比方，是说超级充电桩。

他说，技术路线图上有很多不确定的牌，但真正的河牌（river card，德州扑克里最后一张公共牌）是超级充电桩。等人们看到它有多好用，一切就不一样了。细节会在 2012 年晚些时候公布。

这个判断后来被证明是对的。Model S 最早的卖点不是加速，也不是续航，是"我能开它跑长途"。这个能力不是车本身给的，是充电网络给的。

把它放在 2012 年的语境里看，这个判断相当超前。当时全行业的共识是，电动车的短板是电池，解决办法是把电池做得更好。马斯克把短板定义成补能体验，解决办法是自建网络。同一件事，换一个角度定义问题，解决方案完全不同。

Roadster 会变成收藏品

有分析师问 Roadster 的长期计划。

马斯克的回答很坦率：第一代 Roadster 产量两千多台，是第一款真正能上路的电动车，他相信它会成为 21 世纪第一批真正的收藏车之一。

下一代 Roadster 会做，但排在 Gen 3 之后，大概要等四年左右。

这个安排背后是资源分配的逻辑。Roadster 是品牌资产，不是现金流业务。在产能和现金都紧张的阶段，先做能放量的车，再做能立品牌的车。等 Gen 3 把规模做起来，再回头做一台高价的旗舰跑车，那时候品牌溢价和资金都到位了。

不试驾，也敢交车

有个分析师问了交付流程的细节：客户提车前能不能试驾？第一批 5000 个客户里，有多少人会坚持试驾？

马斯克的回答是，客户根本没有"提车前必须试驾"的预期。这些人等了两三年，只想尽快拿到车。

他补了一句更有意思的：就算有人提车后发现不喜欢，也可以直接卖掉，因为需求远超供给，转售价格会很漂亮。

这句话信息量很大。当一款产品的需求远大于供给时，你不需要靠试驾来降低决策门槛，因为客户知道买错了也能原价出掉，风险被市场本身消化了。这是极少数产品才有的待遇。

当然特斯拉也不是完全不给试驾。门店会放一批车专门做试驾，跟客户交付并行推进。等产能上来、车多起来，试驾自然就不是问题。

关于媒体试驾，他的态度更保守：车要调到足够完美，才会交给汽车记者。第一批评测的口碑影响太大，不能赌。

租赁可能比购买更有吸引力

有分析师问融资方案。马斯克的回答绕到了太阳能。

他说特斯拉会提供完整的租赁和融资方案，跟多家金融机构合作。然后他讲了一个类比：太阳能行业里，租赁模式比直接购买更受欢迎，因为租赁能让客户把太阳能的价格和电费直接对比，而电费是每月都在涨的。

电动车是同一个逻辑。买一台车，客户要一次性拿出一大笔钱，很难跟油费做对比。租一台车，每月付的钱可以直接跟每月省的油钱对比，电价和油价差着一个数量级，这笔账一算就清楚。

他还提到一个细节，租赁模式还能规避残值波动的风险。电动车的二手残值当时没人看得准，租赁把这个问题从客户身上转移到了金融机构身上。

这段对话在 2012 年听起来是个销售技巧，放到今天看是对整个电动车商业模式的预判。后来特斯拉自己的租赁业务、电池租赁、FSD 订阅，本质都是同一套思路：把一次性大额支出拆成月度支出，让客户能跟替代方案做直接对比。

中国是绕不开的市场

最后一个提问的分析师问了 Gen 3 的目标市场。

马斯克的回答是全球，包括中国。原话是，如今很难忽视中国这个市场。他还确认，Model S 和 Model X 都会在中国销售，而且 Model X 在中国可能会有很强的吸引力。

这段话放在 2012 年，是个相当早的判断。当时中国的新能源车市场几乎为零，充电设施基本没有，进口车关税高得吓人。但特斯拉的逻辑不是看当下的销量，是看十年后的市场容量。

关于 Model X 的产量规划，他给了一个保守数字：Model S 的一半到四分之三。

分析师追问 2014 年 15000 台的目标，他确认这是保守估计，按需求看很可能更高，但不想给太激进的指引。

这个"保守估计"的说法在整场电话会里出现了好几次。给指引时压低预期，交付时超预期，是马斯克一贯的做法。听特斯拉的财报会，得把管理层的数字和他们的表述方式分开看。

这通电话会之后发生了什么

回头看清这场电话会，几个判断后来都被验证了。

Model S 确实在下半年放量，2012 年交付约 2650 台，虽然没到 5000 台的目标，但产能爬坡的曲线是对的。超级充电桩确实成了 Model S 最核心的卖点之一，2012 年 9 月第一批站点上线。Gen 3 确实提前了，2016 年发布的 Model 3 起售价 3.5 万美元，比原计划晚了几年，但方向没变。戴姆勒和丰田的动力总成业务确实撑起了那几年的非整车收入。

"再也不需要融资"这句话，从字面上看是错的。特斯拉在 2013 年、2014 年、2017 年、2020 年多次融资。但从另一个角度看又是对的：那些融资都是"想要"而不是"需要"，是为了加速，不是为了活下去。

这场电话会最值得学的地方，不是马斯克说了什么，是他怎么组织判断。市场多大、坐标系选谁、成本曲线怎么走、哪张牌最关键，每一个问题他都先给出判断框架，再填数字。框架对了，数字差一点也能修正；框架错了，数字再准也没用。

  • 听财报电话会，把管理层的会计重分类和真实成本变化分开。研发费用下降，先确认是不是转进了销货成本，别把记账动作当成降本成果。
  • 看硬件公司的收入指引，别只看台数，要看交付顺序和配置结构。先交顶配和先交入门版，同样台数能差出几千万营收。
  • 判断一家公司怕不怕竞争，看它选什么坐标系。把自己放进"电动车"类目和放进"豪华轿车"类目，是完全不同的两门生意。
  • 看技术路线图，区分规模效应和体系变化。前者连续、可预测，后者跳跃、周期长，别用前者的节奏去预期后者。
  • 跟供应商或合作伙伴做联合开发，第一件事是把 IP 条款和授权模式写清楚。互信是结果，不是前提。
  • 产品需求远大于供给时，试驾、试用这类降低决策门槛的动作可以往后放，先把货交出去。反之，需求不足时，这类动作要提前做。
