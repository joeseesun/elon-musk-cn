2016年3月31日晚上，洛杉矶霍桑，特斯拉设计工作室。马斯克走上台，准备发布 Model 3。

他开口讲的第一件事跟车没什么关系。

他讲气候。

台下站着几百号人，很多提前几个小时就来排队交订金，他们想看的是一台3.5万美元的电动车长什么样。马斯克却先花了将近十分钟，讲大气里的二氧化碳。

这个安排本身就是信息。一家公司愿意在自己最重要的产品发布会上先讲一件没人爱听的事，说明它认为那件事才是这产品存在的理由。

他说，大气二氧化碳浓度刚刚越过 403ppm。屏幕上那条曲线几乎是竖直向上的。上一次地球碳浓度停在这个水平，是 1100万年前，大致相当于灵长类刚开始直立行走的年代。

「我们不想回到那个状态。」（马斯克）

这段开场决定了后面所有内容的说服力。一台3.5万美元的电动车凭什么值得存在，答案藏在这条曲线里，不在参数表里。

平均值涨2度，极端值涨20度

马斯克给了一组容易被忽略的对比。

全球平均气温上升了2度。单听这个数字不吓人，一杯水的温差都比它大。可平均值会掩盖分布：极端温度的上升幅度最高达到20度。

他的意思很直白。平均值是统计学，极端值是生存问题。某些地方在某些时段变得不适合居住，那才是真实代价。伤害人的方式有两种，一种温和一种剧烈，媒体通常只报道前一种。

第二组数字跟气候无关，杀伤力更直接。

麻省理工学院（MIT）一项研究显示，仅在美国，每年就有 5.3万人死于汽车尾气。

马斯克没有论证这个数字的可信度，他只是把逻辑摆在那儿：车在排放有毒气体，你呼吸的空气里就有有毒气体。推理到这一步就够了。

所以特斯拉存在的理由，他自己压缩成了一句话：加速向可持续交通的转变。

留意「加速」这个词。他没说电动车是唯一解，也没说特斯拉要干掉所有燃油车。他要的是让这件事早几年发生。早五年和晚五年，累计碳排放差出一大截。

一篇博客写下的四步棋

接着马斯克放出一张老截图。

那是他为公司写的第一篇博客，标题叫「秘密蓝图」（The Secret Master Plan）。写这篇东西的时候，特斯拉还是家小公司，资源少得可怜，造不出大家伙。

他说当时想清楚了一件事：一家小公司要真正影响行业，唯一的路径是从低产量、高价格的产品起步，然后一步步往下走。

任何新技术都需要反复迭代，也需要规模效应，才可能做到又好又便宜。这个顺序颠倒不得。你先造一台便宜但平庸的车，市场不会记住你；你先造一台贵但惊艳的车，行业会记住你，然后你才有钱继续往下走。

他原本设计的是三步。讲到这儿他插了句玩笑：现在变成了「四部曲的三部曲」。

第一步，Roadster。

第二步，Model S。

第二步半，Model X。

第三步，Model 3。

这四步棋的每一步，都在解决前一步暴露出来的问题。

Roadster：先证明电动车可以很好

Roadster 的价格很高，产量很低，一年只造 500 台。

马斯克很坦率，这个产量就是当时的能力上限。这台车的作用不在销量，在于打破一个刻板印象。

在 Roadster 之前，公众对电动车的想象是：慢、丑、续航短、性能差。这印象谈不上偏见，差不多就是当时产品的真实水平。高尔夫球车加个壳，确实是那个年代电动车的普遍形态。

所以 Roadster 的任务只有一个：让世界看到电动车可以做得很好。快、好看、操控出色。

「对那些买了 Roadster 的人，谢谢你们。」（马斯克）

效果有多大？马斯克引了一个案例。通用汽车前副董事长鲍勃·卢茨（Bob Lutz）公开把雪佛兰 Volt 项目的启动，部分归功于 Roadster。Volt 后来又带动了日产 Leaf 的项目。

一家每年造500台车的小公司，撬动了整个行业的路线图。这是典型的杠杆效应：销量可以很小，信号必须足够响。

500台车卖出去，改变的是几十万台燃油车的设计决策。这个换算比值，比任何销量榜单都有意思。

Model S 和 Model X：用高价车的钱，养平价车

Roadster 之后，质疑换了个说法。

「Roadster 是不错，可它是个玩具，太贵了。你造不出一台人们每天开的车，也竞争不过世界上那些优秀的燃油轿车。」

马斯克的回应是 Model S。

这台车的成绩单他念了一串：最多可坐七人，五个成人加两个小孩；被《Motor Trend》等媒体评为史上最快的四门车；被《消费者报告》（Consumer Reports）评为有史以来最好的车。

但马斯克强调，拿奖算不上目的。

「原因跟拿什么汽车界的 superlative 无关。它要展示的是一台电动车能做到什么。因为当时没人相信电动车能做到这些。」（马斯克）

这句话值得停一下。产品获奖，通常被理解为商业成功。在一个品类被普遍低估的阶段，奖项的用处是修正市场预期。它撬动的是整个行业的心理天花板，跟这家公司当期销量关系不大。

然后是 Model X。逻辑很清楚：轿车市场占一半，SUV 市场占一半，把 Model S 的平台延伸过去，就能覆盖另一半需求。那对鹰翼门，马斯克承认给他们添了不少麻烦，但「现在它们能用了」。

讲到这里，他说了整场发布会里最实在的一段话。

Model S 和 Model X 带来的收入，是 Model 3 研发资金的来源。开发 Model 3 需要的高产量产线、成本压缩工程、全新能力，加起来要花数十亿美元。

「所以我想对所有买了 S 或 X 的人说，谢谢你们为 Model 3 付了钱。Model 3 之所以存在，是因为你们。」（马斯克）

这段话把特斯拉的产品线关系讲透了。高端车型承担两个任务：融资工具，和工程验证平台。买 Model S 的人，实际上在补贴五年后买 Model 3 的人。

这跟大多数车企的做法正好相反。传统车企用低端车走量赚钱，用高端车树品牌。特斯拉把顺序倒了过来，先用高价车养研发，再让平价车去改变世界。

安全：平均五星和全项五星

进入 Model 3 的具体参数，马斯克第一个讲安全。

「在特斯拉，我们真的相信安全必须放在第一位。我们在乎你，希望你安全，希望你的朋友和家人安全。这是最重要的。」（马斯克）

然后他给了一个具体承诺：Model 3 不只是平均五星，而是每一个类别都五星。

这个区别很关键。碰撞测试的星级通常分正面、侧面、翻滚、座椅等多个项目，一款车完全可能总分不错但某一项拉胯。平均五星和全项五星，对坐在车里的人来说是两码事。

接着是加速。

即便最低配的 Model 3，0到60英里（约96公里）加速也不到6秒。当然会有更快的版本。

「在特斯拉，我们不造慢车。」（马斯克）

这句话在现场引来掌声，背后是个产品决策。电动车的动力输出特性决定了，做快几乎不增加额外成本。燃油车要快，得堆发动机、变速箱、排气系统；电动车要快，把电机功率调大就行。既然成本这么低，凭什么不做？

性能在这里承担的是教育任务。每一个红绿灯起步，都是一次免费的广告。车主不需要解释电动车快不快，他只要踩一脚油门。

续航：215英里是下限，不是目标

续航这一项，马斯克的表述非常小心。

EPA 标准下至少215英里，约合346公里。他紧接着强调：这些是最低数字，我们希望超过它们。

为什么把话说得这么保守？续航是电动车的信任货币。传统车企标续航可以留点水分，用户没油了去加油站补上就行；电动车标高了，用户会在高速上被拖车。一次虚标，毁掉的是整个品类的信誉。

215英里放在2016年，是个精准的位置。它比当时主流电动车高一截，又没有高到让人怀疑。它足够覆盖绝大多数人的日常通勤，也足够支撑一次短途城际出行。

数字后面还有一层意思。马斯克说的是「最少」，这在汽车行业是个罕见的承诺方式。绝大多数厂家标的是「最多」，理想工况下的最好成绩。标「最少」，等于把测试条件之外的所有不利变量都提前担了下来。

Autopilot：安全功能不做选装

接下来是一条容易被低估的宣布。

所有 Model 3 都标配 Autopilot 硬件，而且所有 Autopilot 安全功能在每一台车上都会存在，不需要额外购买任何选装包。

请注意这个措辞的区别。硬件标配，软件功能里的安全部分也标配。要付费的，是那些「便利性」功能。

这里有个明确的价值判断：救命的东西不能拿来加价。

如果自动紧急制动、车道偏离预警这些功能成了选装，结果可以预见：买低配的人用不上，而这些人往往预算最紧张，也最需要安全冗余。技术上能这样卖，商业上也能多赚一笔，产品逻辑上却说不通。

这个决定后来被整个行业跟进。到今天，AEB（自动紧急制动）在欧洲和北美已经逐步成为强制标配。特斯拉在2016年把它做成了全系默认，比监管早了好几年。

五个成年人，和一块连续玻璃

空间是紧凑型轿车的传统弱项。马斯克说 Model 3 能舒适坐下五个成年人，然后专门解释了「舒适」这两个字。

「舒适才是重点。造一台小车容易，难的是坐满人还舒服。」（马斯克）

为此他们做了两处改动。

第一，把仪表台前移。电动车前面没有庞大的内燃机，不需要那么长的发动机舱，前排座椅可以整体往前挪，同时压缩仪表台厚度。这样前后排的腿部空间同时变大。他提到，今晚试乘的人会发现坐姿比想象中靠前，「感觉其实很好」。

第二，后部车顶是一整块连续的玻璃。

这块玻璃的价值在头部空间和通透感，好看只是顺带。传统车顶有横梁、有内饰板、有天窗框架，每一层都在吃掉垂直空间。一整块玻璃省掉了这些结构，头部空间直接上去了，坐在后排的人也不会觉得压抑。

马斯克说，这是同尺寸车型里「空间感受最好的」。

这里有个工程上的取舍值得注意。玻璃车顶在隔热和成本上都不占优势，夏天车内会更热，结构强度也需要额外设计。他们用这两项代价换来的是用户坐进去第一秒的感受。对一个主打家用的车型来说，这笔账算得过来。

前后两个备箱，和一块七英尺的冲浪板

电动车没有发动机，车头就空出来了。Model 3 和 Model S 一样，有前行李箱和后行李箱两个储物空间。

马斯克给了一个对比：在相同外部尺寸下，它的储物容积超过任何一台燃油车。

这句话在工程上没什么争议。燃油车的车头被发动机、变速箱、散热器、排气系统占满，这部分空间属于纯损耗。电动车把它变成了可用的行李厢。同样的车身轮廓，能装的东西多出几十升。

然后他讲了个细节。最近有人问他，车里能不能放下一块7英尺长的冲浪板（约2.1米）。

「答案是能。」（马斯克）

这个细节比任何容积数字都好用。它把抽象的升数变成了一个具体画面：后排座椅放倒，前排座椅推到最前，一块两米多的板子塞进去。听众脑子里立刻有了尺寸感。

讲参数的时候，一个能被复述的画面，胜过十个精确的数值。

超级充电桩：卖的是自由

所有 Model 3 都标配超级充电功能。

马斯克解释这件事的时候，用的是「自由」这个词。

「超级充电很重要的原因是，它给你出行的自由。你可以方便地去任何想去的地方，以任何你想要的方式。」（马斯克）

「拥有一辆车，很大一部分意义在于自由，在于能去你想去的地方。」（马斯克）

这段话点出了电动车真正的销售阻力。潜在买家算的账跟电费省多少关系不大，他算的是：「我能不能开它回老家」「我能不能开它去自驾」。续航焦虑的本质跟里程数字无关，跟补能网络的不确定性有关。

充电桩得算进产品本身。一台不能长途的电动车，在城市通勤场景里再优秀，也只能卖给一部分人。补能网络覆盖到哪里，产品能卖到哪里。

这也是为什么特斯拉在卖车之前先铺桩。桩建在车前面，看起来是重资产投入，实际上是打开市场的钥匙。用户看到路上有桩，才敢下单。

3.5万美元：不选装，也是好车

价格出来了：3.5万美元。

马斯克紧接着强调了一句，这句话的份量比价格本身更重。

「我要强调，即使你什么选装都不买，这依然是一台很棒的车。在3.5万美元这个价位，你买不到更好的车，差得远。」（马斯克）

这段话针对的是汽车行业的一个老毛病：低配车是营销工具，不是产品。广告上打3.5万，你去店里发现3.5万那台是织物座椅、手动空调、小屏幕、没有倒车影像，销售会告诉你「这台不排产，看看旁边这台4.8万的好吗」。

特斯拉的做法不同。基础版就是完整产品，只是少了额外的性能和配置。

这跟善意关系不大，跟商业模式关系很大。特斯拉用直销，没有经销商靠选装赚钱，把车做成「诱导升级的钩子」对它有百害无一利。经销商模式需要低配车当诱饵，直销模式需要低配车能自己站住。

所以他敢说，不选装的车，也是好车。

「愚人节在别处」

参数讲完，马斯克说：你们想看看车吗？

「不过今晚我们没准备。」（马斯克）

台下安静了一秒。他补了一句：「愚人节在别处。」然后说，把它开出来吧。

这是个设计好的玩笑。发布会日期定在3月31日，距离愚人节还有几个小时。这个梗他显然准备了很久。

几台 Model 3 开上台。马斯克问台下：「你们觉得怎么样？喜欢这台车吗？」

然后他讲了一件「有点疯狂」的事。

「我刚被告知，过去24小时里，Model 3 的订单总数已经超过了 11.5万辆。」（马斯克）

现场的反应是掌声和欢呼。马斯克自己在台上说了句「这确实很多」。

11.5万张订单，和一台还没量产的车

这个数字需要放在语境里看。

2016年，特斯拉全年交付量不到8万台。而 Model 3 在24小时内收到的订单，超过这家公司历史累计交付量的一大截。这些订单来自一个还没有量产工厂、没有完整定价表、没有试驾过的产品。

人们付订金买的是一份承诺，一份已经讲了十年的承诺。

回头看这场发布会，它的结构非常简单：先用十分钟讲清楚为什么这件事必须做，再用二十分钟讲清楚为什么之前做不成，最后用十分钟讲清楚这次为什么能成。

参数是最后一层。真正让人下单的，是前面那套逻辑：高端车养研发，研发降成本，成本降下来才有平价车，平价车才有规模，规模才能改变碳排放曲线。这条链上每一环都被前面十年的产品验证过，所以最后一环的3.5万美元才有说服力。

马斯克在那天晚上没有说的是，Model 3 的量产地狱还在前面。产能爬坡的两年里，特斯拉几乎每周都在破产边缘。11.5万张订单既是动力，也是悬在头顶的债。订金收得越多，跳票的代价就越大。

但在2016年3月31日的晚上，逻辑是闭合的。一家小公司用了十年，把自己变成了能造平价车的公司。这个路径本身，比那台车更值得记住。

  • 判断一个新品类能不能成，先看有没有一台让人闭嘴的旗舰。Roadster 年销500台，却让通用汽车重启了 Volt 项目。早期产品的价值跟销量关系不大，跟它能否修正整个市场的预期有关。评估一项新技术时，别只看市场占有率，要看它有没有逼着老玩家改路线图。
  • 成本下降靠规模，不靠省。Model 3 能卖3.5万美元，是因为 Model S 和 X 已经摊掉了平台、产线和供应链的钱。想做便宜产品，先得有台贵的产品替它付学费。这个顺序反了，两边都做不成。
  • 安全功能做成标配，不做选装。这是2016年一个反行业惯例的决定，后来成了监管标准。做产品时值得问一句：这个功能如果只有一部分人能用，剩下的人承担的是什么？
  • 发布会先讲为什么，再讲是什么。马斯克花了三分之一的时间讲碳排放，才轮到参数。顺序倒过来，3.5万美元就只是一个价格；顺序对了，它是一个解决方案的入场券。
  • 最低配也得是好产品。用低配车引流、逼用户升级，是短期转化的最优解，也是长期口碑的最差解。直销模式没有经销商吃差价，反而逼着产品必须诚实。
  • 看订单数，更要看交付能力。11.5万张订单在24小时内产生，真正的考验在两年后的产能爬坡。评估任何「爆单」新闻时，问一句：交付跟得上吗？
  • 补能网络要算进产品定义。超充标配解决的是「我能不能开它去远方」这道心理门槛，跟充电本身关系不大。任何依赖基础设施的新产品，都得把基础设施当成产品的一部分来规划。
  • 一个能复述的画面，胜过十个精确数值。「能塞下一块七英尺冲浪板」比「后备厢容积425升」传播力强得多。讲参数时，先想清楚用户会怎么转述它。
