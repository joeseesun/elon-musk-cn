Model Y 发布

Model Y Unveil

Tesla·2019 年（约）·35 分钟·精读约 5351 字 · 阅读 12 分钟
中文精读由 AI 基于原始视频与文稿改写，非官方翻译，可能存在偏差或错误；表述以原视频为准。说明

2008年2月，特斯拉整个公司只造出过一辆车。序列号1，车主是马斯克本人。那辆车经常抛锚。为了造出第二辆，他们又花了三个月。

十一年后的同一个场地，马斯克报出的数字是：累计产量约55万辆。再过12个月，这个数字会翻到100万。

发布会叫 Model Y Unveil，主角是一辆中型 SUV。但马斯克把大把时间花在了工厂、电池和充电桩上。他自己解释了原因。

哪怕是造火箭，设计制造系统大概也比设计火箭本身难10倍。造车的话，设计制造系统比设计汽车本身难100倍。（马斯克）

做一个能跑的原型机，相对容易。把原型机做成能可靠、低成本、大批量下线的商品，是另一码事。这句话放在任何一家硬件公司身上都成立，只是大部分人只在发布会上看车，看不到产线。

马斯克还提了一个容易被忽略的事实：美国上一次有汽车公司完成大规模制造，大约是100年前。中间那段漫长的时间里，没有新玩家挤进来。然后是特斯拉。

所以这场发布会的结构有点奇怪。先讲十一年历史，再讲工厂和电池，最后才把车开出来。

先用一辆跑车，打碎“电动车又慢又丑”

2008年那辆 Roadster，使命很明确，改变人们对电动车的刻板印象。

当时的普遍认知是，电动车慢、丑、性能差。所以特斯拉第一辆车选了跑车形态。要快，要好看，要性感，续航还得长。

外界给了两个判断：你造不出这种规格的车；就算造出来，也没人买。

后来两条都被推翻了。

推翻之后，新的质疑立刻跟上：行，你能造一辆玩具跑车，但你造不出轿车，更不可能跟燃油豪华轿车竞争，因为那些车已经做到最好。

于是有了 Model S。

马斯克在现场拿传统车评的套路开了个玩笑：这么吵，排气管在哪，汽油加哪儿。

发布会放出的照片里，初代 Roadster 停在台上，马斯克的原话是“它有点小”。那辆车的序列号是1，属于他本人。十一年前，那是全公司唯一的资产。

Model S 是在火箭工厂的角落里画出来的

那时候特斯拉没有设计工作室。他们在 SpaceX 的火箭工厂里划出一小块地方，Franz von Holzhausen 加入，一支很小的团队把 Model S 画了出来。

马斯克认为这款车意义重大，因为它直接对标的是当时最好的燃油轿车。能在那个级别的比较里赢下来，“你可以电动”这件事就不用再解释了。

名字的来历也值得说。马斯克的原则是把东西叫成本来的样子。Roadster 叫 Roadster，因为它是 roadster。但 sedan 这个词在英文里没有好听的替代，saloon 也别扭，索性用 Model S，S 就是 sedan。

他后来才意识到，Model S 念出来像“models”。有段时间他挂着一块车牌写着 Model S2，因为那是第二辆量产版 Model S。有天他走向自己的车，听见旁边有人说，这人真够呛，车牌写着 models too。

车牌换了。

福特杀死了“sex”

Model S 和 Model X 之后，马斯克想再出一款 Model E，凑成 S、E、X。他觉得这个梗挺好玩。

福特威胁要起诉。按马斯克的说法，福特杀死了 sex。

那就换个名字，叫 Model 3。他跟对方说，3 跟 E 完全不是一回事。对方说行。

加上 Model Y，四个字母凑齐了：S3XY。发布会开到末尾，马斯克说的是“我们把性感带回来了，字面意义上的”。

Semi 这个名字也有类似的双关。马斯克说自己是在命名之后才发现 semi 有两个意思。他的版本是，semi sexy。

Model X：把所有想得到的玩意儿都塞进去

做完 Model S，目标变成造世界上最好的 SUV。马斯克承认这次有点失控，基本上把当时能想到的技术和花哨配置全塞了进去。

他给 Model X 的形容是，像一颗法贝热彩蛋撞上了一艘飞船。

结果就是造起来极其困难。X 代表 crossover，跨界 SUV。车本身很出色，代价是工程复杂度。

发布会现场摆出的产品线一字排开：初代 Roadster、Model S、Model X、Model 3、新一代 Roadster，还有一辆 Tesla Semi。那辆 Semi 是从湾区一路不充电开过来的，续航500英里。马斯克还特意提了一句，加拿大萨斯喀彻温省有人问过超充的事，他问过两次，得到的回复是正在建，建成之后就能开车横穿加拿大了。

那家差点被当成废品站的工厂

马斯克说，工厂的重要性和价值被严重低估了。工厂跟车一样是产品，甚至比车更像产品。

特斯拉买下 Fremont 工厂的时候，它叫 NUMMI，是丰田和通用的合资厂。价格很便宜。便宜的原因也很直接，丰田和通用把所有好设备都搬走了，剩下的是连废铁都不值的东西。照片拍出来，就是一个废弃仓库。

很多人会误以为，有了汽车工厂就能造任何车。马斯克的比喻是：这就像说你有了一个盒子，盒子里就能装任何你想要的东西。不对，只有你在盒子里真的造出那个东西才行。

把一个废弃仓库变成能运转的汽车工厂，花的力气超过造车本身，而且超出很多。

今天的 Fremont 是另一个样子。按占地面积算，它是世界第二或第三大的建筑。里面有两万人，分四到五个班次，和机器人一起挤在极高的密度里。马斯克的说法是，一台巨大的控制论集合体。

这段历史放到行业尺度上看更刺眼。美国上一次有汽车公司从零完成大规模制造，大约是100年前。中间这一百年，底特律的格局几乎没被打破过。

30 GWh 的世界，需要一座 50 GWh 的工厂

整车厂建起来，下一个问题是电池、电机、电力电子从哪来。

特斯拉算了一笔很朴素的账：至少需要50 GWh 的电芯产能。而当时全球锂电池的总产量，把所有用途都算上，手机、笔记本、车，加起来大概30 GWh。

需求大于全球产能。答案只能是自建。

我们本来打算把 Gigafactory 建在加州，但光拿许可就要两年。所以我们在拿许可所需的时间里，把工厂建完了。（马斯克）

2010年那块地是石头和灌木。今天它只完工三分之一，面积大约是五角大楼的四到五倍，高70英尺，绕建筑走一圈要两个小时。它的锂离子电池产量，超过世界其他地区的总和。

这个数字值得停一下。一家公司的电池产量超过全球其余部分的总和，意味着电动车行业的瓶颈不在整车设计，而在电芯。谁掌握了电芯产能，谁才真正掌握了成本曲线。

上海：三个月，从水坑到钢结构

2019年1月的破土动工照片里，最显眼的是一大片水坑。马斯克自己都笑了。

三个月后的照片，厂房已经起来了。年底的样子，他也放了幻灯片。

这座工厂建成后，产能相当于 Fremont 整车厂加内华达电池工厂的总和，把两件事合在一处。它对 Model 3 和 Model Y 的平价版本至关重要，尤其是面向中国市场的版本。

把电池厂和整车厂放在同一个园区，省掉的是物流和库存，也省掉了跨洋运输的时间。这个安排在后来被反复复制。

2018年，一年老了五岁

讲能源产品之前，马斯克先道了个歉。

Model 3 产能爬坡那段时间，公司把所有资源都压了上去，因为不这么做就会死。Powerwall 的销售被牺牲掉了，销售资源要么给车，要么给储能，只能选一个。

2018年感觉像是一年老了五岁。真的非常紧张。（马斯克）

他专门感谢了在那段时间支持特斯拉的人。台下鼓掌的时间比前面任何一段都长。

等到 Model 3 的产能稳定下来，工程资源才终于能分给太阳能屋顶、太阳能改造和 Powerwall。马斯克说，2019年是太阳能屋顶之年。

能源这件事，得三样凑齐

要完成能源转型，得同时解决生产和消费。生产端是太阳能，消费端是电动车。中间必须夹一块电池，因为太阳晚上不照。

太阳能板加电池加电动车，三样凑齐，才是一个完整的、可以理直气壮乐观的未来。马斯克用了“exciting and optimistic”这个词组，语气很认真。

储能产品线里，Powerwall 面向家庭，Powerpack 面向工业级。特斯拉在澳大利亚建了当时全球最大的电池储能系统。南加州正在建一个约1 GWh 规模的 Powerpack 项目，就在发布会场地附近。

超充：2010年是0个

2010年，特斯拉的超充数量是零。开电动车跑长途基本不成立。

Model S 在设计时就留了后门，高压直流可以直接旁路进电池包，把电灌进去。

问题在于没人建大功率充电桩。既然没人建，那就自己建。从零开始，铺成一张全球网络。北美基本全覆盖，欧洲几乎全覆盖，中国大部分地区，戈壁滩还没到，马斯克说会到的。哈萨克斯坦有支持者，他当场承诺会建。

V3超充在发布会上同步亮相。第一代只有75千瓦左右，V3的功率大幅提升。长续航版 Model 3 的充电速度约为每小时1000英里，折合每小时1600公里。

湾区有一个 V3 站点已经在跑，设计工作室这个当晚启用。因为要等 V3，超充的铺设节奏被有意放慢过一段时间。现在 V3 跑通了，接下来是全球范围的逐步替换和新增。马斯克的说法是，到明年某个时候，全世界的超充体验会有一次剧烈改善。

从一辆到一百万辆，和四百万吨碳

发布会进行到一半，马斯克把两个数字并排放：十一年前一辆车，一年后一百万辆。

另一个数字是累计减少的二氧化碳排放，400万吨。第400万吨在开场前一小时刚刚跨过。

他还翻出了早年网上对特斯拉的评论。大意是电动车愚蠢、不可能、你是骗子。他的原话是“互联网是有记忆的”，这些只是冰山一角。

专利开源，是为了让所有人都来做

马斯克说，特斯拉存在的意义，应该用一个标准衡量。

特斯拉最终的历史价值，应该用它在多大程度上加速了可持续能源和可持续交通的到来来衡量。（马斯克）

目标从头到尾都是让整个汽车行业转向电动。特斯拉跟丰田、奔驰做过合资，三四年前把专利开源，免费开放。

看到同行都在电动化，他的反应是，这很好。

这套做法在商业教科书里很难解释。把核心专利免费给出，等于主动放弃护城河。除非把目标函数设定成“加速转型”，而不是“独吞市场”，逻辑才成立。

十年后，特斯拉在火星

有人问，十年后特斯拉会在哪。

马斯克的回答是火星。他说他觉得真的可以，十年内特斯拉会开在火星上。

这句话放在整场发布会的语境里不算突兀。前面讲的火箭工厂、制造系统、电池产能，本来就是同一套能力的不同应用。

Model Y：安全、续航、价格

然后是正事。

马斯克上台前留了个悬念：有一辆车不见了，名字以 Y 开头，以 Y 结尾，中间那个 Y 就是它。

安全是第一目标。Model 3 是美国政府测试过的所有车型里乘员受伤概率最低的。Model Y 预期得到同样的结果，每个类别五星。

电池包铺在底盘，重心极低。功能上是 SUV，开起来像跑车，过弯很紧。马斯克说，这会是世界上最安全的中型 SUV，而且领先幅度很大。

性能方面，0到60英里加速3.5秒。风阻系数0.23，对 SUV 来说是很低的数字。EPA 续航300英里，这是实际可用里程。

车顶是一整块全景玻璃。坐进去的感觉跟 Model 3 一样，抬头能看见天。

七座是选装，储物空间66立方英尺。Autopilot 那套辅助驾驶自然都有。

价格：长续航版约47,000美元。2021年会推出标准版，39,000美元起。

马斯克对销量的判断是，Model Y 很可能超过 Model S、Model X、Model 3 三款车的总和。理由是中型 SUV 本来就是最大的细分市场，而这款车在同类里几乎没有对手。

自动驾驶：今年“功能完整”

马斯克重申了公开说过的时间表：今年晚些时候，自动驾驶达到功能完整（feature complete），靠软件升级就能实现基本所有场景。

之后的路径是用几十亿英里的实际行驶数据证明安全性，特斯拉自己认为足够安全、驾驶员可以不再时刻关注，再去拿监管批准。

功能完整和监管批准之间隔着很长的距离。这一点他在现场没有回避，只是把两件事分开说得很清楚。

这场发布会真正的信息量在哪

新车参数很快会被遗忘。几年后回看，这场发布会值得记的可能是另外几件事。

马斯克把制造系统的重要性说得很直白。原型机容易，量产难，难十倍到一百倍。他在现场反复强调这一点，因为这决定了公司之间真正的差距在哪。

电池产能是硬约束。全球30 GWh 的年产量对应特斯拉一家的50 GWh 需求，这不是靠采购能解决的，只能自己建。这个逻辑后来被验证了很多次。

垂直整合有顺序。整车厂、电池厂、充电网络、储能产品，四件事互相咬合。没有超充网络，车卖不动。没有电池厂，车造不出来。没有车和储能，太阳能板的需求起不来。

特斯拉对行业的定位也很特别。专利开源、合资、公开喊话让同行电动化，这套做法在商业上难以理解，除非把目标函数设定得不一样。

最后一个细节。马斯克说 2018 年像一年老了五岁，说的不是产品失败，是产能爬坡。一家公司的生死，往往不在它能不能做出好东西，而在它能不能把好东西稳定地、便宜地、大量地做出来。

如果你只打算从这场发布会里拿走几样能用的东西：

  • 判断一家硬件公司的真实壁垒，看它的产能爬坡曲线和工厂建设周期，不看发布会上的参数表。
  • Model Y 的三个关键数字是 EPA 续航300英里、0到60英里3.5秒、长续航版47,000美元。七座为选装，要额外付费。
  • 标准版39,000美元要等到2021年。预算卡在这个区间的话，等待期是真实成本，不是一句“以后会有”就能抹掉的。
  • 超充网络的覆盖决定电动车的实际使用半径。查一下你常跑的路线有没有 V3 站点，比研究车漆颜色有用得多。
  • 上海工厂的投产时间，直接决定 Model 3 和 Model Y 在中国市场的落地价。盯工厂进度比盯配置表有价值。
  • 自动驾驶的“功能完整”和“可以不管方向盘”是两件事，中间隔着几十亿英里的验证和监管审批。做购车决策时，把这两个时间点分开算。
