2012年5月，龙飞船（Dragon）第一次逼近国际空间站。飞船上的激光雷达开始扫描空间站，把回波在计算机里重建成一个模型，用来算出两个航天器之间的相对位置和运动。然后它卡住了。

不是彻底失败，是"不确定"。计算机认为自己可能锁定了空间站，但没有百分之百把握。真实的空间站和数据库里的模型有点出入，表面还有一些高反射的区域，回波对不上。而在距离空间站几百米的地方，"pretty sure"和"确定"之间的差距，就是任务成败的差距。马斯克后来在座谈上回忆那一刻，用的词是"a little worrying at first"。

地面团队做的事是：诊断问题，写一段新代码，把它放到地面那台完整的龙飞船硬件在环仿真器上跑一遍（那台机器包含全部航电、软件和阀门），确认可行，然后把补丁上传到天上的飞船。飞船重新锁定，只是视场被收窄了。

我们基本上就是把视场收窄了，就像给马戴上眼罩一样。（马斯克）

然后加拿大机械臂伸过去，抓住了它。

这段插曲很能说明 SpaceX 在2012年的状态：一家成立十年的公司，用打补丁的方式在轨修好了自己飞船的感知系统，而它的创始人把这件事讲得像修自行车。

造火箭的理由，和生意无关

主持人问他，卖了互联网公司之后，怎么会想到去造火箭。

马斯克的回答没有任何商业色彩：

我认为人类成为一个多行星物种很重要。而从航天业的进展来看，我们显然没有在往那个方向走。所以我创办 SpaceX 是想解决这个问题。（马斯克）

他给出的理由是两条，一条硬的，一条软的。硬的一条是概率：如果人类只存在于一颗星球上，那么这个物种的存续时间就会短得多。软的一条是：只待在地球上会很无聊。

主持人追问，所以你做的不是"每几个月往空间站送几个宇航员和一些生活物资"的生意，你想的比这远得多。马斯克说，绝对是的。

这个回答框定了后面所有技术细节的意义。逃逸系统、可重复使用、甲烷燃料、超大火箭，这些不是为了拿 NASA 的订单，是为了把几百万人送到火星上去。

载人认证的真正门槛在上升段和下降段

龙飞船对接空间站的时候，其实已经载过"人"了。马斯克提醒听众，航天员在空间站里，而飞船是以机器人航天器的身份靠近的。所以它通过了空间站的安全评审。

但这个评审有个隐含前提：飞船是自动驾驶的，没有人在里面操纵摇杆。它会停在几个预设的航点上，请求许可，地面看数据，确认没问题，再放行到下一个点。制导和控制全部由飞船自己完成。

如果真出了最坏的情况呢？主持人的说法是"shudder at the thought"，马斯克的说法更直白：任务终止事件，空间站可能被毁，上面的人可能受伤。所以 SpaceX 和 NASA 两边都极度谨慎，靠近之前跑过上百万次仿真，靠近过程中逐步验证。

但要真正载人，还差两块：上升和下降。

上升段需要加发射逃逸系统。如果助推器出问题，乘员舱要能跑掉。同时火箭本身要做升级，把冗余度尽可能提高；对于那些实在做不了冗余的部件，就测到极限，让安全余量高于卫星任务。

这里马斯克给了一个具体数字：卫星任务的常规余量是25%，载人任务是40%，都在预期飞行载荷之上。

龙飞船的逃逸方案比较特别。逃逸发动机集成在乘员舱侧壁里，用的是同一套推进剂。因为在轨机动和逃逸这两件事不会同时发生：你要是需要逃逸，就不会再去做什么在轨机动了。所以一套推进剂够用。

好处是省掉了传统方案里装在飞船头部的那枚大型固体火箭。那玩意儿太重，没法一路带到轨道，通常起飞三分钟左右就得抛掉。抛掉之后，你在这段最危险的时间里就没有高加速度逃逸能力了。龙飞船不需要抛，所以它能一路逃到轨道。

推力够大到什么程度？即使在最大动压点（Max Q），火箭正在全力推进、马赫数1.8左右，龙飞船依然能加速脱离。

液体火箭真正的优势是可以关掉

马斯克顺手批评了固体火箭。

我不太喜欢用固体火箭做载人运输，说实话。（马斯克）

他的理由不是可靠性。固体火箭本身相当可靠，尤其是没有分段设计的。问题在于它点着了就停不下来。

液体火箭的好处是我们可以把它关掉。而且关掉其实很容易，液体火箭难的是让它保持开着。固体火箭一旦点着，它们倾向于一直开着。（马斯克）

这个区别在故障场景下被放大。如果整个系统出了别的问题，你还剩一堆想从后面撞上你的东西，而你没办法躲开。

从溅落海面到动力着陆

返回方案是分级的。马斯克自己给它们编了号：一级是降落伞加溅落海面，简单、可靠，龙飞船的第一版就是这样。1.5级是降落伞加陆地着陆，他希望能明年做到，最晚后年。再往上是带翼的方案，以及用推力器着陆。

推力器着陆直接复用了侧壁里的逃逸发动机，精度很高。一共八台，布置成对，可以失去四台（比如右边那四台全没了），也可以每隔一台失去一台，仍然安全。上面还有降落伞做备份，降落伞本身也是冗余的。

说实话我想不出更安全的着陆方式了，冗余的推力器加冗余的降落伞。（马斯克）

而最好的情况是可重复使用：像登月舱那样推进着陆，为复用打好了基础。

46个合同，只有12个是 NASA 的

主持人问商业计划，问十年后政府合同之外的收入从哪来。

马斯克的回答纠正了一个常见误解：当时 SpaceX 手上有46个发射合同，其中只有12个来自 NASA。绝大多数是商业卫星发射，猎鹰1号和猎鹰9号（Falcon Heavy 当时还在规划中）都有。

他还在跟毕格罗（Bigelow）谈，那是一家想做私营空间站的公司。如果谈成，SpaceX 可以把人送到那个空间站上，跟 NASA 分摊成本，减轻 NASA 的负担。

他描述公司原则的方式很直接：凡是能推进太空事业的事，我们就去做。有些事不是最赚钱的，甚至不是利润最大化的，但他不在乎。

为什么可以不在乎？因为他保留了公司的控制权。他拿投资人和上市公司做对比：

有一种经营公司的方式是，你每个季度都被人拿枪顶着，你必须做大量短期优化。这让你很难做出大的技术突破，因为有些突破要好几年才有回报。你处在错误的时间间隔上。（马斯克）

季度是三个月的间隔，而重型火箭的研发周期是十年。两者不匹配。

特斯拉面对的是三道"你做不到"

话题转到车上。主持人提到《大众机械》（Popular Mechanics）几年前给初代 Roadster 发过一个突破奖，说它几乎单枪匹马改变了人们对电动车的看法。

马斯克讲的是认知战。当时人们相信电动车必然有三个特征：外观难看、性能差、续航短，看起来像高尔夫球车。

他的做法是算账。锂离子电池的能量密度是多少，每英里耗电多少，除一下就知道能跑多远，这是很直白的算术。他把这个算给人们看，对方的反应是不信，或者说这不可能。有人干脆无视，有人说是荒谬。

所以我们决定直接造一辆车出来。这个比较难无视。而讨论 PowerPoint 就容易被无视得多。（马斯克）

造出 Roadster 之后，评价变了：小型电动跑车你能造，真正的车你造不出来，比如一辆奔驰或者奥迪，有全套功能的那种。于是有了 Model S。

Model S 出来之后，评价又变了：你不可能量产爬坡。马斯克把这形容成一系列接一系列的问题，解决一个冒出一个。

他总结出一条产品原则，后面还会再提一次：

如果你是一个新来的产品，仅仅和现有产品一样好是不够的。因为人们习惯了他们习惯的东西。要让人改变，你得做出明显更好的东西。（马斯克）

半小时充三小时，而且免费

超级充电器（Supercharger）的逻辑也是从这条原则推出来的。名字是从加油站行业"回收"来的。目标不是让电动车充电和加油一样方便，是让它更方便。

算一笔时间的账：早上九点出发，中午想停下来吃口饭、上个厕所、顺便补能，这个过程总共20到30分钟。所以充电技术要做到停半小时，换来三小时行驶。比例大约是6比1，这个比例是大多数人长途出行体验的拐点。

充电站顶上装了太阳能板，用来回应"你只是把排放转移到了发电厂"的质疑。按年计算，这些站发的电比车充进去的电还多，稍微能源为正。

然后是免费。真要收钱，一次补150英里续航大概四五美元，在电价高的州充满一次也就几美元。成本低到可以核算一下：要么象征性收一点，要么干脆免费。他选了免费。

人们长途驾驶的频率比他们以为的要低得多。我想做的是某种比汽油车明显更好的东西，不只是追平汽油车。（马斯克）

所以宣传语是：用纯粹的阳光，免费开到任何地方，永远。

被当政治足球踢，他其实挺享受

2012年大选期间，特斯拉成了话题。副总统辩论里有人把公司名念错，说成了"Tester"之类。马斯克前一天刚发了份声明，说明能源部贷款的还款进度。

他的回应是先摆数据。

特斯拉当时有3500多名员工，都是高质量岗位。整车在美国本土从零开始制造。动力总成出口到全世界，客户里有丰田和奔驰，是净出口，对贸易平衡有帮助。预计下个月就能盈亏平衡，这在 Model S 上市后算是相当快。

然后是市值对比：资本市场给特斯拉的估值大约30亿美元。如果把能源部所有项目里失败的公司全部加起来，总额都不到30亿。

如果你把它看成一个风险投资组合，从风投的角度看（罗姆尼州长大概懂这些，也可能不懂），净收益是非常显著的。你得问，给美国经济增加了多少价值，那些没成的公司减掉了多少价值，净值是非常正的。（马斯克）

结论是：能源部其实干得不错。

一扇门的工程学

座谈现场外面停着 Model X 的样车。马斯克被主持人半推半就地"套"出了信息，然后自己承认：本来你要是让我干等着，我可能会说出什么大秘密。

Model X 是 SUV，和 Model S 同平台，轴距略长，瞄准 SUV 和 MPV 市场。它的独特之处是侧面那双铰链鸥翼门，马斯克说这在此前的量产车里没出现过。叫"猎鹰翼"，因为两扇门都打开时形状像猎鹰。

为什么必须双铰链？单铰链的鸥翼门在向外摆的时候，弧线既伸得太远又抬得太高。双铰链可以让门先收再上，几乎垂直升起。实际效果是：只要人能挤进 Model X 和旁边那辆车之间的缝隙，门就能打开。

他还对比了侧滑门：侧滑门打开时先往外凸再往后滑，所以人没法从车尾方向靠近车身。鸥翼门打开后，那个方向是通的。

火星不是南极科考站

回到火星。主持人提到之前的那次采访，马斯克谈的是移民，不是一个像南极站那样的小前哨。

马斯克的回答是：一开始可能确实类似南极站，但最终要建的是自给自足的文明。

那才是能保证万一地球发生灾难，文明还能延续、意识的火光不会熄灭的东西。在我看来这是好事。（马斯克）

规模有多大？至少几万人，最终可能几百万人，以及几百万吨货物。因为你要在火星上重建地球的工业基础。所以需要真正巨大的火箭，而且发射频率极高，而且必须可重复使用。

燃料选甲烷，理由是它最便宜。更重要的理由是火星上能就地生产：从大气里取二氧化碳，开采水冰（火星上有巨量水冰），合成甲烷和液氧。

这基本上是乐高积木，很简单。（马斯克）

不要把小行星采矿设成前置条件

主持人问，是否可能在途中设中转站、在太空里加注燃料、用小行星资源做跳板。

马斯克的回答是一个方法论问题，不只是技术问题。他认为小行星采矿可能是一种优化，但不该成为去火星的必要条件。小行星都不大，月球永久阴影区的陨石坑里可能有水冰，可以做成推进剂补给站。

他用早期美洲殖民地打比方：你首先得想过去，人到了那里，如果中转站能让旅程更高效，那些人自然会去建。有了目的地，就有了强制函数，剩下的会有人做。

既然这件事本来就极其困难，除非某件事必须做，否则我会把它砍掉。（马斯克）

换句话说，探索路线上每增加一个前置依赖，就多一个让整个计划死掉的理由。

火星上的一个早晨

主持人问，你自己说过可能有一天会搬去火星，那火星居民早上起来干什么？

马斯克说，探索，建基础设施，看那些有意思的东西。他点了两个地名：水手号峡谷（Valles Marineris），长到让大峡谷显得微不足道；奥林帕斯山（Olympus Mons），坡度很缓，但是太阳系最高的山。

然后是把火星建成自给自足社会所需的那套基础设施。

电池：够用了，但可能有惊喜

现场第一个提问来自观众，问下一代电池化学体系。

马斯克的判断分两层。第一层是：光靠锂离子电池的渐进改良，就足以把整个汽车行业转成纯电。飞机不行，飞机需要更高的能量密度，但汽车、船、火车都可以。

具体在改什么？负极从碳改成硅，这是一条路。锂硫这类化学体系能量密度能到每公斤400到500瓦时，对比当时最先进的锂电大约每公斤250瓦时。

第二层是：真正的突破可能在电容器。他提到自己当年去斯坦福读博就是想研究高密度电容器，后来退学了。思路是借用芯片制造已经投进去的几百亿美元设备能力，把结构精确做到分子尺度，做出能量密度极高的超级电容。他说硅谷有一家公司（特意声明不是 Eestor）有可能在这个方向上取得突破，如果成真会是革命性的。

第一性原理，和主动去讨骂

有人问，你带的年轻工程师，你用什么哲学去激励他们。

马斯克的回答有两部分。第一部分是物理作为思考框架，尤其是第一性原理（first principles）而不是类比推理。

类比推理在计算上更容易。如果你整天都从第一性原理推，你一天都过不完。但当你试图做一件新的、复杂的事情时，那才是正确的方式，因为类比必然是不完美的。（马斯克）

类比依赖的是已经发生过的事。你要做的是新东西，那就不适用。第一性原理的意思是，把事情拆到最基本的事实，然后从那里往上推。

第二部分是反馈回路，而且他强调的是负面反馈。

人们，尤其是朋友，不愿意给你负面反馈，因为他们不想伤害你。他们这么做的原因是，大多数人收到负面反馈时会受伤，这个预期不算不合理。所以你得主动去引导别人给你负面反馈，仔细听，听到的时候不要反应过激。（马斯克）

怎么知道自己是对的

有人问了一个更尖锐的问题：创新者常常遇到这种情况，你拿出计算，别人就是不买账。怎么突破"不敢违背常规"的恐惧？怎么在所有人都反对你的时候，判断自己是对的？

马斯克给了一个可操作的检验标准：先过物理这一关。

你得先确认它在物理上是可能的。确保你没有违反能量守恒或者动量守恒之类的东西，因为如果违反了，那你几乎肯定是错的，哪怕有人告诉你你是对的。（马斯克）

然后，成功必须是所有可能结果中的一个。

他说这类问题往往能用非常直白的方程说明，不需要搞得很复杂。而让他感慨的是，他真的遇到过这种场面：他列出三个像初中生水平、大概十一年级难度的方程，推导出一个显而易见的结论，对面的人依然不信。

我就想，你怎么能看着这个还不被说服？（马斯克）

太空太阳能：他最有意见的话题

接着他主动开火，说自己最受不了的一件事是太空太阳能发电。

他的开场是自嘲：要说谁该支持太空太阳能，那应该是他，因为他既有火箭公司又有太阳能公司。但这件事明显行不通。

逻辑很干净。第一，它必须比把太阳能板放在地面上更好。放一块太阳能板到轨道上，最好的情况是接收到两倍阳光，前提是没进地球阴影。

第二，你得做两次转换。地面上的太阳能板只需要把光子转成电子。轨道上你需要光子转电子，电子再转成光子（用来传回地面），光子再转回电子。这两次额外的转换，效率加起来能达到50%就已经很难了。

那两次转换基本上会把你带回原点。那你费劲把它送到太空去干什么？（马斯克）

第三，光电转换器件不是免费的，把东西送上太空也不是免费的。

他的建议是把同一块太阳能板放在地球上比一比。他预言这个话题还会再出现十次，让主持人准备一张超长的提问卡。

去火星路上的辐射，比抽烟轻

最后一个问题关于生物学：长期太空飞行中的肌肉萎缩、骨密度流失、辐射，怎么看。

马斯克的判断是这个问题被夸大了。阿波罗计划把人送到了月球，那是深空，那些人活到了很大的岁数，没有出现明显的早逝。所以真正的问题只是：你能在深空待多久。每天有一定量的辐射损伤，身体有修复能力，两者相抵。去火星六个月的旅程会增加一点癌症风险，但按他看到的粗略估算，这个增量比在路上抽烟还低。

唯一需要认真对待的是太阳耀斑。而人们对它的想象经常是错的：不需要20英尺厚的水层把整个人包起来（那会重到不可行），朝太阳的方向竖一柱水就够了，人躲在柱子后面。反正水你本来就要带。

所以旅程本身没有致命的障碍。剩下的靠时间和技术去改善。

但根本上我们得先到那里。如果到不了，这一切都是学术讨论。所以我们先把人送过去。（马斯克）

这场2012年的座谈，今天还能拿来用的东西

十二年过去，龙飞船已经把航天员送上了空间站，猎鹰9号的一级火箭已经回收了几百次，星舰在用甲烷，Model X 的猎鹰翼门成了街上一眼能认出的东西。这份文字稿里没有一条预测是错的，也没有一条是靠运气对的，因为它们都是从同一个方法里推出来的。

马斯克在那一个小时里反复做的事，其实就是把一个问题拆到最底层，然后问一句：物理允许吗？允许就去做，不允许就砍掉，不管这个方向上已经堆了多少人的期待，也不管有多少人告诉你做不到。

这套方法可以直接搬走用。

  • 遇到一个"业内都这么做"的方案，先把它拆成基本量：能量、质量、时间、成本。算一遍再决定要不要跟。
  • 判断一个新技术值不值得做，把同样的投入放到现有方案上做对照。太空太阳能那块太阳能板放到地面会怎样？这个对照一做，很多"听起来很酷"的项目会自己现原形。
  • 做新产品，别定"和现有产品一样好"的目标。用户有惯性，一样好等于不会换。找一个能一句话说清、而且明显更好的点，比如"免费"。
  • 给团队建反馈机制时，重点放在负面反馈上。朋友和下属天然不愿意说难听话，得主动去要，而且听到的时候脸色要稳。一次情绪化的反应，能让你后面半年听不到真话。
  • 定长期目标时，砍掉所有不必要的前置条件。每多一个"必须先完成 X"，计划就多一个死掉的理由。先让核心那件事成立，配套的东西等有了需求自然会有人做。
  • 想说服别人接受一个反直觉的结论，用不超过三个简单方程，把推导过程写出来。如果对方还是不信，那问题不在你的方程，别在那儿耗着了，去做个东西出来给他看。
