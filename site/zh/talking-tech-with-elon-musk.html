89%。这是马斯克给自己在特斯拉的时间分配估出的比例。工厂、设计会议、工程会议、生产会议，占掉了绝大部分。

推特？他说那几乎不占时间。

2018 年，外界对马斯克的印象和他自己给出的这个数字，差得有点远。那阵子他在推特上发的东西，比很多全职内容创作者还勤。可在他自己的账本里，真正的工作发生在喷漆车间、车身车间、总装线旁边，看一块钢板怎么一步步变成一辆能开走的车。

Marques Brownlee（网上都叫他 MKBHD）就是在这样的地方逮到他的。采访地点选在特斯拉工厂的高处，背景里是空的运门架，一趟一趟把车门送到装配点，再空着回来。马斯克坐下来，先自嘲了一句：

有时候人们觉得我花很多时间在推特上，我不知道他们为什么会这么想，这太离谱了。（马斯克）

如果不在这个工厂，他多半在内华达的超级工厂（Gigafactory）。两个地方，构成了他那几年生活的绝大部分。采访里他没提"产能地狱"这个词，但他说"最近几个月一直在工厂里转"，说的就是那段时间。

这场对话从特斯拉的产品聊到技术、自动化、公司战略，信息量很密。下面按话题拆开讲。

喜欢是沉默的，爱才会开口

MKBHD 先问了一个所有车企都绕不开的问题：除了把产品做好，你怎么让人对特斯拉兴奋？

马斯克的答案很干脆：特斯拉把所有的钱都投进产品里，尽力把产品做得尽可能有吸引力。因为卖东西最有效的方式是口碑。

一个人买了车，如果他真的很喜欢，他就会去说。关键是做出人们爱的产品。如果你只是喜欢一样东西，你不会太在意，也不会主动去讲。只有那些让你有高有低、情绪起伏的东西，你才会一直说。（马斯克）

他对"爱"和"喜欢"的区分，做产品的人应该记下来。喜欢是沉默的，爱才会开口。一个用户说"这车还行"，等于什么都没说。一个用户愿意在饭桌上主动聊二十分钟，那才叫传播。

这套逻辑的代价是慢。口碑是一辆车一辆车攒出来的，没有捷径，也没法靠一次营销活动引爆。好处是，一旦攒起来，它比任何广告都结实。广告买的是注意力，口碑买的是信任，后者贵得多，也耐用得多。

特斯拉不投广告，不请代言，不打折。马斯克自己买车也付全价。他说这话的时候语气很平，像在陈述一条不需要讨论的规则，没有标榜的意思。

采访现场的三个人，恰好代表了三种用户。MKBHD 自己是 P100D 车主，同事 Rich 在等 Model 3，摄像师 Brandon 也在等。有人订了长续航版，蓝色，后轮驱动。马斯克听完配色组合，说了句"这个组合不错"。

把车做便宜，比把车做快难得多

MKBHD 提到一个数据：Model 3 的前五大置换车型里，有一款是普锐斯（Prius）。普锐斯起售价两万多美元，丰田的产量是特斯拉的很多倍。

那特斯拉能不能做一款更便宜的电动车？

马斯克说，能。要做到 2.5 万美元左右的车，如果真拼一把，大概三年。

便宜从哪来？两件事：设计和技术进步，加上规模。他拿手机举例。

最早的大哥大，出现在 1987 年的电影《华尔街》里，主角拎着一个公文包大小的电话在海滩上走。那东西只能打电话，续航大概 30 分钟。

马斯克说，在那个年代，再多的钱、再大的规模，也没法让那台手机变便宜。它缺的东西，是无数次工程迭代和设计迭代。

现在的手机大概进化到第 30 版。每一版都能塞进更多能力，集成更多零件，找到更好的生产方法。结果是它同时变得更好和更便宜。

任何新技术的降价路径都一样：多个版本，加上足够大的产量。没有第三条路。这条规律听起来平淡，但它解释了很多事：为什么第一代产品总是又贵又糙，为什么后来者往往能做得更便宜，为什么急着降价的厂商通常降不下去。

汽车行业还有一个额外的难点。马斯克说，这个行业竞争激烈到近乎疯狂。其他车企的产量比特斯拉大得多，经济规模好得多。特斯拉只能一边爬产量，一边把成本往下压，两条腿同时走。

所以他给出的三年期限，是在"真拼一把"的前提下。言下之意，这已经是很乐观的估计。

Roadster 的任务：拆掉燃油车最后的光环

MKBHD 问，特斯拉近期有什么让人兴奋的东西？

马斯克说，产品想法远远多于资源。过去特斯拉一次只做一款车。接下来要学会一边走路一边嚼口香糖，同时做两款，而且两款都得是好产品。

名单很长：Model Y，紧凑型 SUV，价格和 Model 3 相当；Semi 电动卡车；皮卡；下一代 Roadster。

Roadster 像甜点。它很贵，产量不会大，但它有另一个任务。

我觉得做它是有价值的，它能证明电动车在任何一项指标上都能超过燃油车。（马斯克）

燃油跑车到今天还占着一个指标，最高速度。这个指标撑着一种光环效应（halo effect），让人觉得燃油性能车还是更"正宗"，电动车只是起步快。

Roadster 要做的，是把这最后一块招牌也拆掉。MKBHD 说自己很喜欢电动车，但也清楚，跑赛道跑 30 圈，电动车的圈速撑不住。马斯克接了一句：那正是我们要解决的。他说他刚跟团队聊过，觉得这里还有余量。

Track Mode 像给车超频，风险写在明面上

Track Mode 把赛道体验从 Roadster 下放到 Model 3。马斯克说，特斯拉本质上是一群书呆子（nerds），所以这个模式会开放很多设置，像一个专家用户模式。

你可以调牵引力控制，调电池温度，配置一堆参数。系统会提示你：这么设有点冒险，刹车会磨得更快，可能会烧掉一个电路。

它像给电脑显卡超频。你进设置里把频率拉高，系统告诉你风险，然后你自己按下确认。

这个比喻很马斯克。他把车主当成愿意承担后果的成年人，没有当成需要层层保护的用户。想玩，就给你工具，也把代价说清楚。

一家卖量产车的公司这么做，并不常见。大多数厂商会把设置藏起来，避免用户把车开坏、再回来找麻烦。特斯拉反过来，把实验权交出去。这背后是他对用户的一种判断：买这车的人，本来就想折腾。

两个后视镜，吃掉 5% 的高速续航

MKBHD 问 Roadster 发布会上那句"空间很充裕"到底是什么意思。

马斯克说，意思是一米九八的人也能坐进去。他自己一米八八，他弟弟一米九三，Franz von Holzhausen（特斯拉首席设计师）一米九一。这几个人坐进去都没问题，那对绝大多数人来说就够宽了。

下一个问题更技术：Roadster 原型车没有侧后视镜。特斯拉的概念车经常这样，量产前因为法规再加回去。去掉后视镜有实际好处吗？

马斯克说，好处比大多数人想的大。

高速行驶时，两个侧后视镜对风阻的影响相当可观，它们像两个小空气刹车。典型汽车的侧后视镜，会让高速续航减少大约 5%。（马斯克）

在风洞里看烟迹，效果一目了然。气流撞上镜子，在后面形成一个低压区，等于给车尾装了个减速板。

理想的空气动力学形状是水滴形。尾部不能是钝的，钝尾会在后面拖出一大片低压区，把车往后拽。后视镜的问题一模一样。要减小影响，得在镜子后面加一个锥形过渡，或者干脆把它和车身融合。

法规要求制造商装后视镜，但车主可以改。至少在美国，规则管的是制造，不管驾驶。马斯克说，这也正是造一辆好看、性能好、空气动力学又好的车这么难的原因：约束太多，能腾挪的空间很小。

这句话值得停下来想想。外行看车，看的是线条、比例、颜色。内行看车，看的是一堆互相打架的约束：碰撞法规、行人保护、能耗、成本、制造公差。设计好看，本质上是在约束的缝隙里找形状。

200 kWh 电池包，地板会高 4 到 5 英寸

Roadster 的参数：0 到 60 英里（约 96 公里）加速 1.9 秒，200 kWh 电池，续航 600 英里以上。马斯克顺口提了一句，比 Ludicrous 更高一级的模式叫 Plaid。

MKBHD 问了个很技术的问题：这些数字，是基于 2020 年技术进步做出的假设，还是现在就能做到，只是没有产能？

马斯克的回答是，它基本上就是两个 Model S P100D 的电池包叠在一起。但电池包里有很多东西跟电芯无关，封装、结构件、安全件都在里面。所以电芯数量翻倍，电池包的体积只增加大约 80%。

如果按现有技术做，车厢地板会高 4 到 5 英寸。

但他们预计还能再挤出 10%，也许 20% 的提升。原因很实在：Roadster 是贵车，可以用最先进的设备和材料。这和电脑一样，新显卡、新 CPU 刚出来时贵，过一段时间价格就下来了。贵车先吃这波红利，等技术成熟再往下放。

这段回答透露的是特斯拉一贯的节奏：先用高价产品把新技术养熟，再把它推到低价产品上。Roadster 是实验室，Model 3 是考场。

总装线上，机器人抓不住一根软管

工厂里既有机器人也有人。MKBHD 问，人和机器的比例大概是多少？

马斯克说，差异极大，取决于生产环节。有的环节 80% 到 90% 自动化，有的只有 10% 到 20%。

人强在哪？适应、快速演进，还有做那些精细而琐碎的动作。

然后他讲了一个特斯拉犯过的大错：试图自动化总装。

总装是把零件装到一起。比如你要接一根晃来晃去的软管，机器人得先找到它，抓住它，再接到另一根软管上。这个对机器人来说非常难。一个人走过去，一下就搞定了。（马斯克）

现场景象很荒诞。机器人抓错东西，抓空气，然后一头撞到车上。

马斯克管这叫"喜剧式的悲剧"。软管刚才在这，现在在那，人一看就明白，机器人不明白。它没有"这个东西必须连到那个东西上"的常识，不管两者怎么到位。

他说，你到现场看一眼就会发现，这事明显得不能再明显。可当时他们就是试了，还试了很久。

这段自述里有种难得的坦白。一个以工程能力著称的 CEO，公开承认自己在最引以为豪的环节上判断错了，而且错得很基础。

还有一个瓶颈是招人。工厂里人和机器并存，他打了个比方，像一个集成在一起的赛博格（cyborg）。机器负责重复、搬运、需要力气的活，人负责判断和收尾。

这个分工看着朴素，实际上要求很高。它要求产线设计者清楚每一道工序到底需要什么能力：是力气，是精度，还是临场判断。搞错了，就会出现机器人在那儿对着空气挥舞手臂，旁边站着一个三秒钟能干完的人。

Model X 是一次傲慢的练习

特斯拉的"秘密宏图"（Master Plan）第一部，路径很清楚：先用低产量、高价格的 Roadster 起步，再做产量更高、价格更低的 Model S，最后是 Model 3。

Model X 夹在中间。马斯克对它有一句很重的评价：那是一次傲慢的练习（exercise in hubris）。

X 是好车。但当时他们被"艺术"带偏了，想要最好的艺术，也想要最好的技术，结果偏离了使命，也就是推进电动车的核心目标。它还拖慢了 Model 3。

想要好的艺术、好的技术，这没错，但我们确实从使命上分心了，也让 Model 3 晚了一点。（马斯克）

这段话放在一家公司的 CEO 嘴里，分量不轻。它等于承认：一款卖得不错的旗舰车，从战略上看是绕了路。鹰翼门很好看，工艺很复杂，量产很痛苦，而这些东西对"让世界转向电动"这个目标，贡献有限。

不过他自己也补了一句：X 现在是一辆很棒的车。这句补充挺真实。做出来的东西可以很好，但好在错误的地方，那还是错误。

从一年一款，到同时两款

MKBHD 问，第一部宏图走完，接下来是不是只要把船稳住，挑机会下手？

马斯克说，这个战略选择很难：一边是专注，一边是想做很多款车。

特斯拉过去一次只做一款。现在想试试同时做两款。如果两款做顺了，再试三款。其他厂商会同时做 12 款，但他们规模大得多。

专注和小步扩张之间，没有标准答案，只有节奏。特斯拉的节奏是：先把一件事做到能重复，再往上加一件，没有一次铺开。

这个思路和他前面讲的自动化其实是一回事。总装自动化失败，是因为想在还没搞懂的地方一步到位。产品线扩张，他学乖了，先加一款试试。

采访结束前，MKBHD 说自己是 Roadster 的第一天订金用户，就冲那份兴奋。马斯克道了谢，两个人站起来。背景里，运门架还在来回跑。

这场对话里能直接拿走的东西

马斯克讲的东西并不玄。把大部分时间放在现场，把产品做到让人愿意主动谈论，用设计迭代和规模把价格压下来，承认自动化判断失误，砍掉偏离使命的项目。每一条拆开看都不新鲜。难的是同时做到，并且在犯错之后当场认账。

还有一层信息容易被忽略：他讲的每一个判断，都能追溯到具体的现场。后视镜 5% 的续航损失来自风洞里的烟迹，机器人抓不住软管来自产线上的真实画面，Model X 跑偏来自事后对项目优先级的复盘。观点背后有实物，这是这场对话信息密度高的原因。

对做产品、做技术、带团队的人，有几条可以直接落地的做法。

  • 把时间放在一线。马斯克说自己 89% 的时间在工厂、设计和工程会议上。想让判断准，先让信息离自己近，别靠汇报和二手转述做决策。
  • 做让人"爱"的产品，别停在让人"喜欢"。喜欢不会带来口碑，爱才会。衡量标准很土：用户会不会主动跟朋友讲二十分钟。
  • 降价靠两条腿：设计迭代和规模。别指望一步到位，也别指望只靠产量。没有迭代的规模，只会把贵的东西造得更多。
  • 自动化要分环节。重复、危险、需要力气的活交给机器；需要适应、判断、临场处理的活留给人。总装那种"软管晃来晃去"的场景，现阶段还是人的地盘。
  • 犯错之后公开承认。总装自动化、Model X 跑偏，马斯克都自己讲出来。藏着只会让同一个错再犯一次。
  • 扩张之前先证明节奏。一次做一款，做顺了再试两款，别一上来就学大厂同时开十几个项目。别人能同时做 12 款，是因为规模撑得住，不是因为方法更高明。
  • 给专业用户开放设置，同时把风险写清楚。像超频一样，把工具和代价一起交出去，让愿意承担后果的人自己去调。
  • 贵的东西先吃新技术。新方案先放在高价产品上验证和摊薄成本，等成熟了再往下放，比一上来就赌大众市场稳妥得多。
