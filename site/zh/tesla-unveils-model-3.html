2016年3月31日晚上，加州霍桑的特斯拉设计工作室，马斯克在台上说了一句话，现场直接炸了：Model 3 开放预订24小时，订单总数突破11.5万台。

要知道，特斯拉第一款车 Roadster 一年的产量只有500台。11.5万是那个数字的230倍。而且这些人下单的时候，车还没开出来，价格只知道一个3.5万美元的起步价，配置表几乎是空白。

这场发布会值得重新读一遍。它没有堆参数，没有对比竞品，前面三分之一的时间马斯克在讲气候、讲碳排放、讲死亡人数。等到所有人以为要揭幕了，他又把特斯拉十几年的产品路线图从头讲了一遍。

一辆3.5万美元的车，为什么要用这种方式介绍？答案藏在他讲的每一个环节里。

一场汽车发布会，开场是二氧化碳浓度曲线

马斯克上台后的第一句话不是“欢迎来到Model 3发布会”，而是“我想先说说我们为什么要做这件事”。

他放了一张图，大气中的二氧化碳浓度。图上那条线看起来几乎是垂直的，已经越过403 ppm，还在往上爬。

上一次大气碳浓度达到这个水平，是1100万年前。那差不多是灵长类开始直立行走的时候。那时候的世界和现在完全不一样，我们不想回到那个状态。（马斯克）

这个类比很狠。他没说“气候正在恶化”，他把时间轴拉长到千万年，让观众意识到人类文明的全部历史都发生在这条曲线的平坦部分，而现在它翘起来了。

接着是温度。全球平均气温已经上升2摄氏度。马斯克补了一句：这个数字没讲完整故事，因为极端温度上升的幅度可以达到20度。

平均值掩盖了分布的尾部。平均升2度，意味着原本几十年一遇的极端高温变成了几年一遇，原本的“最热夏天”变成了常态。这一点在讨论气候时经常被忽略，因为平均值好记，尾部才是真正杀人的部分。

然后他抛出了另一个数字，跟气候无关，跟每个人的肺有关。麻省理工学院的一项研究显示，仅在美国，每年就有5.3万人死于汽车尾气排放。

一辆车在排有毒气体，这事儿对健康显然没好处，逻辑简单到不需要论证。马斯克在这里几乎没做修辞，只是把两个数字放在一起：403 ppm 和 5.3万条命。

秘密蓝图：一家小公司只能用杠杆撬行业

讲完为什么，马斯克放出了他写的第一篇公司博客，标题叫“秘密蓝图”（Secret Master Plan）。

他说这东西原本是个三步走的三部曲，现在变成了“四部曲的三部曲”。台下笑了。这句自嘲里有个事实：计划赶不上变化，但路线图本身没跑偏。

蓝图的核心逻辑只有一条：任何新技术都需要多轮迭代和规模效应，才能从“做得出来”走到“做得好还买得起”。一家资源极少的初创公司想撬动百年汽车工业，唯一的办法是从小处起步，一级一级往上跳。

具体到特斯拉，就是四步：高价低量的跑车，中高价中量的豪华轿车和SUV，低价高量的家用车，以及未来更便宜的产品。

这个顺序不能乱。如果特斯拉第一天就去造3.5万美元的车，它活不到2016年。

Roadster 的真正作用是打破刻板印象

2008年的 Roadster，售价超过10万美元，一年只能造500台。从商业角度看这是个玩具，从战略角度看它干了另一件事。

在 Roadster 之前，公众对电动车的印象是慢、丑、续航短、性能差。这个印象不打破，后面所有产品都会被同样的偏见挡住。

Roadster 是第一辆真正意义上的好电动车。我们必须打破那个模具，让世界看到电动车可以很快、很漂亮、性能很强。（马斯克）

马斯克在台上专门感谢了买 Roadster 的那批人。他说这话不是客套，因为 Roadster 年产500台，却产生了远超其体量的影响。

最直接的证据来自通用汽车。前通用副总裁鲍勃·卢茨（Bob Lutz）公开表示，雪佛兰 Volt 项目受 Roadster 启发，Volt 又影响了后来的日产聆风（Nissan LEAF）。

一台年销500辆的小车，改变了行业里最大的几家公司的产品决策。这就是杠杆。

Model S 拿的那些奖，目的不在奖本身

第二步是 Model S。马斯克在现场问了句“在座有开 Model S 的吗”，然后自己接话：那你们知道它是辆好轿车。

参数摆在那里：最多七座，五个成人加两个孩子；被 Motor Trend 等媒体测为史上最快的量产轿车；操控好，有 Autopilot；几乎每一个评测机构都把它评为当年最佳车型；《消费者报告》（Consumer Reports）给了它“史上最佳车”的评价。

念完这些，马斯克做了一段非常重要的解释。

拿这些奖不是目的。重要的是让汽车行业、让全世界看到，一辆电动车真的可以成为最好的车。这才是真正要紧的事。（马斯克）

这句话说明了特斯拉每一代产品的隐藏目标。Roadster 证明电动车可以性感，Model S 证明电动车可以全面超越燃油车。每一次都在拆掉一块“电动车不行”的心理墙。

墙拆完了，才轮到价格。

Model X 补上市场的另一半

数据是：轿车和SUV各占汽车市场的一半。只做轿车会丢掉一半客户，所以 Model S 的平台被延展成了 Model X。

Model X 的鹰翼门（Falcon Wing doors）在台上被马斯克轻描淡写地提了一句“确实给我们带来了一些挑战”。了解那款车交付历程的人都知道这句话背后有多少工程麻烦。这也是这场发布会难得的诚实时刻。

S 和 X 收的钱，养出了 Model 3

这一段是全场最容易被忽略、但对理解特斯拉最关键的部分。

Model 3 要做到高产量、低成本，需要的工程投入是几十亿美元级别。这笔钱从哪来？来自 Model S 和 Model X 的销售收入。

我想对所有买过 S 或者 X 的人说一句，谢谢你们帮 Model 3 付了研发费用。Model 3 能出现，是因为你们。（马斯克）

这句话把特斯拉的产品序列讲透了。每一代产品不只是卖给当下的客户，它在给下一代产品融资。豪华车的高毛利，是廉价车能存在的前提。

很多新造车公司跳过了这一步，直接宣布要做“国民电动车”，然后卡在资金和产能上。

3.5万美元的车，标配清单值得逐条看

Model 3 的起步价是3.5万美元。马斯克强调，就算一个选装件都不买，这辆车依然好得离谱：

不选任何配置，你也不可能用3.5万美元买到更好的车，连接近的都没有。（马斯克）

那么标配里有什么？

  • 安全：不只是平均五星，而是每个细分项目都拿五星。马斯克说得很直白，安全必须排第一，这关系到买车的人和他们的家人朋友。
  • 性能：基础版0到60英里每小时（约96公里每小时）不到6秒，换成0到100公里每小时也在6秒以内。他的原话是“在特斯拉我们不造慢车”。还补了一句，会有快得多的版本。
  • 续航：EPA 工况至少215英里。他特意强调这是最低数字，希望能超过。
  • Autopilot 硬件：全系标配。所有自动驾驶安全功能都在每台车上，不需要额外购买选装包。
  • 超级充电：全系标配，不额外收费。

这份清单在2016年是反常识的。当时行业惯例是：安全气囊数量分档，高级驾驶辅助功能锁在顶配或者选装包里，快充要单独付费解锁。特斯拉把这几样全部拉到基础款。

原因不难推。这些功能一旦成为标配，它们就从“卖点”变成了“门槛”。竞争对手要么跟进，要么在配置表上永远低一档。

车变小了，人还得坐得舒服

做小车最难的地方不是把尺寸缩下来，是在缩下来之后里面还能舒服地坐五个成年人。马斯克在“comfortably”这个词上停顿了一下，说这个词才是重点。

工程上他们做了两件事。

第一件，把仪表台往前推。燃油车前面有个大发动机，需要一层隔火墙（firewall）把高温和噪音挡在座舱外。电动车没有发动机，这层墙就不必存在。于是前排座椅整体前移，仪表台被压薄，第二排的腿部空间就出来了。

马斯克说，今晚试驾的人会感觉到自己坐得比平时靠前一点，但前排的感受其实很好。

第二件，后排头顶是一整块连续的玻璃。这块玻璃带来的是头部空间和开扬感。他的评价是，在同尺寸的车里，Model 3 的空间感是最好的。

还有一个燃油车很难做到的事：前后两个行李厢。因为没有发动机占位，前舱也是空的。同样外部尺寸下，Model 3 的载物能力超过任何一辆燃油车。

现场有人问能不能在车内放一块七英尺长的冲浪板。马斯克的回答是：可以。

车还没量产，充电桩先铺开

超级充电网络在当时已经建成3600多座，目的地充电桩数量差不多。计划是到2017年底，超充数量翻倍，目的地充电桩翻四倍。

为什么在这里花这么多篇幅？马斯克给的理由是自由。

拥有一辆车，很大一部分意义在于自由，在于你想去哪就去哪。超级充电桩对这件事是决定性的。（马斯克）

续航数字解决的是“能不能开到”，充电网络解决的是“敢不敢开去”。两个问题分开。一辆续航300英里的车，如果沿途充不上电，它的有效活动半径会大幅缩水。

还有一个细节：Model S 的车载充电器能适配任何国家的电压和电流。也就是说，世界上只要有电的地方，这车就能充。这个设计对出口市场很重要。

销售和服务网点：从215个到441个

当时特斯拉在全球有215个销售和服务网点，分布在亚洲、北美和欧洲。计划到2017年底翻倍到441个。

马斯克给的标准很具体：在北美、欧洲和欧亚大陆，只要你在一个中等规模的城市圈里，就能买到车，也能修车。

对3.5万美元这个价位的买家来说，这一点比参数更实际。买豪华车的人愿意为一次保养开两小时，买家用车的人不愿意。

真正的瓶颈在电池，不在整车厂

有人问这些车怎么造出来。马斯克的回答分成两半。

整车这半，弗里蒙特工厂历史上曾经做到年产近50万台车，所以特斯拉达到同样数字“不能说是轻松，但非常可行”。

电池这半才是硬骨头。要造50万台车，就要有对应的电池产能，而这个量级相当于吞下全世界锂电池的总产量。

这就是内华达沙漠里那座超级工厂（Gigafactory）存在的理由。

马斯克给了一组尺度对比：按占地面积算，它将是世界上最大的建筑，任何类型都算；按体积算，它只输给华盛顿州的波音工厂。它一家的锂电池产量，会超过全世界其他所有工厂加起来的总和。年产能50 GWh。

更关键的是，它不只做量，还要做当时世界上最先进的电芯和电池包。高产量加上最先进的技术，两个条件同时具备，Model 3 的成本结构才成立。

这段话其实是在回答一个所有人心里都有的疑问：3.5万美元的电动车，电池成本怎么压下来？答案不在采购谈判桌上，在一座还没完全建好的工厂里。

“某个地方已经是愚人节了”

终于到了揭幕环节。马斯克先卖了个关子：“今晚我们没把车带来。”台下安静了半秒。他接着补了一句：“某个地方已经是愚人节了。”

发布会是3月31日，第二天就是愚人节。这个玩笑开得挺马斯克。

然后是那组数字：24小时内订单11.5万台。他说这话的时候语气明显有点飘，连说了好几个“so”。

交付时间定在2017年，他自己也承认这个时间表“我确实比较有信心”。了解特斯拉交付史的人看到这句话，大概会笑一下。

把这场发布会当成一份产品战略文件来读

回头看，Model 3 发布会的信息密度集中在一个地方：它完整展示了特斯拉怎么从零走到大规模量产，每一步的钱、技术、供应链从哪来。

碳排曲线和死亡人数解释动机。秘密蓝图解释路径。Roadster 和 Model S 解释品牌资产怎么积累。S 和 X 的销售收入解释研发资金从哪来。Gigafactory 解释成本结构。超充网络解释使用体验怎么兜底。最后才是那辆3.5万美元的车。

这个叙事顺序本身就是策略。如果一上来就讲车，观众记住的是参数；从动机讲到基础设施再讲到车，观众记住的是一整套判断。

对做硬件和做产品的人来说，这场发布会里有几条规律值得抄下来：

  • 先找到那个卡住成本的物理约束。Model 3 的成败不在设计，在电芯产能和成本。找到它，然后把最大的一笔钱押上去。
  • 用高价低量产品养技术和品牌，用中价中量产品养现金流，用低价高量产品换规模。这个顺序跳过任何一步，后面都补不回来。
  • 基础设施的铺设节奏要比销量提前半步。充电桩和门店在车大规模交付之前翻倍，用户提车时才不会撞墙。
  • 把别人的选装包变成你的标配。Autopilot 硬件和超充全系标配，一次性把竞争对手的配置表变成减分项。
  • 预订量不等于交付量。11.5万台是一天的意向金，真正的考验是接下来12到18个月的产能爬坡和转化率。看这类数据，永远要跟进后面两个指标。
  • 产品发布会的第一页可以不是产品。如果动机足够硬，讲动机比讲参数更能建立信任。

3.5万美元这个价格，在2016年是一道分水岭。它意味着电动车第一次被摆到了和凯美瑞、雅阁、帕萨特同一个货架上。之前的 Roadster 和 Model S 都在说服有钱人换一种玩具，Model 3 要说服普通人换一种生活方式。

这两个任务，难度完全不同。前者靠惊艳，后者靠的是充电桩密度、维修网点、二手车残值、保险费率，一堆不上发布会PPT的东西。

马斯克在那晚讲的每一项基础设施，都是在为后一个任务做准备。车只是一个入口。
