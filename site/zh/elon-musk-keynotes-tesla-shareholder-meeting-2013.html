《消费者报告》给特斯拉 Model S 打了99分。往前数六年，只有一款车拿过同样的分数，那是雷克萨斯。Model S 是第一款、也是唯一一款拿到99分的美国车。

时间回到2013年年中，特斯拉股东大会。马斯克站在台上，先感谢了一圈股东，然后没忍住提了一句做空的人。

“很多人以为特斯拉会失败，其中不少人还愚蠢地做空了我们的股票。我猜那些人今天不在这里。”（马斯克）

那时候 Model S 刚交付一年多，股价从年初的三十几美元涨到了一百上下。会场坐满了人，问询环节排起长队，一直开到原定散会时间之后快一个小时。这篇文章把马斯克那天讲的东西拆开：车为什么好、钱够不够花、充电站怎么铺、下一辆车长什么样，以及他跟全美汽车经销商协会那场还没打完的仗。

99分不是满分，扣掉的那一分指向充电

马斯克花了不少篇幅解释这个99分。因为《消费者报告》的评测方式和别家不一样：他们自己随机去市场上买一辆车，不通知厂商，然后开四个月，各种路况各种用法都试一遍。

“神奇的是，他们那辆车一次都没坏，”马斯克说，“他们肯定是运气特别好。”

那为什么不是100分？他专门去问了。扣分的地方在于快速充电的覆盖，评测方担心车主没法自由地长途出行。马斯克说他自己也不确定把这个问题解决了能不能拿到100分，他没问过，但反正要去解决。

这个扣分点恰好构成那天演讲的主线。

一个季度的收入，超过全美其他电动车加起来

先说成绩。2013年第一季度，特斯拉是美国销量最高的电动车品牌。如果按销售额算，特斯拉一家的收入超过了全美所有其他电动车的总和。

马斯克自己给这个数据加了注脚：这说明必须尽快把更便宜的车做出来，希望三到四年内能实现。

他列了几项家底。知识产权积累了不少，虽然他说自己不是专利的忠实粉丝。品牌认知度很高，而且是两极分化的那种高：人们要么爱特斯拉，要么恨特斯拉，很少有人无感。合作伙伴有戴姆勒、丰田、松下。Model S 这个平台还能延伸，Model X 就建在它上面，之后可能还有别的产品。

更长远的，是一个成本更低的平台，走更大的量，造一辆价格大约 Model S 一半、尺寸略小的车。他说这是他从特斯拉成立第一天起就定下的目标。

现金多到“不用贴着树梢飞”

有股东问营运资金管理，担心现金流。马斯克的回答很直接：上一轮融资募的钱比实际需要的多。

为什么要多募？他打了个比方。飞机就算状态再好，贴着树梢飞也是件冒险的事。账上多留现金，是为了扛住突发状况：加州来场大地震，或者某个供应商破产，公司不至于立刻陷入被动。

“我们募的钱比我们认为需要的多，是想给人们一个高确定性的信号：即便出现短期的供应中断，特斯拉也能撑过去。”（马斯克）

他承认这么做会让公司在现金管理上显得不那么精打细算，但“就算我们现金管理做得烂，也还是没事”。

北美一万五，全球四万，这个推算他标了“猜测”

需求端的数据是这样的：北美市场需求大约一万五千辆出头，这个势头延续到了第二季度，Q2 的销量和 Q1 大致持平。

第三季度会多一块欧洲的量，车子6月底上船，7月到港。第四季度开始发往亚洲。

然后他做了一个外推：如果美国需求是一万五，按三倍估算全球，至少是四万辆。他连着强调了两遍这只是推测，不能当成承诺，但补了一句“我认为这是可能的”，后面又说实际可能更接近四万。

支撑这个乐观判断的，是一个他反复提到的现象：特斯拉车主是最好的销售员。车交付到一个地区之后，车主会主动带别人看车、让人试驾。他见到新车主，对方常说的第一句话是“我又帮你们卖了几辆”。车在一个区域保有量越大，那个区域的销量就越好。这种病毒式的传播，是他敢做全球三倍推算的依据之一。

阻碍买车的，是“坏了去哪儿修”

渠道在扩。门店和展示厅到年底从42家增加到50家左右，涨幅五成。

但马斯克说，真正卡住消费者的往往跟附近有没有门店关系不大，他们关心的是“我这车坏了去哪儿修”。所以服务中心的扩张幅度更大，年底数量几乎翻倍。

他特别提到美国中部。很多人低估了中部地区的真实需求，他认为那里的潜力比大多数人想的高，接下来的服务中心扩张会有很大一块放在中部。这个判断在后面问答环节被一位纳什维尔的股东当场验证，对方站起来请求尽快在当地开服务中心和门店，马斯克当场表示认同，并说会在网站上公布服务中心的开业时间表，让下单的人知道提车时附近有没有服务点。

超级充电：免费，而且是一辈子免费

那天信息量最大的一块在这里。

特斯拉的超级充电桩，充电免费，而且是永久免费。不只是现在免费，是这辆车开到报废都免费。马斯克说这个模式的逻辑很简单：把充电成本预先算进车价，车主到了充电站插上就行，不用掏钱、不用刷卡、不用处理任何账单。

铺设速度：到当年下个月底，充电站数量比年初翻三倍。六个月内覆盖北美主要都市区。一年后覆盖北美80%的人口。两年后覆盖98%。

他的原话是，买了特斯拉，等于永久拥有全美免费长途出行能力。

技术也在迭代。充电功率从90千瓦提高到120千瓦。更关键的是充电曲线的“衰减点”往后推了。锂电池充到接近满电时必须降速，就像往杯子里倒水，快满的时候得放慢，不然会溢出来。特斯拉把这段降速的起点往后挪，所以在超级充电站的实际停留时间，相比之前的体验差不多砍了一半：过去要40到45分钟，现在20到22分钟。

他自己年底要开着车带孩子们从洛杉矶去纽约，全程只靠超级充电网络。他说这像是切维·蔡斯那类公路喜剧片里的情节，可能会有点折腾，但应该好玩。二十年前他读大学时和弟弟开车横穿过美国，从洛杉矶一路开到费城，中间绕了大峡谷、四角地区、拉什莫尔山、芝加哥，这次想带孩子再走一遍。

这场旅行还有个功能：亲自证明电动车能跑长途。

导航里那个闪电图标

有个细节被大部分媒体报道忽略了。马斯克说充电网络的地理扩张抢了头条，但技术本身的进步同样重要。

Model S 的导航屏上有个闪电图标，点一下，车会自动把你导到最近的超级充电站，而且这个数据是实时更新的，新站一上线立刻可见。

更进一步，导航软件升级之后，你输入北美范围内任意目的地，车会自动规划出最优路线，把沿途该在哪个站充电、充多久都算好，目标是最短总耗时。你不用想，打字或者说出来，剩下的车自己算。

这个功能的潜台词是：电动车的里程焦虑，一部分是心理问题，一部分是规划麻烦。把规划这件事从人脑转移到车载电脑，焦虑就少了一半。

Model X：那对门，和世界上最快的扭矩分配

产品线上，Model S 之上是 Model X，目标是吃下小型厢式车市场，以及 Model S 覆盖不到的那部分 SUV 市场。Model S 能坐五个大人加两个孩子，前备箱也能装东西，偶尔七个人出行没问题。但如果你经常要坐那么多人、想要更高的坐姿和更大的空间，就得等 Model X。交付时间是次年年底。

Model X 有两个创新点，马斯克讲得很细。

第一个是双铰链鹰翼门。普通车门开门时是向外划一道弧线，旁边有车就会撞上，车库顶低也会撞上。双铰链让门先向上、再向外翻，占用横向空间很小，不会碰到旁边的车，也不会顶到车库天花板。

他承认这是在冒险，因为人们没见过这种门，接不接受很难说。安全方面做了两件事：门边装了防夹条，就算孩子最后一秒把手指伸进去，门也不会夹伤；门上有接近传感器，离障碍物还有几英寸就自动停下。

这对门真正的价值在第三排。如果第二排装了儿童座椅，常规车门根本进不去第三排。有了这个开口，你可以直接走到第三排。而且第二排的头顶空间足够一个六英尺三、六英尺四以下的人站直，抱孩子放儿童座椅不用再扭着身子往里探。

第二个创新，是世界上第一款量产的双电机全轮驱动。前轴加一个电机，扭矩可以在前后轴之间动态分配，分配的时间精度是毫秒级。

马斯克解释这个精度意味着什么：在千分之一秒的尺度上，车几乎是静止的，系统可以不停地重新分配扭矩。开过油膜或者冰面时，哪个轮子抓得住，扭矩立刻转过去，过了打滑区再转回来。传统机械四驱有惯性、有延迟，做不到这个反应速度。他的说法是，这会是“数字对模拟”的体验差距。

电池包铺在底盘上，重心极低，这会是重心最低的 SUV。目标是：跑车的操控、好看的外形、比小型厢式车更强的功能性。

2016年底，一辆半价的 Model S

产品节奏马斯克列得很清楚。当年已经推出60千瓦时版本，欧洲版研发完成，支持三相充电，亚太版在推进，中国有专门版本。Model X、右舵、全轮驱动同步在做。

再往后，2016年底，第三代车。尺寸比 Model S 小，价格大约一半。他给了一个模糊的方向：会有明显的家族特征，看起来就是特斯拉家的车，但希望能做出一些不只是“缩小版 Model S、放大销量”的东西。如果运气好，自动驾驶的一些元素也许能赶上放进这辆车，但他不确定时间上来不来得及。

关于电池能不能撑起三万到四万美元的价位，他的回答是：需要显著的技术进步，但不是奇迹。一辆有竞争力的平价电动车，续航至少要有200英里，才能和燃油车比。特斯拉在和松下等公司合作开发专门针对车用的新电芯化学体系。他对“不需要奇迹就能做到”表示乐观。

他还提了一个自己熟悉的领域：超级电容器。他说这个方向有可能出现突破，但今天市面上没有任何产品能达到量产锂电池的能量密度。手机快充那种新闻常见，电容能快充，可跑不远。他个人对能量密度的突破越来越乐观，只是“还没到公开的程度”。

跟全美汽车经销商协会的正面冲突

问答环节最激烈的一段，来自一位股东提问：全美汽车经销商协会（NADA）和一些州协会基本是向特斯拉宣战了，在州议会和法院里堵特斯拉的直销模式，你们公布的门店扩张计划有没有因此打折？

马斯克的回应没有绕弯。他说经销商协会确实在制造麻烦，让事情变难。协会的说法是“你们应该授权加盟商”，他的反问是：过去90年里，有哪家创业公司靠加盟模式成功过？菲斯克没成，科达没成，让他举例子，举不出来。

他还点了一个更根本的分歧：特斯拉不打算在售后服务上赚钱，经销商体系的利润大头恰恰来自售后维修。这两套逻辑放在一起，天然对立。

关于政治影响力，他提醒在场的人别搞错了对手。站在对立面的是资金雄厚的大型全国性经销商集团，它们掌握着州一级立法机构的话语权，街角的小店没这个能量。

然后他抛出一组民调数据。在任何一个州、全国范围、任何语境下问“是否应该允许特斯拉直销”，支持率从86%到99%不等。最低的那个86%，是经销商花了大力气动员反对之后的结果。

“如果民主运转正常，议员在执行人民的意愿，就不会有立法去人为限制直销。经销商协会现在到处宣扬他们在得州击败了我们，在北卡推进、在弗吉尼亚阻止我们。他们拿颠覆民主来炫耀，我觉得这很离谱。”（马斯克）

他的判断是，这事最后会由消费者引爆。如果一家公司公开为花钱扭曲民意而沾沾自喜，消费者会用不买它的车来回应。

专利、品牌、还有那句“我没有过滤器”

有股东问，未来五到七年怎么维持特斯拉的品牌形象。马斯克的回答可以概括成一句话：品牌是产品的副产品。

他说自己不太相信品牌，也不太相信营销。有篇文章夸他是营销天才，他的评价是“这是最蠢的说法，不可能是真的”。他说自己的毛病在于根本没有过滤器，跟过滤器太强沾不上边。

“品牌真正形成的方式，是你做出好产品。人们看到这辆车，会想：这家公司能造出这样的车，那它做的其他东西大概也不错。品牌就这么简单，没有更复杂的东西。”（马斯克）

关于超级充电网络会不会开放给其他厂商，包括用特斯拉动力系统的奔驰 B 级，他的态度是开放的：愿意，但要分摊成本，因为充电网络的费用本来就摊在车价里。他不希望变成每次充电都要付费的模式，那太麻烦。有人写文章说这是要建围墙花园，他否认这是营销阴谋，解释说高速充电这件事如果等所有人达成一致，就永远做不成，所以特斯拉只能先自己干，别人可以加入、可以照抄，也可以想出更好的方案。

太阳能车棚，和“丧尸末日也能用”

有人问超级充电站的电从哪来、长期成本怎么覆盖。

马斯克的规划是：几乎所有超级充电站都配太阳能车棚，在停车位上方架光伏板。有人算过账说那片地方的日照发不出需要的电，但那些算法忽略了一件事：充电位大部分时间空着，真正排队集中在周五下午到晚上和周日下午，那是人们长途出行的时候。电站的规模是按峰值配的，而峰值很少出现，所以全年算下来，光伏发电量可以超过车辆消耗的电量，做到净输出为正。

偏远地区另说。挪威有些站靠近北极圈，冬天几乎没太阳，这些站会采购可持续电力，水电或者地热。目标是整个网络完全由可持续能源驱动。

长期运维成本比外界估计的低得多。初期建站是主要投入，之后如果全年净发电为正，从电网取的只是备用的涓流补电，电费很低。土地是高速休息区的既有车位，租金几乎为零甚至没有，等于给对方加了个吸引高端客户的磁铁。

至于单个站的造价，他后来回答另一位股东时给了数字：不含太阳能大约15万美元，含太阳能大约30万美元，各站有高有低。

他还提到超级充电站开始配固定式储能电池，白天用太阳能把电池充满，车来了再从电池取电。这为未来突破120千瓦留了口子，新硬件是往上叠，不用推倒重来。他那句玩笑话是：就算丧尸末日、文明崩塌，超级充电站也应该还能用。

关于车顶太阳能，他的判断比较冷静。太阳能板装在房子或办公楼顶上几乎总是划算的，角度对、一直能发电。装在车上，很多时候车停在车库里，而且车规光伏板的每瓦成本比固定式高不少，所以近期没把它当重点，但长期看“挺酷，也许可以做”。

几个被追问的技术细节

有住在 Cul-de-sac（尽头环路）的股东说，社区里小孩越来越多，电动车太安静有安全隐患，能不能加点声音。马斯克的思路是：长期最好的方案是用接近传感器，把悦耳的声音定向投射到行人所在的方向，噪音最小、不扰民、只传到需要的地方。这需要一些工程工作，但方向应该是这个。

有人问 Roadster 为什么用不了超级充电桩。他解释，Model S 为了实现高功率充电，在充电口里做了高压直流直连电池包的通道，涉及复杂的电子器件、大号接线盒和继电器，因为流过的功率太大。同一接口既能走交流经车载充电机进电池，也能走直流直连电池。Roadster 没有这套直流旁路，所有电流都得经过车载充电机，只能接受交流。而且 Roadster 本来也不是为长途设计的车，开三个小时就得歇，他也承认这一点。

有摩托车爱好者问特斯拉做不做电动摩托，顺带毛遂自荐想加入特斯拉。马斯克的回答是公司要专注，眼下是 Model S，然后是 Model X。市面上已经有电动摩托车，比如 Brammo，但不是特斯拉做的。至于求职，他让对方去官网投简历，说特斯拉常常招背景不在汽车行业的人。

最大的风险，和一句关于保时捷的对比

有位股东问，创业阶段的风险都过去了，接下来最大的风险是什么。

马斯克的答案只有两条：可负担性，和长途出行。假如能把 Model S 的造价砍到一半，普及速度会非常快。长途出行的问题，靠超级充电网络解决。这两件事解决了，电动车替代燃油车的临界点就到了。

他拿手机打比方。第一代手机又贵功能又少，一代代迭代下来才变好。特斯拉想用比手机短得多的时间走完这条路，难度更大，因为工程量大得多。这些工程努力的核心方向，就是提升可制造性和可负担性。

有股东拿保时捷做对比，问经营利润率和资本开支占比。马斯克说资本开支会明显高于保时捷，因为特斯拉在扩产能，还要建超级充电网络。但毛利率这个指标，他认为长期可以接近甚至超过保时捷。Model S 和 Model X 有这个可能，第三代车不好说。第三代车本质是成本优化，他的战略判断是：那辆车宁可卖便宜一点，也不去追最高毛利率，因为走量之后固定成本摊得更薄，净利仍然可观。

Model S 的生命周期，和那个没被采纳的建议

有股东问 Model S 的产品周期，参照行业惯例，同类车六年一换代，销量在一年半到两年见顶。

马斯克说特斯拉的情况不一样，因为没有现成的销售和服务网络。Model S 的销量峰值大概会出现在第三、第四年，因为铺开北美、欧洲、亚洲的销售和售后，再加上南美、南非这些地方，至少要三四年。他还顺带回应了南非用户的抱怨，说车确实还没进南非，但会去的。大改款大概在第六、第七年，中途第三、第四年会做一次小幅更新，行业惯例如此。

有股东提了个建议：车主是最好的销售员，能不能给老车主激励，比如每推荐成交一辆送一年免费保养。马斯克说目前没有这样的激励计划，虽然按理说应该有。

另一位股东提到马斯克在推特上说“充电时间会比加油还短”，问6月的发布是不是就是这个。马斯克纠正说，6月20日办的是现场演示，没有发布环节。

城市里没车库的人怎么办

一位住在旧金山的股东说，很多城市居民没有车库，晚上车停路边，第三代车更偏城市使用，到时候有没有城市充电方案。

马斯克承认这是必须解决的问题。理想方案是城市在路边建设充电设施，车停在你平时停的地方，插上就行。退一步，去超级充电站等20分钟，体验差很多。他说开惯 Model S 的人换回燃油车，最不适应的事情之一就是去加油站，会发现加油站“真的很糟糕”。但这种体验很难说服没开过电动车的人，只有亲身经历过，才知道“在平时停车的地方充电”有多值钱。

他的态度是：城市无车库人群占总客户比例不高，但不能不解决，长期一定要有方案，无论旧金山、曼哈顿还是伦敦。

还有一位股东问新兴市场，比如墨西哥，第三代车上市后会不会进入，以及会不会坚持直销。马斯克说会进墨西哥和其他国家，最可能的路径是直销。他提到有人来找他要独家经销权，但不愿意附带销量承诺，这种条件他不会答应，否则等于把某个地区的销售能力自我封锁。北美、欧盟、中国、日本之外的市场，大概次年年中开始拓展。

零排放积分、家族化设计，和“股东价值与使命一致”

关于零排放车辆（ZEV）积分，马斯克给了个测算：预计约三分之二的销量在美国之外，那部分没有 ZEV 积分；美国销量里大约一半能拿积分，折算下来全部销量里大约六分之一带积分收入。他没听说有哪个市场会推出类似 ZEV 的替代政策。他解释 ZEV 积分的初衷其实是改善本地空气质量，洛杉矶、旧金山、纽约人呼吸的空气，燃油车排的那些气体浓度高了会致命，这个政策跟全球变暖的关系反而没那么直接。目前实行 ZEV 的大概14到16个州，覆盖约一半美国人口，他不认为这块会被替代。

有人问第三代车会不会延续 Model S 的造型，答案是会，明显的家族特征。

最后一位提问的股东问了个有点哲学的问题：你个人想推动电动车普及，同时又是特斯拉 CEO 要对股东负责，这两个目标怎么平衡。

马斯克的回答是，这俩目标长期看是一致的。特斯拉要造出大量电动车、不断推出新产品，就必须产生比花掉更多的现金，也就必须盈利，必须从现有产品里挤出足够现金流去供养下一代产品的研发。短期可能有冲突，有些动作能拉高短期股价但长期有害，他不会做。

他还顺带回答了自己那个“今年要多找点乐子”的新年决心。过去几年成就很大，回忆起来很享受，但当时压力极大。他说今年的乐趣确实在稳步上升。

至于工作资本管理和现金流的追问，他的回答前面已经说过：账上钱够，就算管得糙也没事。

那天他没说出口的判断

把整场演讲串起来看，马斯克在2013年年中讲的其实是一个三层结构。

最上面一层是产品。Model S 拿奖、拿高分、拿销量第一，证明电动车首先得是一辆好车，环保只是顺带的加分项。

中间一层是基础设施。超级充电网络免费、快速铺开、充电时间砍半、导航自动规划。这一层解决的是“能不能开电动车出远门”这个具体问题。他年底要亲自开车横穿美国，就是要把这个答案演示给人看。

最下面一层是成本。第三代车、半价、2016年底、电池技术、可制造性。这一层决定电动车能不能从少数人的玩具变成多数人的工具。他自己说得很清楚，这是他从第一天就想做的事。

三层之间有时间差。第一层已经兑现，第二层在当年年底能看到雏形，第三层还要等三四年。这中间的空档，就是经销商协会、州立法、做空者、还有那些怀疑论者活跃的空间。

他那天反复提到的一个词是“专注”。不做摩托车，因为要专注 Model S 和 Model X。不急着在车上装太阳能板，因为固定式的每瓦成本更低。不给独家经销权，因为那会锁死一个市场。这些取舍背后是同一套逻辑：资源有限，先把决定成败的那几件事做透。

对今天看这场演讲的人来说，真正有价值的地方，是他把一个资本密集、周期漫长、还要跟既得利益正面碰撞的生意，拆成了可以验证的里程碑。预测准不准反倒次要。哪一年铺多少站、哪一年出什么车、毛利率做到多少、全球需求按几倍推算，全是可证伪的数字。做得到就继续，做不到就调整。

这种把宏大叙事翻译成可验证指标的能力，比任何一句愿景都更值得学。

  • 评估一家公司时，先看它有没有把目标拆成可验证的里程碑。只有愿景没有数字的，多半是在讲故事。
  • 判断一个新产品能不能普及，盯住两个变量：价格能不能砍到大众可接受，使用场景的麻烦能不能被抹平。特斯拉当年盯的就是这两条。
  • 遇到行业既得利益方的阻挠，先看民意数据再判断输赢。86%到99%的支持率摆在那里，短期立法输了不代表长期输了。
  • 看创始人的公开表态，重点听他承认了什么不确定。“这是推测，不能当承诺”这种自我限定，比任何保证都可信。
  • 做长期投入时，账上多留现金的做法经常被看成保守，它实际买的是犯错的余地。贴着树梢飞，状态再好也是冒险。
  • 想理解一个行业的技术路线，别只看发布会的标题，去看被标题盖住的那半段。导航里那个闪电图标，信息量不比充电站数量少。
