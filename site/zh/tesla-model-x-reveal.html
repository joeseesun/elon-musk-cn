2012 年，特斯拉在洛杉矶的设计与工程工作室办了一场发布会，主角是一款叫 Model X 的车。这个时间点很微妙：Model S 一辆都还没交到用户手上，Roadster 卖了几年，公司刚走出最艰难的日子。马斯克就在此时把第三款车推上了台。

发布会地点选得有讲究。洛杉矶工作室负责设计与工程，公司总部在帕洛阿尔托，整车制造放在加州弗里蒙特的特斯拉工厂。整个链条都在加州境内，马斯克在开场反复强调这一点，用意不难猜：他要让人看到，一家加州公司能把车从图纸一路做到量产。

州长先上台，讲了点场面话，也讲了点真心话

开场由特斯拉的人介绍，请出了加州州长杰里·布朗（Jerry Brown）。他自称“月光州长”，这是他几十年前就有的绰号，他自己拿来开玩笑。他说隔壁就是造火箭的公司，而他既喜欢火箭，也喜欢电动车。

场面话之外，他讲了一句值得记下的话：加州给全美国定下了调子，眼前这座工厂属于今天，也属于未来。他还提到加州问题不少，政界、商界都有麻烦人物，但这里真正有的是创造力，而在一间设计中心开发布会本身就在说一件事，重点在设计和想象，在敢于冒险，不在纠缠旧战场。

这段致辞不长，但它给整场发布会定了一个框架：这件事发生在加州，靠的是加州的产业土壤和政策环境。马斯克后来讲碳排放时反复引用加州电网的清洁度，和州长这段话是同一个逻辑。

一家公司为什么存在，得先讲清楚

马斯克上台，第一件事是讲特斯拉的使命。

我们创办特斯拉，是为了给世界带来改变。世界迫切需要可持续的交通方式。如果我们这个世纪解决不了这个问题，我们就真的完蛋了。（马斯克）

他用的词是 fracked，既是水力压裂，也是另一个脏话的谐音，现场笑了一下。这个双关背后的判断很硬：可持续交通是必须完成的作业，并非一道可做可不做的选择题。

接着他给出了特斯拉的解题思路。光是环保立场远远不够。

如果你造不出让人心动的电动车，如果电动车只是“差不多和汽油车一样好”，那这件事就不会发生。特斯拉的使命，是用创造力和创新，造出世界上最有吸引力的车，没有例外。（马斯克）

这段话点出了特斯拉早期最关键的产品哲学：卖车的理由只有一个，产品本身够好。政策补贴和环保情怀都撑不起一门生意。电动车要赢，光有“我比油车更干净”这种道德优势没用，得靠“我比油车更好开、更好看、更能装”这种硬实力。

这个判断在 2012 年属于少数派。当时业内的主流做法是把电动车包装成环保符号，卖给有情怀的人。特斯拉走的是另一条路，先把车做成好东西，再谈环保。

把污染从排气管挪到电厂，这笔账到底怎么算

每次聊电动车，都会有人抛出同一个问题：电也是烧煤烧出来的，你不过是把排气管从车尾挪到了电厂烟囱上，有什么意义？

马斯克在台上直接把这笔账算了一遍。

在加州，一辆电动车每英里产生的二氧化碳，只有同级汽油车的四分之一。这个数字用的是从电表直接取电的常规场景，没有任何特殊假设。

他还把最坏的情况也摆了出来。西弗吉尼亚是美国电力结构最依赖煤的州之一，即便在那里，电动车每英里的碳排放依然低于汽油车。而在佛蒙特这种以水电和核电为主的州，电动车每英里几乎不产生二氧化碳。

比这更好的情况，是在自家屋顶装光伏。马斯克顺带提了一句，他恰好知道一家做太阳能做得不错的公司，说的是 SolarCity，他本人是这家公司的董事长。装了太阳能之后，一个家庭在屋顶发的电，很容易超过自家车辆消耗的电量。

这就把能源的生产和消费两头都解决了。电动车的环保账，取决于电网的清洁度，而电网的清洁度是可以持续改善的。汽油车的排放曲线是平的，卖给用户的那一刻就固定了；电动车的排放曲线跟着电网一起往下走，同一辆车在十年后会自动变得更干净。这是两种技术路线最本质的差别，也是那个“只是把污染转移了”的质疑站不住脚的地方。

三个数据摆在一起的意义，在于它覆盖了最坏与最好两端。用区间回应质疑，比用平均值有力得多。

Roadster 的真正作用，是让通用汽车坐不住

讲完能源账，马斯克回头讲产品史。

特斯拉的第一款车是 Roadster。在它出现之前，公众对电动车的印象相当统一：慢、丑、续航短，长得像高尔夫球车。

Roadster 要打破的就是这个印象。它比大多数汽油跑车更快，续航够长，外形也好看。马斯克的原话是，Roadster 是“一辆非常像样的高尔夫球车”。这款车后来卖到了 31 个国家。

但 Roadster 最重要的影响，发生在特斯拉公司之外。

通用汽车时任副董事长鲍勃·卢茨（Bob Lutz）看到我们发布 Roadster 之后，把我们的新闻稿拿给他的团队，说：如果加州一家小公司能做到这件事，通用汽车也能做到。（马斯克）

这句话的分量不小。一家创业公司最难证明的地方从来落在别处，技术可行性反而是次要的，真正难的是让大公司相信这件事值得认真对待。Roadster 证明的是后者。它之后，日产的 LEAF 项目、通用的沃蓝达项目相继推进，电动车这盘棋才真正开始动。

特斯拉也没有把技术攥在手里。它和戴姆勒合作做了电动版 Smart 和纯电奔驰 A 级，和丰田合作做了电动版 RAV4，后者在当年晚些时候上市。马斯克的定位很明确：特斯拉是一家硬核的技术与设计公司，技术不该锁在保险柜里，要推向大众市场。

这条路线当时看起来有点反直觉。一家创业公司最怕的就是把核心能力泄露给巨头。马斯克的选择是主动分享，把整个品类的盘子做大。回头看，这个判断是对的：电动车真正起来，靠的是所有厂商一起推，靠一家公司单独吆喝不可能成事。

Model S 身上有三件事值得单独说

从 Roadster 到 Model S 是第二阶段。Model S 的续航被推到 300 英里，车身比 Roadster 大得多，续航反而更长，交付时间定在 2012 年 7 月之前。

它身上有三个细节，放在当年都算超前一截。

第一个是那块 17 英寸的中控触摸屏。马斯克解释这块屏的逻辑：人们平时用 iPhone、iPad、安卓手机，习惯了好用的消费电子产品，一坐进车里，车机反而更差。特斯拉不接受这个落差，干脆去苹果的供应链上找屏幕，把笔记本屏幕为了省电而做的妥协全部去掉，提高对比度和亮度。结果就是，车上那块屏比大多数人手里的 MacBook Pro 还要好。

这段解释里藏着一个方法论。跨行业的供应链能力可以移植。车厂跟车厂比屏幕，永远在那个小圈子里内卷；去跟消费电子比，标准立刻被拉高一个档位。

第二个是 5+2 座椅布局。五个成年人加两个小孩，马斯克说这个配置他自己就需要，他有五个孩子。这句话听起来像玩笑，实际上是产品定义的一部分，创始人自己就是目标用户。

第三个是平台化。Model S 事实上是一个可以衍生出多款车型的平台。有了这个平台，第二款车就能快速跟上。这就是 Model X 的由来，马斯克在台上说得很直接：Model X 的全部意义就在于，它用 Model S 的底子再造出了一款完全不同的车。

Model X 要同时解开三个死结

马斯克在台上把问题定义得很清楚。市面上的车，长期卡在三个矛盾里。

MPV 空间大，但没什么造型可言。SUV 外面看着大，坐进去反而局促。这两个品类迭代了几十年，问题一直没解决。他放了几张历史车型的图，从早期厢式车一路放到奥迪 Q7 和本田奥德赛，然后说了一句：不清楚是不是越改越好。

他自己就有一辆奥迪 Q7，现场还停了一辆供人对比。本田奥德赛他没买。

那么第三个缺失的元素是什么？性能。

于是 Model X 的产品定义就出来了：比 MPV 更能装，比 SUV 更有型，比跑车更快。三个条件同时满足，市面上找不到第二辆车。

这个定义方式值得学。好的产品定义，通常长成一句互相矛盾的话，然后倒逼工程团队去解决矛盾。如果定义本身四平八稳，做出来的东西也就平庸。

一个车门，为什么要重新发明一遍

Model X 最出名的设计是鹰翼门（Falcon Wing doors）。

为什么要做门？因为对 MPV 这类车来说，侧滑门是最核心的体验部件。你要造一辆比 MPV 更好的车，就得先造一扇比侧滑门更好的门。

马斯克说这件事不简单，团队迭代了很多轮。最终的方案是分体式双铰链结构，门先向外平移很小的距离，再向上展开，形状像猎鹰张开翅膀，所以叫鹰翼门。

这个结构带来几个实际好处。

横向占用空间极小。只要一个人能侧身站在车和旁边车辆之间，门就能打开。马斯克说它的进出便利性超过任何侧滑门，因为侧滑门打开后门板本身还占着位置。停车场里被旁车贴得很近、开不了门的窘境，鹰翼门不会遇到。

门展开的高度不超过普通 SUV 尾门开启的高度。判断标准很朴素：只要你的车位能打开 SUV 后备厢，就能打开鹰翼门。他放了一张自己车库的照片，一辆 Roadster 和一辆 Model X 并排停着，用来证明这个高度差真的不大。

门顶是开口的，下雨天站在门下方相当于有把伞。

还有一点是马斯克最看重的，车内的纵向空间足够让人站直。这一点直接改变了儿童安全座椅的使用方式。传统 SUV 里，把小孩放进第二排的安全座椅，大人得弯腰探身、别扭地往里塞。有了这扇门和这个高度，大人可以直接站进车里，把孩子放好再出来。

第三排也解决了。传统 SUV 的第二排装了儿童座椅之后，第三排基本就废了，进出极其困难。Model X 把第二排座椅往前一推，人可以直接走进第三排。马斯克的原话是，七个人，七个体格正常的成年人，都坐得下。

现场演示时，开车的是设计总监弗朗茨·冯·霍尔茨豪森（Franz von Holzhausen），车上还坐了六位参与 Model X 的关键工程师和设计师。马斯克特意点了一句：这些人都不瘦小。这是个很聪明的演示，用真人和真体型证明“七个成年人”不是宣传话术。

电池包铺在地板上，空间就全回来了

鹰翼门解决的是进出，储物空间靠的是另一套逻辑。

燃油车的空间被什么吃掉了？发动机、变速箱、油箱、催化器、排气管。这些部件占据了车头和车尾的大量体积，而且没法挪。电动车的架构把这些统统省掉，电池平铺在车底，前后两端还给用户。

结果很直观。奥迪 Q7 第三排立起来的时候，后备厢基本放不下东西，马斯克的说法是塞几个睡袋、一个背包加一根绳子就到头了。Model X 在第三排立起的状态下，仍有大量行李空间。全部座椅放平之后，车内空间大到可以躺下，塞一辆自行车毫无压力，搬家都够用。

车头还多出一个前备厢。他打开它的时候，现场的反应和台上一样：没想到这里还能装东西。

电动化带来的不只是动力形式的变化，它重新分配了整车的空间结构。这是很多人讨论电动车时容易忽略的一层。电池包铺在地板下方，重心降低了，结构刚度上去了，前后配重也变均匀了，操控和碰撞安全同时受益。这些收益不会写在配置表上，只有开过才知道。

双电机四驱，机械结构做不到的事

Model X 的另一项核心发明，是双电机全轮驱动。前后轴各有一个电机。

传统四驱靠的是机械传动，一根传动轴把动力分到前后轮，分配比例固定，或者只能做很有限的调整。它是一套纯粹的机械连接，反应速度由零件决定。

双电机方案完全不同。前后两个电机的输出可以独立控制，车辆每秒数千次根据路面附着力动态调整前后扭矩分配。哪个轴抓地力强，动力就往哪里送。

这套逻辑还能和转向联动。过弯时按行驶意图分配扭矩，结果是这辆 SUV 的转弯半径小得反常。马斯克说，它可能是转弯半径比 Mini 还小的 SUV。

他还提到这套系统的操控表现：抓地力和循迹性都远超传统四驱。原因不复杂，电机的响应速度是毫秒级的，机械连接的响应速度由物理结构决定，两者不在一个量级上。

这里有个更普遍的道理。很多看起来需要精妙机械设计才能解决的问题，换成电控之后会被降维打击。扭矩分配是这样，刹车能量回收是这样，悬架调节也是这样。汽车行业的很多传统难题，都在被“把机械件换成电机加软件”这个思路重写一遍。

一辆 SUV 跑得比保时捷快，意味着什么

性能数据是整场发布会最直接的一击。

保时捷 911 Carrera，0 到 60 英里加速 4.6 秒。Model X，4.4 秒。

一辆能坐七个成年人、能塞下自行车、第三排还能正常坐人的 SUV，加速比一台经典跑车更快。这句话放在 2012 年，几乎是不合常理的。

它打破的是一个更深的偏见：电动车天生要在性能上妥协。Roadster 时代人们觉得电动跑车是噱头，Model S 时代人们觉得电动车只能做轿车，Model X 把这条线又往前推了一步，连最讲究实用的大车，也不需要为性能让路。

电机的一个物理特性决定了这件事。内燃机需要转速攀升才能输出最大扭矩，中间还要经过变速箱，动力输出是一段一段递进的；电机从零转速开始就是最大扭矩，输出是连续的一条线。这个差别在起步的一瞬间体现得最明显，也是所有电动车加速成绩都好看的根本原因。

什么时候能买到，以及那个没兑现的时间表

发布会最后，马斯克讲了预订和量产节奏。

预订流程和 Model S 一样，先做签名版（Signature Series），再开放普通量产版。生产在 2013 年底启动，先交付少量车辆，2014 年进入批量生产。预订通道在第二天中午于 teslamotors.com 开放，现场的人当晚就能下订。

回头看，这个时间表没兑现。Model X 实际交付拖到了 2015 年 9 月，比承诺晚了将近两年，鹰翼门的工程复杂度是最主要的原因之一。这扇门后来给特斯拉带来过不少麻烦，量产爬坡阶段的良率和密封问题反复出现。

但这场发布会真正有价值的部分不在时间表上，在马斯克拆解问题的方式上。

他把一款新车拆成三个互相冲突的需求，再逐个用技术手段解开。空间和造型冲突，用鹰翼门和纯电架构解。性能和实用性冲突，用双电机解。每一个解法都指向一个具体的物理机制，并非一句空泛的口号。这种拆法，比任何一句宣传语都更能说明一家公司是怎么思考产品的。

还有一点容易被忽略。整场发布会花了大量篇幅讲“我们解决了什么问题”，讲参数的时间相对少。这决定了听众记住的东西：他们记住的是“七个人能坐进去”“下雨有伞”“小孩好放”，并非一个加速数字。

给技术从业者的几条行动建议

  • 评估一个新产品时，先问它解除了什么物理约束。鹰翼门针对的那个约束，跟“把门做得更好”没什么关系，它解决的是停车位太窄、人下不了车这个具体困境。找到被解除的约束，才看得懂产品价值在哪。
  • 看发布会别只记参数，看问题怎么定义。马斯克花了大量时间讲 MPV、SUV、跑车各自的毛病，这段比 0 到 60 的秒数更有信息量。定义问题的方式，决定了产品的天花板。
  • 面对“只是把污染转移了”这类质疑，把账算完，并且覆盖最坏情况。加州四分之一、西弗吉尼亚仍然更低、佛蒙特接近零，三个数据摆出来，任何一端都堵死了。只报平均值的人，永远吵不过质疑者。
  • 如果所在行业存在“消费电子产品体验好于专业设备”的落差，这个落差就是机会。特斯拉去苹果供应链找屏幕，本质是把成熟消费电子供应链的能力移植到车机上。跨行业移植能力，往往比在本行业里内卷更有效。
  • 平台化要趁早。Model S 从设计之初就是可衍生的平台，Model X 才能在两年内跟上。第一款产品如果只为一个场景设计，第二款就得从零开始，研发成本和时间都会翻倍。
  • 给复杂设计留足工程时间。鹰翼门这个案例的教训很直接：发布会承诺了 2013 年底生产，实际交付晚了两年。好设计不等于能量产的设计，在排期时把机械复杂度算进去，比在会上报一个漂亮日期重要得多。
