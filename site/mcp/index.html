1. 安装 Skill

开源仓库：github.com/joeseesun/elon-musk-archive（MIT）。一行安装：

npx skills add joeseesun/elon-musk-archive

或下载 elon-musk-archive.zip，解压到 ~/.workbuddy/skills/elon-musk-archive/ 后重启客户端。

2. 配置 MCP

编辑 ~/.workbuddy/mcp.json，在 mcpServers 下加入：

"elon-musk": {
  "type": "http",
  "url": "https://elon.qiaomu.ai/mcp"
}

保存后在连接器管理里点「信任」并启用。若客户端只支持 stdio，可用 npx -y mcp-remote@latest https://elon.qiaomu.ai/mcp 桥接。

  • 找出"火星殖民"相关的中文精读，并给出视频链接。
