### 经验
- slidep 逐页流程：create → present_files → 每页 upsert-dsl（省略 page-index 追加）→ lint --page-index（0-based）。修复时 upsert 用同一 page-index 覆盖重来。
- 常见 lint 错误：`child-containment`（绝对定位元素 top/bottom 为负值溢出父容器、或同栏堆叠内容超高）→ 改正值 / 压缩 gap 与字号即可。

## 界面 i18n：8 语言运行时翻译（只改界面，内容仍英中）
- 需求：界面支持简中/繁中/英/德/法/西/韩/日；内容保持英文原话 + 中文精读；尽量自动识别地区。
- 架构：一套静态页 + 浏览器端字典（`site/i18n.js`），不生成多套 HTML。字典键为简体中文 UI 原文，运行时替换文本节点与 aria/title/placeholder/alt；SKIP 跳过正文/标题/文稿/语录/图表数据；WeakMap 缓存原文防链式翻译；MutationObserver 处理 JS 动态插入；切换时派发 `i18n:change`。样式 `.i18n-picker` 在 `site/style.css`，注入在 `tools/build.py` 的 `I18N_SCRIPT`（已到 `?v=3`）。
- 自动识别：静态站读不到 IP，改用浏览器语言偏好。优先级 **URL `?lang=` > localStorage > navigator.languages > zh**（URL 优先是为了分享链接与 CDN/边缘注入生效）。静态站若真要按 IP，只能让 CDN/边缘规则重写 `?lang=xx`。

- 另两处坑：① `[lang="en"]` 旧 SKIP 会匹配 `<html lang="en">` 导致整棵 DOM 被跳过 → 改为 `[lang="en"]:not(html)`；② 泛化子串替换会污染中文正文 → 改为「整句精确命中优先 + 人工白名单 SUB_KEYS」。
